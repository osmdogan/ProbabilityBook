30.1 Product \(\sigma\)-Algebras and Projections

Let \((\Omega_1, \mathcal{F}_1)\) and \((\Omega_2, \mathcal{F}_2)\) be measurable spaces.

Definition 30.1 The product \(\sigma\)-algebra, denoted \(\mathcal{F}_1 \otimes \mathcal{F}_2\), is the \(\sigma\)-algebra on \(\Omega_1 \times \Omega_2\) generated by product sets (rectangles) \(A_1 \times A_2\) with \(A_1 \in \mathcal{F}_1\) and \(A_2 \in \mathcal{F}_2\): \[ \mathcal{F}_1 \otimes \mathcal{F}_2 \triangleq \sigma(\{ A_1 \times A_2 \mid A_1 \in \mathcal{F}_1, A_2 \in \mathcal{F}_2 \}) \tag{30.1}\]

More generally, for a finite family of measurable spaces \(\{(\Omega_j, \mathcal{F}_j)\}_{j=1}^d\): \[ \bigotimes_{j=1}^d \mathcal{F}_j \triangleq \sigma\left( \left\{ \prod_{j=1}^d B_j \;\middle|\; B_j \in \mathcal{F}_j \text{ for } 1 \le j \le d \right\} \right) \tag{30.2}\]

  • Canonical Projections: For an arbitrary index set \(J\) and measurable spaces \(\{(\Omega_j,\mathcal{F}_j)\}_{j \in J}\), let \(\pi_k: \prod_{j \in J} \Omega_j \to \Omega_k\) be the coordinate map \(\pi_k\big((\omega_j)_{j \in J}\big) = \omega_k\). When \(J = \{1,\dots,d\}\) we write \(\pi_k(\omega_1,\dots,\omega_d) = \omega_k\).

Example 30.1 (Two-dimensional product space) Let \(\Omega=\mathbb R\times\mathbb R\) and consider the first and second coordinate maps \(\pi_1(x,y)=x\) and \(\pi_2(x,y)=y\). Take \(A=(0,1]\). Then \[ \pi_1^{-1}(A) = \{(x,y)\in\mathbb{R}^2:x\in(0,1]\}. \] Equivalently, \(\pi_1^{-1}((0,1]) = (0,1]\times\mathbb R\). Geometrically, this is a vertical strip in \(\mathbb R^2\).

Take \(B=[2,5]\). Under the second coordinate projection, we have \[ \pi_2^{-1}([2,5]) = \{(x,y):y\in[2,5]\}. \] Therefore, \(\pi_2^{-1}([2,5])=\mathbb{R}\times[2,5]\).

Finally, note that the intersection of cylinder sets is again a cylinder set. For example, \[ \pi_1^{-1}((0,1]) \cap \pi_2^{-1}([2,5]) = (0,1] \times [2,5], \] which restricts both the first and second coordinates.

Definition Definition 30.1 covers only finite families. For an arbitrary index set the correct notion is generated by cylinders, not by unrestricted products; see Remark 30.1 below.

Definition 30.2 (Cylinder Sets) A cylinder set in the product \(\Omega = \prod_{j\in J}\Omega_j\) is a set of the form \(\prod_{j\in J}B_j\) with \(B_j\in\mathcal F_j\) for every \(j\in J\) and \(B_j=\Omega_j\) for all but finitely many \(j\). In particular, a cylinder that restricts only the \(j\)-th coordinate is of the form \(\pi_j^{-1}(B_j)=\prod_{k\in J}B_k\), where \[ B_k= \begin{cases} B_j,&k=j,\\ \Omega_k,&k\neq j. \end{cases} \]

  • For a product space \(\Omega=S_1\times\cdots\times S_N\), the inverse image of a set under the \(n\)th coordinate map has the form \[ \pi_n^{-1}(A) = S_1\times\cdots\times S_{n-1} \times A\times S_{n+1}\times\cdots\times S_N. \] This is called a cylinder set: we restrict one coordinate and leave all the other coordinates unrestricted.

Example 30.2 (A cylinder set in \(\mathbb{R}^{\mathbb{N}}\)) Consider the product space \(\Omega=\mathbb{R}^{\mathbb{N}} = \{(x_1,x_2,x_3,\ldots):x_j\in\mathbb R\}\). Define \[ C = [0,1]\times[2,3]\times\mathbb R\times\mathbb R\times\cdots. \] This is a cylinder set because \(B_1=[0,1]\), \(B_2=[2,3]\), and \(B_j=\mathbb R\quad(j\ge3)\), so only finitely many coordinates are restricted. Equivalently, \[ C = \left\{ x\in\mathbb R^{\mathbb N}: x_1\in[0,1],\ x_2\in[2,3] \right\}. \] In terms of coordinate projections, we have \[ \begin{aligned} &\pi_1^{-1}([0,1])=\{ x\in\mathbb R^{\mathbb N}: x_1\in[0,1] \} = [0,1]\times\mathbb R\times\mathbb R\times\cdots,\\ &\pi_2^{-1}([2,3])=\{ x\in\mathbb R^{\mathbb N}: x_2\in[2,3] \}= \mathbb R\times[2,3]\times\mathbb R\times\mathbb R\times\cdots. \end{aligned} \] Then, \[ \begin{aligned} C &= [0,1]\times[2,3]\times\mathbb R\times\mathbb R\times\cdots\\ &= \pi_1^{-1}([0,1]) \cap \pi_2^{-1}([2,3]). \end{aligned} \]

Example 30.3 (Cylinder events for an infinite sequence of coin tosses) Consider the sample space \(\Omega=\{H,T\}^{\mathbb N}\), where an element \(\omega=(\omega_1,\omega_2,\omega_3,\ldots)\) represents an infinite sequence of coin tosses. Define the cylinder set \[ C=\{\omega\in\Omega:\omega_1=H,\ \omega_3=T,\ \omega_7=H\}. \] In product notation, \[ \begin{aligned} C &= \{H\}\times\{H,T\}\times\{T\} \times\{H,T\}\times\{H,T\}\times\{H,T\}\\ &\times\{H\} \times\prod_{j=8}^{\infty}\{H,T\}. \end{aligned} \] This is a cylinder set because only three coordinates are restricted: 1, 3, and 7. All other coordinates are unrestricted. Equivalently, if \(\pi_j(\omega)=\omega_j\) denotes the \(j\)-th coordinate projection, then \[ \begin{aligned} &\pi_1^{-1}(\{H\})=\{\omega\in\Omega:\omega_1=H\} = \{H\}\times\{H,T\}\times\{H,T\}\times\cdots\\ &\pi_3^{-1}(\{T\})=\{\omega\in\Omega:\omega_3=T\} = \{H,T\}\times\{H,T\}\times\{T\}\times\{H,T\}\times\cdots\\ &\pi_7^{-1}(\{H\})=\{\omega\in\Omega:\omega_7=H\} = \{H,T\}\times\{H,T\}\times\{H,T\}\\ &\times\{H,T\}\times\{H,T\}\times\{H,T\}\times\{H\}\times\cdots \end{aligned} \] Then, we can express \(C\) as the intersection of these cylinder sets: \[ C = \pi_1^{-1}(\{H\}) \cap \pi_3^{-1}(\{T\}) \cap \pi_7^{-1}(\{H\}). \] This illustrates the fundamental idea of a cylinder set: A cylinder event specifies finitely many observations and ignores the rest.

We now give the formal definition of the product \(\sigma\)-algebra for an arbitrary index set.

Definition 30.3 (Product \(\sigma\)-Algebra for an Arbitrary Index Set) Let \(J\) be an arbitrary index set and let \(\{(\Omega_j,\mathcal{F}_j)\}_{j \in J}\) be measurable spaces. Set \(\Omega \triangleq \prod_{j \in J}\Omega_j\). The product \(\sigma\)-algebra is the \(\sigma\)-algebra on \(\Omega\) generated by the cylinder sets: \[ \bigotimes_{j \in J} \mathcal{F}_j \triangleq \sigma\left( \left\{ \pi_j^{-1}(B_j) \;\middle|\; j \in J,\ B_j \in \mathcal{F}_j \right\} \right), \tag{30.3}\] equivalently the \(\sigma\)-algebra generated by those products \(\prod_{j \in J} B_j\) with \(B_j \in \mathcal{F}_j\) for every \(j\) and \(B_j = \Omega_j\) for all but finitely many \(j\).

  • Notation (\(\sigma\)-algebra generated by a family of maps): Given maps \(g_i : \Omega \to \Omega_i'\) into measurable spaces \((\Omega_i', \mathcal{F}_i')\), \(i \in I\), define \[ \sigma(\{g_i \mid i \in I\}) \triangleq \sigma\left( \bigcup_{i \in I} g_i^{-1}(\mathcal{F}_i') \right). \tag{30.4}\] This is the smallest \(\sigma\)-algebra on \(\Omega\) making every \(g_i\) measurable: a \(\sigma\)-algebra \(\mathcal{A}\) on \(\Omega\) renders every \(g_i\) measurable iff \(g_i^{-1}(\mathcal{F}_i') \subseteq \mathcal{A}\) for all \(i \in I\), iff \(\mathcal{A} \supseteq \sigma(\{g_i \mid i \in I\})\). With this notation, Equation 30.3 reads \(\bigotimes_{j \in J}\mathcal{F}_j = \sigma(\{\pi_j \mid j \in J\})\).

Remark 30.1 (The Rectangle Definition Does Not Extend to Uncountable \(J\)). For countable \(J\) the cylinder definition Equation 30.3 agrees with the naive rectangle definition, because then \[ \prod_{j \in J} B_j = \bigcap_{j \in J} \pi_j^{-1}(B_j) \] is a countable intersection of cylinders. For uncountable \(J\) the two differ, and \(\sigma\big(\{\prod_{j \in J}B_j\}\big)\) is strictly larger than \(\bigotimes_{j \in J}\mathcal{F}_j\).

Lemma 30.1 Let \(J\) be an arbitrary index set and \(\{(\Omega_j,\mathcal{F}_j)\}_{j \in J}\) measurable spaces. Each canonical projection \(\pi_k : \prod_{j \in J}\Omega_j \to \Omega_k\), \(k \in J\), is \(\bigotimes_{j \in J}\mathcal{F}_j \,/\, \mathcal{F}_k\)-measurable.

Proof (Proof of Lemma 30.1). To prove that \(\pi_k\) is measurable, we must show that \(\pi_k^{-1}(A)\in \bigotimes_{j \in J}\mathcal{F}_j\) for every \(A\in\mathcal{F}_k\). Take an arbitrary \(A\in\mathcal{F}_k\). By Definition 30.3, \(\pi_k^{-1}(A)\) is one of the generating cylinder sets of \(\bigotimes_{j \in J}\mathcal{F}_j\), hence lies in it.

In the finite case \(J = \{1,\dots,d\}\) one can argue directly from Definition 30.1. By the definition of \(\pi_k\), \[ \begin{aligned} \pi_k^{-1}(A) &= \left\{\omega \in \prod_{j=1}^d \Omega_j \mid \pi_k(\omega) \in A \right\}= \left\{\omega \in \prod_{j=1}^d \Omega_j \mid \omega_k \in A \right\}. \end{aligned} \] This set can be written as the rectangle \[ \pi_k^{-1}(A) = \Omega_1 \times \dots \times \Omega_{k-1} \times A \times \Omega_{k+1} \times \dots \times \Omega_d. \] Since \(\Omega_j \in \mathcal{F}_j\) for all \(j \neq k\) and \(A \in \mathcal{F}_k\), it follows that \(\pi_k^{-1}(A) \in \bigotimes_{j=1}^d \mathcal{F}_j\). Therefore, \(\pi_k\) is measurable.

The following lemma characterizes the product \(\sigma\)-algebra in terms of the canonical projections. It shows that the product \(\sigma\)-algebra is the smallest \(\sigma\)-algebra on \(\prod_{j=1}^d \Omega_j\) that makes all coordinate projections measurable.

Lemma 30.2 Let \(\{(\Omega_j,\mathcal{F}_j)\}_{j=1}^d\) be a finite family of measurable spaces and, for \(k \in \{1, \dots, d\}\), let \(\pi_k: \prod_{j=1}^d \Omega_j \to \Omega_k\) be defined by \(\pi_k(\omega_1, \dots, \omega_d) = \omega_k\). Then \[ \begin{aligned} \bigotimes_{j=1}^d \mathcal{F}_j &= \sigma(\{\pi_k \mid 1 \le k \le d\})\\ &=\sigma(\{\pi^{-1}_k(B_k) \mid 1 \le k \le d, B_k \in \mathcal{F}_k\}). \end{aligned} \]

Proof (Proof of Lemma 30.2). Let \(\mathcal{R} \triangleq \left\{ \prod_{j=1}^d B_j \;\middle|\; B_j \in \mathcal{F}_j \text{ for } 1 \le j \le d \right\}\) denote the collection of product rectangles on \(\Omega = \prod_{j=1}^d \Omega_j\). By Definition 30.1, the product \(\sigma\)-algebra is \(\bigotimes_{j=1}^d \mathcal{F}_j = \sigma(\mathcal{R})\).

The second equality in the statement is Equation 30.4 applied to the family \(\{\pi_k\}_{k=1}^d\), i.e. it holds by definition of \(\sigma(\{\pi_k \mid 1 \le k \le d\})\); as recorded there, this is the smallest \(\sigma\)-algebra on \(\Omega\) making every \(\pi_k\) measurable. It therefore remains to prove the first equality, which we do by mutual inclusion between \(\sigma(\mathcal{R})\) and \(\sigma(\{\pi_k \mid 1 \le k \le d\})\).

  1. \((\subseteq)\) Inclusion: Let \(E \in \bigcup_{k=1}^d \pi_k^{-1}(\mathcal{F}_k)\). Then \(E = \pi_k^{-1}(B_k)\) for some \(k \in \{1, \dots, d\}\) and \(B_k \in \mathcal{F}_k\). We can express \(E\) as a product rectangle: \[ E = \pi_k^{-1}(B_k) = \Omega_1 \times \dots \times \Omega_{k-1} \times B_k \times \Omega_{k+1} \times \dots \times \Omega_d \] Since \(\Omega_j \in \mathcal{F}_j\) for all \(j \neq k\) and \(B_k \in \mathcal{F}_k\), it follows that \(E \in \mathcal{R} \subseteq \sigma(\mathcal{R})\). Thus, \(\bigcup_{k=1}^d \pi_k^{-1}(\mathcal{F}_k) \subseteq \sigma(\mathcal{R})\). Since \(\sigma(\{\pi_k \mid 1 \le k \le d\})\) is generated by this collection, we conclude: \[ \sigma(\{\pi_k \mid 1 \le k \le d\}) \subseteq \sigma(\mathcal{R}) = \bigotimes_{j=1}^d \mathcal{F}_j \]

  2. \((\supseteq)\) Inclusion: Let \(R = \prod_{j=1}^d B_j \in \mathcal{R}\) be an arbitrary product rectangle, where \(B_j \in \mathcal{F}_j\) for each \(j \in \{1, \dots, d\}\). Notice that \(R\) can be written as a finite intersection of preimages under projection maps: \[ R = \bigcap_{j=1}^d \pi_j^{-1}(B_j) \] Indeed, for any \((\omega_1, \dots, \omega_d) \in \prod_{j=1}^d \Omega_j\): \[ \begin{aligned} &(\omega_1, \dots, \omega_d) \in \bigcap_{j=1}^d \pi_j^{-1}(B_j) \\ &\iff \pi_j(\omega_1, \dots, \omega_d) = \omega_j \in B_j \text{ for all } j \\ &\iff (\omega_1, \dots, \omega_d) \in \prod_{j=1}^d B_j = R. \end{aligned} \] For each \(j\), \(B_j \in \mathcal{F}_j \implies \pi_j^{-1}(B_j) \in \sigma(\{\pi_k \mid 1 \le k \le d\})\). Since a \(\sigma\)-algebra is closed under finite intersections, \(R \in \sigma(\{\pi_k \mid 1 \le k \le d\})\). Thus, \(\mathcal{R} \subseteq \sigma(\{\pi_k \mid 1 \le k \le d\})\), which implies: \[ \bigotimes_{j=1}^d \mathcal{F}_j = \sigma(\mathcal{R}) \subseteq \sigma(\{\pi_k \mid 1 \le k \le d\}) \]

Combining both inclusions yields \(\bigotimes_{j=1}^d \mathcal{F}_j = \sigma(\{\pi_k \mid 1 \le k \le d\})\), which together with the second equality noted above completes the proof.

Some Observations:

  • Consequently, for finite \(J = \{1,\dots,d\}\) the rectangle definition Definition 30.1 and the cylinder definition Definition 30.3 agree, and the product \(\sigma\)-algebra is the smallest \(\sigma\)-algebra on \(\prod_{j=1}^d\Omega_j\) that makes all coordinate projections \(\pi_1,\ldots,\pi_d\) measurable.

  • Borel \(\sigma\)-Algebra Identity: \(\mathcal{B}(\mathbb{R}^d) = \bigotimes_{j=1}^d \mathcal{B}(\mathbb{R})\).

    • Proof. \((\supseteq)\) Each projection \(\pi_j : \mathbb{R}^d \to \mathbb{R}\) is continuous, hence \(\mathcal{B}(\mathbb{R}^d)/\mathcal{B}(\mathbb{R})\)-measurable; so \(\mathcal{B}(\mathbb{R}^d)\) makes every \(\pi_j\) measurable and therefore contains \(\sigma(\{\pi_j \mid 1\le j\le d\}) = \bigotimes_{j=1}^d\mathcal{B}(\mathbb{R})\) by Lemma 30.2. \((\subseteq)\) Every open \(U \subseteq \mathbb{R}^d\) is a countable union of open boxes \(\prod_{j=1}^d(a_j,b_j)\) with rational \(a_j < b_j\), and each such box is a measurable rectangle; hence \(U \in \bigotimes_{j=1}^d\mathcal{B}(\mathbb{R})\). Since the open sets generate \(\mathcal{B}(\mathbb{R}^d)\), we get \(\mathcal{B}(\mathbb{R}^d) \subseteq \bigotimes_{j=1}^d\mathcal{B}(\mathbb{R})\).
    • Caveat. The inclusion \((\subseteq)\) uses second countability of \(\mathbb{R}^d\) and does not hold for general topological spaces: if \(X\) is a discrete space of cardinality \(> \mathfrak{c}\), then \(\mathcal{B}(X) = 2^X\), \(X\times X\) is discrete so the diagonal \(\Delta\) is Borel in \(X \times X\), yet \(\Delta \notin \mathcal{B}(X) \otimes \mathcal{B}(X)\). In general one only has \(\mathcal{B}(X) \otimes \mathcal{B}(Y) \subseteq \mathcal{B}(X \times Y)\), with equality when \(X\) and \(Y\) are second countable.

30.2 Product Measurability Lemma

The following lemma characterizes the measurability of functions into a product space in terms of the measurability of their component functions.

Lemma 30.3 Let \(\{(\Omega_j, \mathcal{F}_j)\}_{j \in J}\) and \((\Upsilon, \mathcal{B})\) be measurable spaces. A function \(f: \Upsilon \to \prod_{j \in J} \Omega_j\) is \(\mathcal{B} \,/\, \bigotimes_{j \in J} \mathcal{F}_j\)-measurable if and only if the component mapping \(\pi_k \circ f: \Upsilon \to \Omega_k\) is \(\mathcal{B} \,/\, \mathcal{F}_k\)-measurable for every \(k \in J\).

Proof (Proof of Lemma 30.3). Let \(\Omega \triangleq \prod_{j \in J} \Omega_j\) and let \(\mathcal{F} \triangleq \bigotimes_{j \in J} \mathcal{F}_j\) denote the product \(\sigma\)-algebra.

\((\Rightarrow)\) Forward Direction:
Assume \(f: \Upsilon \to \Omega\) is \(\mathcal{B} \,/\, \mathcal{F}\)-measurable.
Fix any \(k \in J\). By Lemma 30.1, the canonical projection map \(\pi_k: \Omega \to \Omega_k\) is \(\mathcal{F} \,/\, \mathcal{F}_k\)-measurable because \(\pi_k^{-1}(E_k) \in \mathcal{F}\) for all \(E_k \in \mathcal{F}_k\).
Since the composition of two measurable maps is measurable, the component map \(\pi_k \circ f: \Upsilon \to \Omega_k\) is \(\mathcal{B} \,/\, \mathcal{F}_k\)-measurable for every \(k \in J\).

\((\Leftarrow)\) Backward Direction:
Assume that \(\pi_k \circ f: \Upsilon \to \Omega_k\) is \(\mathcal{B} \,/\, \mathcal{F}_k\)-measurable for every \(k \in J\).
Define the generating collection of cylinder sets on \(\Omega\) by: \[ \mathcal{G} \triangleq \bigcup_{j \in J} \pi_j^{-1}(\mathcal{F}_j) = \left\{ \pi_j^{-1}(E_j) \;\middle|\; j \in J,\, E_j \in \mathcal{F}_j \right\} \] By Definition 30.3, \(\mathcal{F} = \sigma(\mathcal{G})\). (For finite \(J\) this is consistent with Definition 30.1 by Lemma 30.2.)

To prove that \(f\) is \(\mathcal{B} \,/\, \mathcal{F}\)-measurable, we must show that \(f^{-1}(E) \in \mathcal{B}\) for all \(E \in \mathcal{F}\). Consider the set of preimages under \(f\): \[ \mathcal{A} \triangleq \{ E \subseteq \Omega \mid f^{-1}(E) \in \mathcal{B} \} \] Then \(\mathcal{A}\) is a \(\sigma\)-algebra on \(\Omega\), since preimages commute with complements and countable unions: \(f^{-1}(\Omega) = \Upsilon \in \mathcal{B}\), \(f^{-1}(E^c) = (f^{-1}(E))^c\), and \(f^{-1}(\bigcup_n E_n) = \bigcup_n f^{-1}(E_n)\).

Now, take any generating set \(A \in \mathcal{G}\). Then \(A = \pi_j^{-1}(E_j)\) for some \(j \in J\) and \(E_j \in \mathcal{F}_j\). Evaluating the preimage under \(f\) gives: \[ f^{-1}(A) = f^{-1}\left( \pi_j^{-1}(E_j) \right) = (\pi_j \circ f)^{-1}(E_j) \] By hypothesis, \(\pi_j \circ f\) is \(\mathcal{B} \,/\, \mathcal{F}_j\)-measurable, so \((\pi_j \circ f)^{-1}(E_j) \in \mathcal{B}\). Thus, \(A \in \mathcal{A}\), which implies \(\mathcal{G} \subseteq \mathcal{A}\).

Since \(\mathcal{A}\) is a \(\sigma\)-algebra containing \(\mathcal{G}\), it contains the \(\sigma\)-algebra generated by \(\mathcal{G}\): \[ \mathcal{F} = \sigma(\mathcal{G}) \subseteq \mathcal{A} \] Hence, \(f^{-1}(E) \in \mathcal{B}\) for all \(E \in \mathcal{F}\), proving that \(f\) is \(\mathcal{B} \,/\, \mathcal{F}\)-measurable.

Some Observations:

  • This lemma is often written more simply as: writing \(f_k \triangleq \pi_k \circ f : \Upsilon \to \Omega_k\) for the \(k\)-th component map of \(f\), the map \(f: \Upsilon \to \prod_{j \in J} \Omega_j\) is \(\mathcal{B} \,/\, \bigotimes_{j \in J} \mathcal{F}_j\)-measurable if and only if each component map \(f_k\) is \(\mathcal{B} \,/\, \mathcal{F}_k\)-measurable for all \(k \in J\).

30.3 Tensor Product Functions

Given \(f_1: \Omega_1 \to \mathbb{R}\) and \(f_2: \Omega_2 \to \mathbb{R}\), their tensor product \(f_1 \otimes f_2: \Omega_1 \times \Omega_2 \to \mathbb{R}\) is defined by: \[ (f_1 \otimes f_2)(\omega_1, \omega_2) \triangleq f_1(\omega_1) \cdot f_2(\omega_2) \tag{30.5}\]

Lemma 30.4 Let \(f_i : \Omega_i \to \mathbb{R}\) be \(\mathcal{F}_i\)-measurable for \(i = 1,2\). Then \(f_1 \otimes f_2\) is \((\mathcal{F}_1 \otimes \mathcal{F}_2)\)-measurable.

Proof (Proof of Lemma 30.4). Note first that \(f_1 \otimes f_2 = (f_1 \circ \pi_1) \cdot (f_2 \circ \pi_2)\).

  • By Lemma 30.1 the coordinate projections \(\pi_i\) are \((\mathcal{F}_1 \otimes \mathcal{F}_2)/\mathcal{F}_i\)-measurable; since \(f_i\) is \(\mathcal{F}_i\)-measurable and compositions of measurable maps are measurable, \(f_1\circ\pi_1\) and \(f_2\circ\pi_2\) are \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable real-valued functions.
  • By Lemma 30.3, the pair map \[ \Phi \triangleq (f_1\circ\pi_1,\, f_2\circ\pi_2) : \Omega_1\times\Omega_2 \to \mathbb{R}^2 \] is \((\mathcal{F}_1\otimes\mathcal{F}_2) \,/\, \big(\mathcal{B}(\mathbb{R})\otimes\mathcal{B}(\mathbb{R})\big)\)-measurable, since both of its components are measurable. By the Borel \(\sigma\)-algebra identity \(\mathcal{B}(\mathbb{R})\otimes\mathcal{B}(\mathbb{R}) = \mathcal{B}(\mathbb{R}^2)\), \(\Phi\) is in fact \((\mathcal{F}_1\otimes\mathcal{F}_2)/\mathcal{B}(\mathbb{R}^2)\)-measurable. (This step is exactly where second countability of \(\mathbb{R}\) is used.)
  • The multiplication map \(m:\mathbb{R}^2\to\mathbb{R}\), \(m(x,y)=xy\), is continuous and hence \(\mathcal{B}(\mathbb{R}^2)/\mathcal{B}(\mathbb{R})\)-measurable. Therefore \[ f_1\otimes f_2 = m\circ\Phi \] is \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable.

30.4 Iterated Integrals for Non-Negative Functions

The following theorem is the iterated-integral form of Tonelli’s theorem. It establishes the measurability of slice functions and the equality of iterated integrals for non-negative measurable functions on product spaces. It is logically prior to the product measure itself: it is what makes Corollary 30.1 possible. The form of Tonelli’s theorem that also identifies these iterated integrals with the integral against \(\mu_1\otimes\mu_2\) is Theorem 31.1 in Lecture 14.3.

Theorem 30.1 (Tonelli’s Theorem (Iterated-Integral Form)) Let \((\Omega_1, \mathcal{F}_1)\) and \((\Omega_2, \mathcal{F}_2)\) be measurable spaces and let \(f: \Omega_1 \times \Omega_2 \to [0, \infty]\) be a non-negative \((\mathcal{F}_1 \otimes \mathcal{F}_2)\)-measurable function. Then:

  1. Slice Measurability (no hypothesis on the measures is required):
    • For every fixed \(\omega_2 \in \Omega_2\), the slice function \(\omega_1 \mapsto f(\omega_1, \omega_2)\) is \(\mathcal{F}_1\)-measurable.
    • For every fixed \(\omega_1 \in \Omega_1\), the slice function \(\omega_2 \mapsto f(\omega_1, \omega_2)\) is \(\mathcal{F}_2\)-measurable.

Assume in addition that \(\mu_1\) and \(\mu_2\) are measures on \((\Omega_1,\mathcal{F}_1)\) and \((\Omega_2,\mathcal{F}_2)\) that are \(\sigma\)-finite. Then:

  1. Integrated Slice Measurability:
    • The function \(\omega_1 \mapsto \int_{\Omega_2} f(\omega_1, \omega_2) \, \mu_2(d\omega_2)\) is \(\mathcal{F}_1\)-measurable (as a map into \(([0,\infty],\mathcal{B}([0,\infty]))\)).
    • The function \(\omega_2 \mapsto \int_{\Omega_1} f(\omega_1, \omega_2) \, \mu_1(d\omega_1)\) is \(\mathcal{F}_2\)-measurable.
  2. Equality of Iterated Integrals (both sides being elements of \([0,\infty]\)): \[ \begin{aligned} &\int_{\Omega_1} \left( \int_{\Omega_2} f(\omega_1, \omega_2) \, \mu_2(d\omega_2) \right) \mu_1(d\omega_1) \\ &= \int_{\Omega_2} \left( \int_{\Omega_1} f(\omega_1, \omega_2) \, \mu_1(d\omega_1) \right) \mu_2(d\omega_2) \end{aligned} \tag{30.6}\]

Remark 30.2 (\(\sigma\)-Finiteness Is Necessary in Parts 2 and 3). Let \(\Omega_1 = \Omega_2 = [0,1]\) with \(\mathcal{F}_1 = \mathcal{F}_2 = \mathcal{B}([0,1])\), let \(\mu_1 = \lambda\) be Lebesgue measure and let \(\mu_2\) be counting measure (which is not \(\sigma\)-finite on \([0,1]\)). The diagonal \[ D \triangleq \{(x,x) \mid x \in [0,1]\} \] is closed in \([0,1]^2\), hence \(D \in \mathcal{B}([0,1]^2) = \mathcal{B}([0,1])\otimes\mathcal{B}([0,1])\), so \(f = \mathbf{1}_D\) is product-measurable and non-negative: \[ f(x,y)=\mathbf{1}_D(x,y) = \begin{cases} 1 & \text{if } x=y,\\ 0 & \text{otherwise}. \end{cases} \]

Then \[ \begin{aligned} \int_{\Omega_1}\!\!\int_{\Omega_2} f \, d\mu_2\, d\mu_1 &= \int_{\Omega_1}\left(\int_{\Omega_2} \mathbf{1}_{\{x\}}(y)\mu_2(dy)\right) d\mu_1\\ &=\int_{\Omega_1}\mu_2(\{x\}) d\mu_1\\ &=\int_{[0,1]} 1 \, \lambda(dx) = 1, \end{aligned} \] \[ \begin{aligned} \int_{\Omega_2}\!\!\int_{\Omega_1} f \, d\mu_1\, d\mu_2 &= \int_{\Omega_2}\left(\int_{\Omega_1} \mathbf{1}_{\{y\}}(x)\mu_1(dx) \right) \mu_2(dy)\\ &=\int_{[0,1]} 0 \, \mu_2(dy) = 0 . \end{aligned} \] Thus Equation 30.6 fails. Note that part 1 still holds here, as it must. The same example shows that uniqueness in Corollary 30.1 fails without \(\sigma\)-finiteness.

Proof (Proof of Theorem 30.1). Steps 1–3 prove all three assertions under the temporary hypothesis \[ \mu_1(\Omega_1) < \infty \quad\text{and}\quad \mu_2(\Omega_2) < \infty, \] which is assumed throughout Steps 1–3. Step 4 removes it: it derives part 1 with no hypothesis on the measures at all, and parts 2–3 under \(\sigma\)-finiteness.

30.4.1 Step 1: Verification for Elementary Tensor Products

Let \(f = f_1 \otimes f_2\), where \(f_1 \in \mathbb{B}(\Omega_1, \mathcal{F}_1, \mathbb{R})\) and \(f_2 \in \mathbb{B}(\Omega_2, \mathcal{F}_2, \mathbb{R})\), i.e. \(f_i\) is bounded, real-valued and \(\mathcal{F}_i\)-measurable. By Lemma 30.4, \(f\) is \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable, and it is bounded, so \(f \in \mathbb{B}(\Omega_1\times\Omega_2, \mathcal{F}_1\otimes\mathcal{F}_2, \mathbb{R})\). Since \(\mu_1,\mu_2\) are finite and \(f_1,f_2\) are bounded, all integrals appearing below are finite real numbers, so no \(\infty - \infty\) or \(0\cdot\infty\) ambiguity can arise.

  1. Slice Measurability: For fixed \(\omega_2 \in \Omega_2\), \(\omega_1 \mapsto (f_1 \otimes f_2)(\omega_1, \omega_2) = f_2(\omega_2) \cdot f_1(\omega_1)\) is a constant multiple of an \(\mathcal{F}_1\)-measurable function, hence \(\mathcal{F}_1\)-measurable. By symmetry, \(\omega_2 \mapsto f_1(\omega_1) f_2(\omega_2)\) is \(\mathcal{F}_2\)-measurable for fixed \(\omega_1\).
  2. Integrated Slice Functions: Fix \(\omega_1 \in \Omega_1\). Since \(f_2\) is bounded and \(\mu_2(\Omega_2)<\infty\), \(f_2 \in L^1(\mu_2)\) and \(\int_{\Omega_2} f_2\,d\mu_2 \in \mathbb{R}\); since \(f_1(\omega_1) \in \mathbb{R}\) is a finite constant, it may be pulled out of the integral: \[ I_2(\omega_1) \triangleq \int_{\Omega_2} f_1(\omega_1) f_2(\omega_2) \, \mu_2(d\omega_2) = f_1(\omega_1) \int_{\Omega_2} f_2 \, d\mu_2 \] As \(\int_{\Omega_2} f_2 \, d\mu_2\) is a finite constant, \(I_2\) is a constant multiple of \(f_1\) and hence \(\mathcal{F}_1\)-measurable (and bounded).
  3. Equality of Iterated Integrals: \(I_2\) is bounded and \(\mu_1(\Omega_1)<\infty\), so \(I_2 \in L^1(\mu_1)\) and integrating over \(\Omega_1\) gives: \[ \int_{\Omega_1} I_2(\omega_1) \, \mu_1(d\omega_1) = \left( \int_{\Omega_1} f_1 \, d\mu_1 \right) \left( \int_{\Omega_2} f_2 \, d\mu_2 \right) \] Reversing the roles of the two coordinates in items 2 and 3 yields the same product of finite numbers for the other iterated integral, establishing equality.

30.4.2 Step 2: Extension to Bounded Measurable Functions via Dynkin’s Theorem

Define the space of test functions \(\mathbb{M} \triangleq \{ f_1 \otimes f_2 \mid f_1 \in \mathbb{B}(\Omega_1, \mathcal{F}_1, \mathbb{R}),\, f_2 \in \mathbb{B}(\Omega_2, \mathcal{F}_2, \mathbb{R}) \}\).

  • \(\mathbb{M}\) is a Multiplicative System: For \(f_1 \otimes f_2, g_1 \otimes g_2 \in \mathbb{M}\), \((f_1 \otimes f_2) \cdot (g_1 \otimes g_2) = (f_1 g_1) \otimes (f_2 g_2) \in \mathbb{M}\) because products of bounded measurable functions remain bounded and measurable.
  • \(\mathbb{M}\) Generates \(\mathcal{F}_1 \otimes \mathcal{F}_2\): We check both inclusions.
    • \((\supseteq)\) For \(A_1 \in \mathcal{F}_1\) and \(A_2 \in \mathcal{F}_2\), \(\mathbf{1}_{A_1 \times A_2} = \mathbf{1}_{A_1} \otimes \mathbf{1}_{A_2} \in \mathbb{M}\), so \(A_1\times A_2 = (\mathbf{1}_{A_1}\otimes\mathbf{1}_{A_2})^{-1}(\{1\}) \in \sigma(\mathbb{M})\). Since \(\sigma(\mathbb{M})\) contains all measurable rectangles, \(\mathcal{F}_1\otimes\mathcal{F}_2 \subseteq \sigma(\mathbb{M})\).
    • \((\subseteq)\) By Lemma 30.4 every element of \(\mathbb{M}\) is \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable, so \(\sigma(\mathbb{M}) \subseteq \mathcal{F}_1\otimes\mathcal{F}_2\).
    Hence \(\sigma(\mathbb{M}) = \mathcal{F}_1 \otimes \mathcal{F}_2\).

Define \(\mathbb{H} \subseteq \mathbb{B}(\Omega_1 \times \Omega_2, \mathcal{F}_1 \otimes \mathcal{F}_2, \mathbb{R})\) as the collection of bounded measurable functions \(g\) satisfying:

  1. For every fixed \(\omega_2 \in \Omega_2\) the map \(\omega_1 \mapsto g(\omega_1, \omega_2)\) is \(\mathcal{F}_1\)-measurable, and for every fixed \(\omega_1 \in \Omega_1\) the map \(\omega_2 \mapsto g(\omega_1, \omega_2)\) is \(\mathcal{F}_2\)-measurable.
  2. The map \(\omega_1 \mapsto \int_{\Omega_2} g(\omega_1, \omega_2) \, d\mu_2\) is \(\mathcal{F}_1\)-measurable and the map \(\omega_2 \mapsto \int_{\Omega_1} g(\omega_1, \omega_2) \, d\mu_1\) is \(\mathcal{F}_2\)-measurable. (These integrals are well defined by property (1), and are finite real numbers because \(g\) is bounded and \(\mu_1,\mu_2\) are finite.)
  3. \(\int_{\Omega_1} \left( \int_{\Omega_2} g(\omega_1, \omega_2) \, d\mu_2 \right) d\mu_1 = \int_{\Omega_2} \left( \int_{\Omega_1} g(\omega_1, \omega_2) \, d\mu_1 \right) d\mu_2\).

\(\mathbb{M} \subseteq \mathbb{H}\): By Step 1, every \(f \in \mathbb{M}\) satisfies properties (1), (2), (3) above, so \(\mathbb{M} \subseteq \mathbb{H}\).

We verify the remaining properties of \(\mathbb{H}\):

  1. Vector Space containing \(1\): Let \(g, \tilde{g} \in \mathbb{H}\) and \(a, b \in \mathbb{R}\). Property (1) for \(a g + b\tilde g\) is immediate. For (2) and (3), note that all four functions \(g(\cdot,\omega_2)\), \(g(\omega_1,\cdot)\), \(\tilde g(\cdot,\omega_2)\), \(\tilde g(\omega_1,\cdot)\) are bounded and \(\mu_1,\mu_2\) are finite, so every integral involved is a finite real number and linearity of the integral applies without any \(\infty-\infty\) ambiguity; consequently \[ \int_{\Omega_2}(a g + b\tilde g)(\omega_1,\cdot)\,d\mu_2 = a\!\int_{\Omega_2} g(\omega_1,\cdot)\,d\mu_2 + b\!\int_{\Omega_2} \tilde g(\omega_1,\cdot)\,d\mu_2, \] which is \(\mathcal{F}_1\)-measurable, and the two iterated integrals of \(ag+b\tilde g\) agree because they do for \(g\) and for \(\tilde g\). Hence \(\mathbb{H}\) is a vector space. Since \(1 = 1 \otimes 1 \in \mathbb{M} \subseteq \mathbb{H}\), the constant function \(1\) belongs to \(\mathbb{H}\).

  2. Closed under Bounded Convergence: Let \(\{g_n\} \subset \mathbb{H}\) with \(|g_n(\omega_1, \omega_2)| \le M < \infty\) for all \(n\) and all \((\omega_1,\omega_2)\), and \(g_n \to g\) pointwise on \(\Omega_1\times\Omega_2\). Then \(g\) is \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable and \(|g|\le M\), so \(g \in \mathbb{B}(\Omega_1\times\Omega_2,\mathcal{F}_1\otimes\mathcal{F}_2,\mathbb{R})\).

    • Slice Limits: For fixed \(\omega_2\), \(g_n(\cdot,\omega_2) \to g(\cdot,\omega_2)\) pointwise, and each \(g_n(\cdot,\omega_2)\) is \(\mathcal{F}_1\)-measurable by property (1) for \(g_n\); a pointwise limit of measurable functions is measurable, so \(g\) satisfies property (1) (and symmetrically in the other coordinate).
    • Slice Integrals: Define \(h_n(\omega_1) \triangleq \int_{\Omega_2} g_n(\omega_1, \omega_2) \, \mu_2(d\omega_2)\). Fix \(\omega_1\). Since \(|g_n(\omega_1,\cdot)| \le M\) and \(\mu_2(\Omega_2) < \infty\), the constant \(M\) is \(\mu_2\)-integrable and dominates the sequence. By the Dominated Convergence Theorem (DCT): \[ \lim_{n \to \infty} h_n(\omega_1) = \int_{\Omega_2} g(\omega_1, \omega_2) \, \mu_2(d\omega_2) \triangleq h(\omega_1) \] Since each \(h_n\) is \(\mathcal{F}_1\)-measurable by property (2) for \(g_n\), their pointwise limit \(h\) is \(\mathcal{F}_1\)-measurable, verifying property (2) for \(g\) (and symmetrically in the other coordinate).
    • Iterated Integral Limit: Note that \(|h_n(\omega_1)| \le M \mu_2(\Omega_2) < \infty\) for all \(n\) and \(\omega_1\), and \(\mu_1(\Omega_1)<\infty\), so the constant \(M\mu_2(\Omega_2)\) is \(\mu_1\)-integrable and dominates \(\{h_n\}\). Applying DCT a second time with respect to \(\mu_1\): \[ \int_{\Omega_1} h(\omega_1) \, d\mu_1 = \lim_{n \to \infty} \int_{\Omega_1} h_n(\omega_1) \, d\mu_1 \] By symmetry, the analogous limit holds for the reversed order of integration. Since the two iterated integrals agree for each \(g_n\) by property (3), and both sides converge, they agree for \(g\), verifying property (3).

All hypotheses of Dynkin’s Multiplicative Systems Theorem (Theorem 29.1) are satisfied: \(\mathbb{M}\) is a multiplicative system, \(\mathbb{M} \subseteq \mathbb{H}\), \(\mathbb{H}\) is a vector space of bounded functions containing \(1\) that is closed under bounded convergence, and \(\sigma(\mathbb{M}) = \mathcal{F}_1 \otimes \mathcal{F}_2\). Therefore \[ \mathbb{H} \supseteq \mathbb{B}(\Omega_1 \times \Omega_2, \mathcal{F}_1 \otimes \mathcal{F}_2, \mathbb{R}), \] i.e. every bounded \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable function satisfies (1), (2), (3).

30.4.3 Step 3: Extension to Non-Negative Functions

Let \(f: \Omega_1 \times \Omega_2 \to [0, \infty]\) be non-negative and \((\mathcal{F}_1 \otimes \mathcal{F}_2)\)-measurable.

  1. Truncation Sequence: Define \(f_n \triangleq \min\{f, n\}\). Since \(f\) is \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable as a map into \([0,\infty]\) and \(x \mapsto \min\{x,n\}\) is Borel, \(f_n\) is non-negative, bounded and \((\mathcal{F}_1 \otimes \mathcal{F}_2)\)-measurable, hence real-valued and in \(\mathbb{B}(\Omega_1\times\Omega_2,\mathcal{F}_1\otimes\mathcal{F}_2,\mathbb{R})\). By the conclusion of Step 2, \(f_n \in \mathbb{H}\) for all \(n \in \mathbb{N}\), and \(f_n \uparrow f\) pointwise.
  2. Slice Measurability: For fixed \(\omega_2\), \(f_n(\cdot, \omega_2) \uparrow f(\cdot, \omega_2)\) pointwise, and each \(f_n(\cdot,\omega_2)\) is \(\mathcal{F}_1\)-measurable by property (1) of \(\mathbb{H}\). As a pointwise limit of measurable functions, \(\omega_1 \mapsto f(\omega_1, \omega_2)\) is \(\mathcal{F}_1\)-measurable (as a map into \([0,\infty]\)). Symmetrically for the other coordinate.
  3. Monotone Convergence Theorem: Fix \(\omega_1\). Since \(0 \le f_n(\omega_1,\cdot) \uparrow f(\omega_1,\cdot)\), MCT on \(\Omega_2\) gives: \[ I_{2, n}(\omega_1) \triangleq \int_{\Omega_2} f_n(\omega_1, \omega_2) \, d\mu_2 \uparrow \int_{\Omega_2} f(\omega_1, \omega_2) \, d\mu_2 \triangleq I_2(\omega_1) \] Since each \(I_{2, n}\) is \(\mathcal{F}_1\)-measurable by property (2) of \(\mathbb{H}\), the pointwise limit \(I_2\) is \(\mathcal{F}_1\)-measurable (possibly \([0,\infty]\)-valued). Symmetrically for the other order.
  4. Iterated Integrals: Since \(0 \le I_{2,n} \uparrow I_2\), applying MCT a second time on \(\Omega_1\): \[ \int_{\Omega_1} \left( \int_{\Omega_2} f_n \, d\mu_2 \right) d\mu_1 \uparrow \int_{\Omega_1} \left( \int_{\Omega_2} f \, d\mu_2 \right) d\mu_1 \] and symmetrically for the reversed order. Since the two iterated integrals agree for each \(f_n\) by property (3) of \(\mathbb{H}\), and both sides converge in \([0,\infty]\), taking \(n \to \infty\) establishes equality of the iterated integrals for \(f\).

30.4.4 Step 4: Extension to \(\sigma\)-finite Measures

The preceding three steps establish the theorem under \(\mu_1(\Omega_1) < \infty\) and \(\mu_2(\Omega_2) < \infty\). We now extend to the general \(\sigma\)-finite case.

Since \(\mu_1\) and \(\mu_2\) are \(\sigma\)-finite, choose increasing sequences \(A_k \nearrow \Omega_1\) in \(\mathcal{F}_1\) and \(B_k \nearrow \Omega_2\) in \(\mathcal{F}_2\) with \(\mu_1(A_k) < \infty\) and \(\mu_2(B_k) < \infty\) for all \(k \in \mathbb{N}\). (If \(\Omega_i = \bigcup_m C^{(i)}_m\) with \(\mu_i(C^{(i)}_m)<\infty\), replace \(C^{(i)}_m\) by \(\bigcup_{l \le m} C^{(i)}_l\), which is still of finite measure by finite subadditivity.)

Rather than passing to trace \(\sigma\)-algebras on \(A_k\) and \(B_k\), we truncate the measures on the original spaces. For \(k \in \mathbb{N}\) define \[ \mu_1^{(k)}(E) \triangleq \mu_1(E \cap A_k) \ \ (E \in \mathcal{F}_1), \qquad \mu_2^{(k)}(F) \triangleq \mu_2(F \cap B_k) \ \ (F \in \mathcal{F}_2). \] These are measures on \((\Omega_1,\mathcal{F}_1)\) and \((\Omega_2,\mathcal{F}_2)\) (countable additivity is inherited from \(\mu_i\)), and they are finite: \(\mu_1^{(k)}(\Omega_1) = \mu_1(A_k) < \infty\) and \(\mu_2^{(k)}(\Omega_2) = \mu_2(B_k) < \infty\). Moreover, for every non-negative \(\mathcal{F}_1\)-measurable \(g_1\) and every non-negative \(\mathcal{F}_2\)-measurable \(g_2\), \[ \int_{\Omega_1} g_1 \, d\mu_1^{(k)} = \int_{\Omega_1} g_1 \, \mathbf{1}_{A_k} \, d\mu_1, \qquad \int_{\Omega_2} g_2 \, d\mu_2^{(k)} = \int_{\Omega_2} g_2 \, \mathbf{1}_{B_k} \, d\mu_2, \tag{30.7}\] which holds for indicators by definition of \(\mu_i^{(k)}\), extends to non-negative simple functions by linearity, and to all non-negative measurable functions by MCT.

  1. Part 1 needs no assumption on the measures. Apply Steps 1–3 with the (finite) zero measures \(\mu_1 \equiv 0\) and \(\mu_2 \equiv 0\) on \((\Omega_1,\mathcal{F}_1)\) and \((\Omega_2,\mathcal{F}_2)\): properties (2) and (3) in the definition of \(\mathbb{H}\) then hold trivially, while property (1) does not involve the measures at all. Steps 1–3 therefore yield that every non-negative \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable \(f\) has \(\mathcal{F}_1\)-measurable and \(\mathcal{F}_2\)-measurable slices, for arbitrary measurable spaces \((\Omega_1,\mathcal{F}_1)\) and \((\Omega_2,\mathcal{F}_2)\). This proves part 1 of the theorem in full generality.

  2. Finite-measure case applies to the truncated measures. Fix \(k\) and let \(f \ge 0\) be \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable. Applying Steps 1–3 to the finite measure spaces \((\Omega_1,\mathcal{F}_1,\mu_1^{(k)})\) and \((\Omega_2,\mathcal{F}_2,\mu_2^{(k)})\) and to \(f\) itself gives that \[ \omega_1 \longmapsto \int_{\Omega_2} f(\omega_1,\omega_2)\, \mu_2^{(k)}(d\omega_2) = \int_{\Omega_2} f(\omega_1,\omega_2)\,\mathbf{1}_{B_k}(\omega_2)\, \mu_2(d\omega_2) \] (the equality being Equation 30.7) is \(\mathcal{F}_1\)-measurable on all of \(\Omega_1\), and that \[ \int_{\Omega_1}\!\!\int_{\Omega_2} f \, d\mu_2^{(k)} \, d\mu_1^{(k)} = \int_{\Omega_2}\!\!\int_{\Omega_1} f \, d\mu_1^{(k)} \, d\mu_2^{(k)}. \] Using Equation 30.7 twice on each side, and writing \(f_k \triangleq f \cdot \mathbf{1}_{A_k \times B_k}\) (so that \(f\,\mathbf{1}_{B_k}(\omega_2)\,\mathbf{1}_{A_k}(\omega_1) = f_k\)), this reads \[ \int_{\Omega_1} \int_{\Omega_2} f_k \, d\mu_2 \, d\mu_1 = \int_{\Omega_2} \int_{\Omega_1} f_k \, d\mu_1 \, d\mu_2, \] and \(\omega_1 \mapsto \int_{\Omega_2} f_k(\omega_1,\omega_2)\,d\mu_2 = \mathbf{1}_{A_k}(\omega_1)\int_{\Omega_2} f(\omega_1,\omega_2)\mathbf{1}_{B_k}(\omega_2)\,d\mu_2\) is \(\mathcal{F}_1\)-measurable.

  3. Monotone limit recovers \(f\): Because \(A_k\) and \(B_k\) are increasing, \(A_k \times B_k \nearrow \Omega_1\times\Omega_2\), so the single-indexed sequence \(f_k = f\cdot\mathbf{1}_{A_k\times B_k}\) satisfies \(0 \le f_k \uparrow f\) pointwise. By MCT applied to the inner integral, for every \(\omega_1\), \[ \int_{\Omega_2} f_k(\omega_1, \omega_2) \, d\mu_2 \uparrow \int_{\Omega_2} f(\omega_1, \omega_2) \, d\mu_2. \] Hence \(\omega_1 \mapsto \int_{\Omega_2} f(\omega_1, \omega_2) \, d\mu_2\) is \(\mathcal{F}_1\)-measurable as the pointwise limit of the \(\mathcal{F}_1\)-measurable functions from item 2, proving part 2 (symmetrically in the other coordinate).

  4. Equality of iterated integrals: By item 3 the inner integrals increase, \(\int_{\Omega_2} f_k(\omega_1,\cdot)\,d\mu_2 \uparrow \int_{\Omega_2} f(\omega_1,\cdot)\,d\mu_2\) for every \(\omega_1\), so MCT applied to the outer integral gives \[ \int_{\Omega_1} \int_{\Omega_2} f_{k} \, d\mu_2 \, d\mu_1 \uparrow \int_{\Omega_1} \int_{\Omega_2} f \, d\mu_2 \, d\mu_1, \] and by symmetry the same limit holds for the reversed order. Since the two sides are equal at each stage \(k\) by item 2, and both converge in \([0,\infty]\), they are equal in the limit. This proves part 3 and completes the proof.

30.5 Construction and Uniqueness of Product Measure

Corollary 30.1 (Existence and Uniqueness of the Product Measure) Let \((\Omega_1, \mathcal{F}_1, \mu_1)\) and \((\Omega_2, \mathcal{F}_2, \mu_2)\) be \(\sigma\)-finite measure spaces.

  1. Existence and uniqueness. There exists exactly one measure \(\mu_1 \otimes \mu_2\) on \(\mathcal{F}_1 \otimes \mathcal{F}_2\) satisfying \[ (\mu_1 \otimes \mu_2)(E_1 \times E_2) = \mu_1(E_1)\, \mu_2(E_2), \tag{30.8}\] for all \(E_1 \in \mathcal{F}_1,\ E_2 \in \mathcal{F}_2\) with the convention \(0\cdot\infty = 0\). Moreover \(\mu_1\otimes\mu_2\) is \(\sigma\)-finite.

  2. Representation by iterated integrals. For every \(E \in \mathcal{F}_1 \otimes \mathcal{F}_2\), \[ \begin{aligned} (\mu_1 \otimes \mu_2)(E) &= \int_{\Omega_1} \left( \int_{\Omega_2} \mathbf{1}_E(\omega_1, \omega_2) \, \mu_2(d\omega_2) \right) \mu_1(d\omega_1) \\ &= \int_{\Omega_2} \left( \int_{\Omega_1} \mathbf{1}_E(\omega_1, \omega_2) \, \mu_1(d\omega_1) \right) \mu_2(d\omega_2). \end{aligned} \tag{30.9}\]

Proof (Proof of Corollary 30.1). For every \(E \in \mathcal{F}_1 \otimes \mathcal{F}_2\) the function \(\mathbf{1}_E\) is non-negative and \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable, so by Theorem 30.1 (parts 1 and 2) the inner integral \(\omega_1 \mapsto \int_{\Omega_2} \mathbf{1}_E(\omega_1, \omega_2)\,d\mu_2\) is well defined for every \(\omega_1\) and \(\mathcal{F}_1\)-measurable. Hence the following definition is well-posed. Define: \[ (\mu_1 \otimes \mu_2)(E) \triangleq \int_{\Omega_1} \left( \int_{\Omega_2} \mathbf{1}_E(\omega_1, \omega_2) \, d\mu_2 \right) d\mu_1. \]

  1. Non-negativity and empty set: Since \(\mathbf{1}_E \ge 0\), we have \((\mu_1 \otimes \mu_2)(E) \ge 0\). Setting \(E = \emptyset\) gives \(\mathbf{1}_\emptyset = 0\), so \((\mu_1 \otimes \mu_2)(\emptyset) = 0\).

  2. Countable Additivity: Let \(E = \bigcup_{k=1}^\infty E_k\) with pairwise disjoint \(E_k \in \mathcal{F}_1 \otimes \mathcal{F}_2\). Disjointness gives \(\mathbf{1}_E = \sum_{k=1}^\infty \mathbf{1}_{E_k}\) pointwise, and the partial sums \(S_N \triangleq \sum_{k \le N}\mathbf{1}_{E_k}\) satisfy \(0 \le S_N \uparrow \mathbf{1}_E\). Fix \(\omega_1\); by MCT on \(\Omega_2\) together with finite additivity of the integral, \[ \begin{aligned} \int_{\Omega_2} \mathbf{1}_E(\omega_1, \omega_2) \, d\mu_2 &= \lim_{N\to\infty}\sum_{k=1}^{N} \int_{\Omega_2} \mathbf{1}_{E_k}(\omega_1, \omega_2) \, d\mu_2 \\ &= \sum_{k=1}^\infty \int_{\Omega_2} \mathbf{1}_{E_k}(\omega_1, \omega_2) \, d\mu_2 . \end{aligned} \] The partial sums of the right-hand side increase in \(N\), so applying MCT again on \(\Omega_1\) (and finite additivity there) gives \((\mu_1 \otimes \mu_2)(E) = \sum_{k=1}^\infty (\mu_1 \otimes \mu_2)(E_k)\). Hence \(\mu_1\otimes\mu_2\) is a measure on \(\mathcal{F}_1\otimes\mathcal{F}_2\).

  3. Rectangle Value: For \(E = E_1 \times E_2\) we have \(\mathbf{1}_{E_1\times E_2}(\omega_1,\omega_2) = \mathbf{1}_{E_1}(\omega_1)\mathbf{1}_{E_2}(\omega_2)\), so the inner integral evaluates as \(\int_{\Omega_2} \mathbf{1}_{E_1}(\omega_1)\mathbf{1}_{E_2}(\omega_2)\,d\mu_2 = \mathbf{1}_{E_1}(\omega_1)\,\mu_2(E_2)\) (with \(0\cdot\infty = 0\) when \(\omega_1 \notin E_1\) and \(\mu_2(E_2)=\infty\)). Integrating over \(\Omega_1\): \[ (\mu_1 \otimes \mu_2)(E_1 \times E_2) = \int_{\Omega_1} \mathbf{1}_{E_1}(\omega_1) \mu_2(E_2) \, d\mu_1 = \mu_1(E_1) \mu_2(E_2), \] which is Equation 30.8. The equality of the two iterated integrals in Equation 30.9 is Theorem 30.1 part 3 applied to \(f = \mathbf{1}_E\), which is non-negative and \((\mathcal{F}_1\otimes\mathcal{F}_2)\)-measurable.

  4. \(\sigma\)-finiteness of \(\mu_1\otimes\mu_2\) and uniqueness: The collection \[ \mathcal{P} \triangleq \{E_1 \times E_2 \mid E_1 \in \mathcal{F}_1,\, E_2 \in \mathcal{F}_2\} \] is a \(\pi\)-system, since \((E_1 \times E_2) \cap (F_1 \times F_2) = (E_1 \cap F_1) \times (E_2 \cap F_2) \in \mathcal{P}\), and \(\sigma(\mathcal{P}) = \mathcal{F}_1\otimes\mathcal{F}_2\) by Definition 30.1.

    By \(\sigma\)-finiteness we may choose increasing sequences \(A_m \nearrow \Omega_1\) and \(B_m \nearrow \Omega_2\) with \(\mu_1(A_m)<\infty\) and \(\mu_2(B_m)<\infty\) (replace a given countable cover by the unions of its initial segments). Put \[ S_m \triangleq A_m \times B_m \in \mathcal{P}. \] Then \(S_m \nearrow \Omega_1\times\Omega_2\) and, by item 3, \((\mu_1\otimes\mu_2)(S_m) = \mu_1(A_m)\mu_2(B_m) < \infty\); in particular \(\mu_1\otimes\mu_2\) is \(\sigma\)-finite.

    Now let \(\nu\) be any measure on \(\mathcal{F}_1\otimes\mathcal{F}_2\) satisfying Equation 30.8. Then \(\nu\) agrees with \(\mu_1\otimes\mu_2\) on \(\mathcal{P}\), and \(\nu(S_m) = \mu_1(A_m)\mu_2(B_m) < \infty\) with \(S_m \in \mathcal{P}\), \(S_m \nearrow \Omega_1\times\Omega_2\). By the uniqueness theorem for measures (Dynkin’s \(\pi\)-\(\lambda\) theorem applied to \(\mathcal{L}_m \triangleq \{E \in \mathcal{F}_1\otimes\mathcal{F}_2 \mid \nu(E\cap S_m) = (\mu_1\otimes\mu_2)(E \cap S_m)\}\), which is a \(\lambda\)-system containing \(\mathcal{P}\), followed by continuity from below as \(m \to \infty\)), \(\nu = \mu_1\otimes\mu_2\) on \(\sigma(\mathcal{P}) = \mathcal{F}_1\otimes\mathcal{F}_2\). See also Lemma 32.1.

30.6 Takeaways

  1. The product \(\sigma\)-algebra is generated by measurable rectangles in finite products and by finite-coordinate cylinder sets in arbitrary products. It is the smallest \(\sigma\)-algebra making all coordinate projections measurable.
  2. In an uncountable product, product-measurable sets depend on at most countably many coordinates; unrestricted products need not be product measurable. This is why the definition uses cylinders.
  3. A map into a product space is measurable exactly when each of its coordinate maps is measurable. In particular, tensor products of measurable functions are measurable on the product space.
  4. For a product-measurable set or non-negative product-measurable function, its coordinate sections are measurable. Under \(\sigma\)-finite measures, integrating a non-negative function over either coordinate produces a measurable function, and the two iterated integrals agree.
  5. The product measure \(\mu_1 \otimes \mu_2\) is the unique \(\sigma\)-finite measure on \(\mathcal{F}_1 \otimes \mathcal{F}_2\) satisfying \[ (\mu_1 \otimes \mu_2)(E_1 \times E_2) = \mu_1(E_1)\mu_2(E_2). \] It can equivalently be computed by integrating the indicator of a measurable set in either order.
