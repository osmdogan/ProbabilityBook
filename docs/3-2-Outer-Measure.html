7  Lecture 3.2: Outer Measure

Historically, the extension result for premeasures is associated primarily with Constantin Carathéodory and his development of the outer-measure construction. Starting from a premeasure on an algebra of sets, Carathéodory’s method constructs an outer measure and then identifies a \(\sigma\)-algebra of measurable sets on which the outer measure becomes a measure extending the original premeasure. The corresponding Carathéodory Extension Theorem is now a fundamental result in measure theory; under a suitable \(\sigma\)-finiteness condition, the extension is also unique.

7.1 The Measure Extension Problem

Let \((\Omega, \mathcal{A}, \mu)\) be a premeasure space, where \(\mathcal{A}\) is a field over \(\Omega\) and \(\mu: \mathcal{A} \to [0, \infty]\) is a countably additive set function (a premeasure).

Our goal is to extend \(\mu\) to a genuine measure \(\bar{\mu}\) defined on the generated \(\sigma\)-algebra \(\sigma(\mathcal{A})\). Specifically, we seek a \(\sigma\)-algebra \(\mathcal{F}\) over \(\Omega\) with \(\sigma(\mathcal{A}) \subseteq \mathcal{F} \subseteq 2^\Omega\) and a measure \(\bar{\mu}: \mathcal{F} \to [0, \infty]\) such that: \[ \bar{\mu}\vert{}_{\mathcal{A}} = \mu. \tag{7.1}\]

Theorem 7.1 (Fréchet Extension Theorem (1924)) Every premeasure \((\Omega, \mathcal{A}, \mu)\) extends to a measure on \(\sigma(\mathcal{A})\). The extension \(\bar{\mu}\) is unique if the premeasure \(\mu\) is \(\sigma\)-finite on \(\mathcal{A}\); that is, if there exists a sequence \(\{A_j\}_{j=1}^\infty \subseteq \mathcal{A}\) such that \[ \Omega = \bigcup_{j=1}^\infty A_j \quad \text{and} \quad \mu(A_j) < \infty \quad \text{for all } j \in \mathbb{N}. \tag{7.2}\]

7.2 Counterexample: Non-Uniqueness of Measure Extensions

If \(\mu\) is not \(\sigma\)-finite, the extension to \(\sigma(\mathcal{A})\) need not be unique.

Consider \(\Omega = \mathbb{R}\) and let \(\mathcal{A} = \mathcal{B}_{\text{el}}(\mathbb{R})\) be the elementary field generated by half-open intervals. Define the premeasure \(\mu: \mathcal{A} \to [0, \infty]\) by: \[ \mu(A) = \begin{cases} 0 & \text{if } A = \emptyset, \\ \infty & \text{if } A \neq \emptyset. \end{cases} \tag{7.3}\]

We can extend \(\mu\) to \(\sigma(\mathcal{A}) = \mathcal{B}(\mathbb{R})\) in multiple ways:

  1. First extension (\(\bar{\mu}\)): Define \(\bar{\mu}(A) = \infty\) for all non-empty \(A \in \mathcal{B}(\mathbb{R})\), with \(\bar{\mu}(\emptyset) = 0\). This is a valid measure on \(\mathcal{B}(\mathbb{R})\) extending \(\mu\).
  2. Second extension (\(\tilde{\mu}\)): Define \(\tilde{\mu}\) as the counting measure on \(\mathcal{B}(\mathbb{R})\): \[ \tilde{\mu}(A) = \# A. \tag{7.4}\] For any non-empty interval \((a, b] \in \mathcal{A}\), \(\#(a, b] = \infty\), so \(\tilde{\mu}(A) = \mu(A) = \infty\) for all non-empty \(A \in \mathcal{A}\), and \(\tilde{\mu}(\emptyset) = 0\).

Both \(\bar{\mu}\) and \(\tilde{\mu}\) are valid measures on \(\mathcal{B}(\mathbb{R})\) extending \(\mu\), but \(\bar{\mu} \neq \tilde{\mu}\) (for instance, on singletons \(\{x\} \in \mathcal{B}(\mathbb{R})\), \(\bar{\mu}(\{x\}) = \infty\) whereas \(\tilde{\mu}(\{x\}) = 1\)).

7.3 Carathéodory Outer Measure Construction

We now describe Carathéodory’s method for constructing an outer measure from a premeasure. This construction is fundamental in measure theory and provides a systematic way to extend premeasures to measures on \(\sigma\)-algebras. It has the following features:

  1. It is defined on all subsets of \(\Omega\) (\(2^\Omega\)), not just on the algebra \(\mathcal{A}\).
  2. It assigns zero to the empty set and is monotone and countably subadditive.

Definition 7.1 (Outer Measure) Let \(\Omega\) be a non-empty set. A function \(\mu^*: 2^\Omega \to [0, \infty]\) is called an outer measure if it satisfies the following three conditions:

  1. Empty Set: \(\mu^*(\emptyset) = 0\).
  2. Monotonicity: If \(A \subseteq B \subseteq \Omega\), then \(\mu^*(A) \le \mu^*(B)\).
  3. Countable Subadditivity: For any sequence of sets \(\{A_n\}_{n=1}^\infty \subseteq 2^\Omega\), \[ \mu^*\left(\bigcup_{n=1}^\infty A_n\right) \le \sum_{n=1}^\infty \mu^*(A_n). \tag{7.5}\]

To construct an outer measure from a set function defined on a collection of subsets \(\mathcal{E} \subseteq 2^\Omega\), we use Carathéodory’s method.

Definition 7.2 (Carathéodory Outer Measure Induced by a Set Function) Let \(\mathcal{E} \subseteq 2^\Omega\) be a collection of subsets containing \(\emptyset\) and \(\Omega\), and let \(\rho: \mathcal{E} \to [0, \infty]\) be a set function with \(\rho(\emptyset) = 0\). The outer measure induced by \(\rho\), denoted \(\rho^*: 2^\Omega \to [0, \infty]\), is defined for any \(A \subseteq \Omega\) by: \[ \rho^*(A) := \inf \left\{ \sum_{j=1}^\infty \rho(E_j) : E_j \in \mathcal{E} \text{ for all } j \ge 1 \text{ and } A \subseteq \bigcup_{j=1}^\infty E_j \right\}. \tag{7.6}\]

Proposition 7.1 (Outer Measure Properties of \(\rho^*\)) For any collection \(\mathcal{E} \subseteq 2^\Omega\) containing \(\emptyset\) and \(\Omega\) and any set function \(\rho: \mathcal{E} \to [0, \infty]\) with \(\rho(\emptyset) = 0\), the induced function \(\rho^*: 2^\Omega \to [0, \infty]\) is a valid outer measure on \(2^\Omega\).

Proof (Proof of Proposition 7.1). We verify the three defining properties of an outer measure:

  1. Empty set: Since \(\emptyset \subseteq \bigcup_{j=1}^\infty \emptyset\) with \(\emptyset \in \mathcal{E}\), we have \(0 \le \rho^*(\emptyset) \le \sum_{j=1}^\infty \rho(\emptyset) = 0\), so \(\rho^*(\emptyset) = 0\).

  2. Monotonicity: Let \(A \subseteq B \subseteq \Omega\). If \(\{E_j\}_{j=1}^\infty \subseteq \mathcal{E}\) is a countable cover for \(B\) (i.e., \(B \subseteq \bigcup_{j=1}^\infty E_j\)), then \(A \subseteq \bigcup_{j=1}^\infty E_j\). Thus, any cover of \(B\) by elements of \(\mathcal{E}\) is also a valid cover of \(A\). Taking the infimum over all such covers yields \(\rho^*(A) \le \rho^*(B)\).

  3. Countable subadditivity: Let \(\{A_n\}_{n=1}^\infty \subseteq 2^\Omega\). If \(\rho^*(A_n) = \infty\) for some \(n\), then the inequality \(\rho^*(\bigcup_{n=1}^\infty A_n) \le \sum_{n=1}^\infty \rho^*(A_n)\) holds trivially. Assume \(\rho^*(A_n) < \infty\) for all \(n \in \mathbb{N}\).

    Fix \(\epsilon > 0\). By the definition of infimum, for each \(n \in \mathbb{N}\), there exists a countable cover \(\{E_j^n\}_{j=1}^\infty \subseteq \mathcal{E}\) such that \(A_n \subseteq \bigcup_{j=1}^\infty E_j^n\) and: \[ \sum_{j=1}^\infty \rho(E_j^n) \le \rho^*(A_n) + \frac{\epsilon}{2^n}. \tag{7.7}\]

    Notice that \(\bigcup_{n=1}^\infty A_n \subseteq \bigcup_{n=1}^\infty \bigcup_{j=1}^\infty E_j^n\). Since \(\{E_j^n\}_{n,j=1}^\infty\) is a countable collection of sets in \(\mathcal{E}\) covering \(\bigcup_{n=1}^\infty A_n\), definition Equation 7.6 implies: \[ \rho^*\left(\bigcup_{n=1}^\infty A_n\right) \le \sum_{n=1}^\infty \sum_{j=1}^\infty \rho(E_j^n) \le \sum_{n=1}^\infty \left( \rho^*(A_n) + \frac{\epsilon}{2^n} \right) = \sum_{n=1}^\infty \rho^*(A_n) + \epsilon. \] Since \(\epsilon > 0\) was arbitrary, letting \(\epsilon \downarrow 0\) yields: \[ \rho^*\left(\bigcup_{n=1}^\infty A_n\right) \le \sum_{n=1}^\infty \rho^*(A_n). \] Thus, \(\rho^*\) is an outer measure.

7.4 Properties of Outer Measures and Premeasure Extensions

Carathéodory’s outer measure construction provides a theoretical tool to distinguish premeasures from purely finitely-additive measures.

Lemma 7.1 (Outer Measure Minimal Extension Property) Let \((\Omega, \mathcal{A}, \mu)\) be a premeasure space, and let \((\Omega, \sigma(\mathcal{A}), \nu)\) be any measure space extending \(\mu\) (i.e., \(\nu(A) = \mu(A)\) for all \(A \in \mathcal{A}\)). Then \(\nu\) is bounded above by the induced outer measure \(\mu^*\) on \(\sigma(\mathcal{A})\): \[ \nu(B) \le \mu^*(B) \quad \text{for all } B \in \sigma(\mathcal{A}). \tag{7.8}\]

Proof (Proof of Lemma 7.1). Fix \(B \in \sigma(\mathcal{A})\). Let \(\{E_n\}_{n=1}^\infty \subseteq \mathcal{A}\) be any countable cover of \(B\), so \(B \subseteq \bigcup_{n=1}^\infty E_n\). Since \(\nu\) is a measure on \(\sigma(\mathcal{A})\), it is countably subadditive. Furthermore, because \(\nu\vert{}_{ \mathcal{A}} = \mu\), we have: \[ \nu(B) \le \nu\left(\bigcup_{n=1}^\infty E_n\right) \le \sum_{n=1}^\infty \nu(E_n) = \sum_{n=1}^\infty \mu(E_n). \]

Taking the infimum over all countable covers \(\{E_n\}_{n=1}^\infty \subseteq \mathcal{A}\) of \(B\) gives: \[ \nu(B) \le \inf \left\{ \sum_{n=1}^\infty \mu(E_n) : E_n \in \mathcal{A}, \, B \subseteq \bigcup_{n=1}^\infty E_n \right\} = \mu^*(B). \]

Proposition 7.2 (Premeasure Characterization via Outer Measure) Let \((\Omega, \mathcal{A}, \mu)\) be a finitely-additive measure space. Let \(\mu^*: 2^\Omega \to [0, \infty]\) be the outer measure induced by \(\mu\) on \(\mathcal{A}\).

  1. \(\mu^* \le \mu\) on \(\mathcal{A}\).
  2. \(\mu^* = \mu\) on \(\mathcal{A}\) if and only if \(\mu\) is a premeasure (countably additive) on \(\mathcal{A}\).

Proof (Proof of Proposition 7.2). Part 1 (\(\mu^* \le \mu\) on \(\mathcal{A}\)): Let \(A \in \mathcal{A}\). We can cover \(A\) using the sequence \(E_1 = A\) and \(E_n = \emptyset\) for \(n \ge 2\), where \(E_n \in \mathcal{A}\) for all \(n\). Since \(A \subseteq \bigcup_{n=1}^\infty E_n\), the definition of infimum implies: \[ \mu^*(A) \le \mu(A) + \sum_{n=2}^\infty \mu(\emptyset) = \mu(A) + 0 = \mu(A). \]

Part 2 (\(\Leftarrow\): Assume \(\mu\) is a premeasure): Let \(A \in \mathcal{A}\). Let \(\{A_n\}_{n=1}^\infty \subseteq \mathcal{A}\) be any countable cover of \(A\), i.e., \(A \subseteq \bigcup_{n=1}^\infty A_n\).

Define \(B_n := A_n \cap A \in \mathcal{A}\) for each \(n \in \mathbb{N}\), so \(A = \bigcup_{n=1}^\infty B_n\). Disjointify \(\{B_n\}\) by setting: \[ \tilde{B}_1 := B_1, \quad \text{and} \quad \tilde{B}_n := B_n \setminus \left( \bigcup_{j=1}^{n-1} B_j \right) \subseteq B_n \quad \text{for } n \ge 2. \] Since \(\mathcal{A}\) is a field, \(\tilde{B}_n \in \mathcal{A}\) for all \(n\), and \(\{\tilde{B}_n\}_{n=1}^\infty\) is a collection of pairwise disjoint sets whose union is \(A = \bigcup_{n=1}^\infty \tilde{B}_n\). Since \(\mu\) is countably additive on \(\mathcal{A}\): \[ \mu(A) = \sum_{n=1}^\infty \mu(\tilde{B}_n). \] Using monotonicity of finitely-additive measures (\(\tilde{B}_n \subseteq B_n \subseteq A_n \implies \mu(\tilde{B}_n) \le \mu(A_n)\)), we get: \[ \mu(A) = \sum_{n=1}^\infty \mu(\tilde{B}_n) \le \sum_{n=1}^\infty \mu(A_n). \] Taking the infimum over all countable covers \(\{A_n\}_{n=1}^\infty \subseteq \mathcal{A}\) of \(A\) yields \(\mu(A) \le \mu^*(A)\). Combining this with Part 1 gives \(\mu^*(A) = \mu(A)\) for all \(A \in \mathcal{A}\).

Part 2 (\(\Rightarrow\): Assume \(\mu^* = \mu\) on \(\mathcal{A}\)): Let \(\{A_n\}_{n=1}^\infty \subseteq \mathcal{A}\) be a sequence of pairwise disjoint sets in \(\mathcal{A}\) such that \(A := \bigcup_{n=1}^\infty A_n \in \mathcal{A}\).

Since \(\mu^*\) is an outer measure (hence countably subadditive) and \(\mu^* = \mu\) on \(\mathcal{A}\), we have: \[ \mu(A) = \mu^*(A) = \mu^*\left(\bigcup_{n=1}^\infty A_n\right) \le \sum_{n=1}^\infty \mu^*(A_n) = \sum_{n=1}^\infty \mu(A_n). \] On the other hand, for any finite \(N \in \mathbb{N}\), since \(\{A_n\}_{n=1}^N \subseteq \mathcal{A}\) are disjoint and \(\bigcup_{n=1}^N A_n \subseteq A\), finite additivity and monotonicity yield: \[ \sum_{n=1}^N \mu(A_n) = \mu\left(\bigcup_{n=1}^N A_n\right) \le \mu(A). \] Taking the limit as \(N \to \infty\) gives: \[ \sum_{n=1}^\infty \mu(A_n) \le \mu(A). \]

Combining both inequalities yields \(\mu(A) = \sum_{n=1}^\infty \mu(A_n)\), proving that \(\mu\) is countably additive (a premeasure) on \(\mathcal{A}\). \(\blacksquare\)
