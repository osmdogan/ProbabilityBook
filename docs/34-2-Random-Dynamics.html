75  Lecture 34.2: Random Dynamics

75.1 Motivation: Dynamical Systems

Dynamical systems can generally be classified into two broad (and often interwoven) categories: discrete-time and continuous-time systems.

75.2 Discrete Dynamics

Let \(S\) be a state space and let \(x_0 \in S\) be an initial state. Consider a function \(f: S \to S\). We study the asymptotic and qualitative behavior of the deterministic sequence \(\{x_n\}_{n \ge 0}\) defined recursively by: \[ x_{n+1} = f(x_n), \quad n \ge 0. \tag{75.1}\]

75.3 Continuous Dynamics

Let \(S\) be a state space (typically \(S \subseteq \mathbb{R}^d\) or a smooth manifold \(M\)) and let \(x_0 \in S\). Let \(f: S \to T S\) be a vector field on \(S\). We study the behavior of the continuous trajectory \(x(t)\) governed by the differential equation: \[ \frac{\mathrm{d}x(t)}{\mathrm{d}t} = f(x(t)), \quad t \ge 0, \quad x(0) = x_0. \tag{75.2}\]

In both deterministic settings, if the initial state \(x_0\) and the evolution function \(f\) are known with perfect precision, the full trajectory of the system is uniquely determined for all time.

However, in realistic physical, economic, or biological modeling, systems are subject to ambient noise, random environmental fluctuations, or measurement errors. To incorporate these effects, we consider dynamical systems driven by stochastic perturbations.

75.4 A Rigorous Model for Noisy (Discrete) Dynamics

To model noisy discrete dynamics, we wish to iterate state transitions of the form \(x_{n+1} = f_n(x_n)\), where each \(f_n: S \to S\) is a random function. To make this mathematically precise and analytically tractable, we formulate the system within a measure-theoretic framework.

Definition 75.1 (Random Dynamical System / Iterated Function System) Let \((\Omega, \mathcal{F}, \mathbb{P})\) be a probability space. Consider:

  1. A state space \((S, \mathcal{B}_S)\), where \(S\) is a measurable space equipped with its \(\sigma\)-algebra \(\mathcal{B}_S\) (typically a Polish space endowed with its Borel \(\sigma\)-algebra).
  2. A noise state space \((R, \mathcal{G})\), equipped with its \(\sigma\)-algebra \(\mathcal{G}\).
  3. An independent and identically distributed (i.i.d.) sequence of random elements \(\{\xi_n\}_{n \ge 0}\) defined on \((\Omega, \mathcal{F}, \mathbb{P})\) taking values in \((R, \mathcal{G})\), so that \(\xi_n: (\Omega, \mathcal{F}) \to (R, \mathcal{G})\) for all \(n \ge 0\).
  4. A jointly measurable transition map \(f: S \times R \to S\).

Given an initial random variable \(X_0: \Omega \to S\) (measurable with respect to \(\mathcal{B}_S\)) independent of the sequence \(\{\xi_n\}_{n \ge 0}\), the random dynamical system \(\{X_n\}_{n \ge 0}\) is defined recursively by: \[ X_{n+1} = f(X_n, \xi_n), \quad n \ge 0. \tag{75.3}\]

75.5 Unfolding and Measurability Properties

By induction, the random state \(X_n\) at step \(n \ge 1\) can be expressed directly in terms of the initial state \(X_0\) and the sequence of noise variables \(\xi_0, \xi_1, \dots, \xi_{n-1}\).

Let \(F_n: S \times R^n \to S\) be the \(n\)-fold iterated composition maps defined recursively as follows:

  • \(F_1(x, y_0) := f(x, y_0)\),
  • \(F_2(x, y_0, y_1) := f(f(x, y_0), y_1)\),
  • \(F_n(x, y_0, \dots, y_{n-1}) := f(F_{n-1}(x, y_0, \dots, y_{n-2}), y_{n-1})\) for \(n \ge 2\).

By standard measure theory, since \(f\) is jointly measurable, each \(F_n: (S \times R^n, \mathcal{B}_S \otimes \mathcal{G}^{\otimes n}) \to (S, \mathcal{B}_S)\) is a measurable function.

Consequently, for every \(n \ge 1\), we can write: \[ X_n = F_n(X_0, \xi_0, \xi_1, \dots, \xi_{n-1}). \tag{75.4}\]

75.6 Filtration and Markov Property

Let \(\mathcal{F}_n\) denote the natural filtration generated by the state history up to time \(n \ge 0\): \[ \mathcal{F}_n := \sigma(X_0, X_1, \dots, X_n). \tag{75.5}\]

Because each \(X_j = F_j(X_0, \xi_0, \dots, \xi_{j-1})\) is measurable with respect to \(\sigma(X_0, \xi_0, \dots, \xi_{j-1})\) by Equation 75.4, we have \[ \sigma(X_j) \subseteq \sigma(X_0, \xi_0, \dots, \xi_{j-1}) \subseteq \sigma(X_0, \xi_0, \dots, \xi_{n-1}) \] for all \(0 \le j \le n\), and hence \[ \mathcal{F}_n = \sigma(X_0, X_1, \dots, X_n) \subseteq \sigma(X_0, \xi_0, \dots, \xi_{n-1}). \]

Lemma 75.1 (Independence of Future Noise) For every \(n \ge 0\), the random driver \(\xi_n\) is independent of the \(\sigma\)-algebra \(\mathcal{F}_n\).

Proof. By construction, \(\{\xi_k\}_{k \ge 0}\) is an i.i.d. sequence, and \(X_0\) is independent of \(\{\xi_k\}_{k \ge 0}\). Thus, the collection \((X_0, \xi_0, \dots, \xi_{n-1})\) is independent of \(\xi_n\). Since \(\mathcal{F}_n \subseteq \sigma(X_0, \xi_0, \dots, \xi_{n-1})\), it follows directly that \(\xi_n\) is independent of \(\mathcal{F}_n\).

Define \[ \mathcal{B}_b(S, \mathcal{B}_S) := \{g:S \to \mathbb{R} : g \text{ is bounded and } \mathcal{B}_S\text{-measurable}\}. \] When the underlying \(\sigma\)-algebra is clear, we write simply \(\mathcal{B}_b(S)\).

Definition 75.2 (Markov Transition Operator) For any \(x \in S\) and any measurable set \(A \in \mathcal{B}_S\), define \[ Q(x, A) := \mathbb{P}(f(x, \xi_0) \in A). \tag{75.6}\] Because \(f\) is jointly measurable and \(\xi_0\) is a random element, for each fixed \(A \in \mathcal{B}_S\) the map \(x \mapsto Q(x,A)\) is \(\mathcal{B}_S\)-measurable, while for each fixed \(x \in S\), the set function \(A \mapsto Q(x,A)\) is a probability measure on \((S, \mathcal{B}_S)\). Thus \(Q\) is a probability kernel from \((S,\mathcal{B}_S)\) to itself.

For any \(g \in \mathcal{B}_b(S, \mathcal{B}_S)\), define the associated Markov operator \(L: \mathcal{B}_b(S, \mathcal{B}_S) \to \mathcal{B}_b(S, \mathcal{B}_S)\) by: \[ (L g)(x) := \mathbb{E}[g(f(x, \xi_0))] = \int_S g(y) Q(x, \mathrm{d}y). \tag{75.7}\]

Theorem 75.1 (Markov Property) Let \(\{X_n\}_{n \ge 0}\) be the random dynamical system defined by Equation 75.3. Then \(\{X_n\}_{n \ge 0}\) is a time-homogeneous Markov chain with transition kernel \(Q(x, \cdot)\) and Markov operator \(L\).

Specifically, for any \(g \in \mathcal{B}_b(S, \mathcal{B}_S)\) and \(n \ge 0\): \[ \mathbb{E}[g(X_{n+1}) \mid \mathcal{F}_n] = \mathbb{E}[g(X_{n+1}) \mid X_n] = (L g)(X_n) \quad \text{a.s.} \tag{75.8}\]

Proof. Let \(g \in \mathcal{B}_b(S, \mathcal{B}_S)\). By definition of the process: \[ g(X_{n+1}) = g(f(X_n, \xi_n)) = (g \circ f)(X_n, \xi_n). \] Since \(X_n\) is \(\mathcal{F}_n\)-measurable and \(\xi_n\) is independent of \(\mathcal{F}_n\) (by Lemma 75.1), we apply the standard freezing lemma for conditional expectations: if \(Z\) is \(\mathcal{F}\)-measurable and \(Y\) is independent of \(\mathcal{F}\), then for bounded measurable \(\phi\), \[ \mathbb{E}[\phi(Z,Y) \mid \mathcal{F}] = \psi(Z) \quad \text{a.s.}, \qquad \psi(z):=\mathbb{E}[\phi(z,Y)]. \] Here \(Z=X_n\), \(Y=\xi_n\), and \(\phi(z,y) = g(f(z,y))\). Therefore, \[ \mathbb{E}[g(X_{n+1}) \mid \mathcal{F}_n] = h(X_n) \quad \text{a.s.}, \] where \[ h(x) := \mathbb{E}[g(f(x,\xi_n))] = \mathbb{E}[g(f(x,\xi_0))] = (L g)(x), \] using that \(\xi_n \stackrel{d}{=} \xi_0\) because \(\{\xi_k\}\) is i.i.d.

Because \((L g)(X_n)\) is measurable with respect to \(\sigma(X_n) \subseteq \mathcal{F}_n\), taking the conditional expectation with respect to \(\sigma(X_n)\) yields: \[ \mathbb{E}[g(X_{n+1}) \mid X_n] = \mathbb{E}[\mathbb{E}[g(X_{n+1}) \mid \mathcal{F}_n] \mid X_n] = \mathbb{E}[(L g)(X_n) \mid X_n] = (L g)(X_n) \quad \text{a.s.} \] This establishes Equation 75.8.

Taking the expectation on both sides of Equation 75.8, using the law of total expectation, yields: \[ \mathbb{E}[g(X_{n+1})] = \mathbb{E}[(L g)(X_n)]. \tag{75.9}\]

75.7 Iterated Conditional Expectations

Theorem 75.2 (Iterated Conditional Expectation Formula) For any \(n \ge k \ge 0\) and any \(g \in \mathcal{B}_b(S, \mathcal{B}_S)\): \[ \mathbb{E}[g(X_n) \mid \mathcal{F}_k] = \mathbb{E}[g(X_n) \mid X_k] = (L^{n-k} g)(X_k) \quad \text{a.s.} \tag{75.10}\] In particular, setting \(k = 0\): \[ \mathbb{E}[g(X_n) \mid \mathcal{F}_0] = (L^n g)(X_0) \quad \text{a.s.} \]

Proof. We proceed by induction on \(m = n - k \ge 0\).

  1. Base Case (\(m = 0\)): For \(n = k\), \(L^0 = I\) (the identity operator). Thus \(\mathbb{E}[g(X_k) \mid \mathcal{F}_k] = g(X_k) = (L^0 g)(X_k)\) a.s.
  2. Induction Step: Assume the statement holds for \(m = n - k - 1 \ge 0\), i.e., \[ \mathbb{E}[g(X_n) \mid \mathcal{F}_{k+1}] = (L^{n-k-1} g)(X_{k+1}) \quad \text{a.s.} \] Using the tower property of conditional expectation since \(\mathcal{F}_k \subseteq \mathcal{F}_{k+1}\): \[ \begin{aligned} \mathbb{E}[g(X_n) \mid \mathcal{F}_k] &= \mathbb{E}[\mathbb{E}[g(X_n) \mid \mathcal{F}_{k+1}] \mid \mathcal{F}_k] \\ &= \mathbb{E}[(L^{n-k-1} g)(X_{k+1}) \mid \mathcal{F}_k] \quad \text{a.s.} \end{aligned} \] Since \(L^{n-k-1} g \in \mathcal{B}_b(S, \mathcal{B}_S)\), we can apply Theorem 75.1 to the bounded measurable function \(\tilde{g} = L^{n-k-1} g\). This gives: \[ \mathbb{E}[\tilde{g}(X_{k+1}) \mid \mathcal{F}_k] = (L \tilde{g})(X_k) = (L (L^{n-k-1} g))(X_k) = (L^{n-k} g)(X_k) \quad \text{a.s.} \] By mathematical induction, Equation 75.10 holds for all \(n \ge k \ge 0\).

75.8 Takeaways

  1. Random dynamical systems (RDS) / iterated function systems (IFS) formalize noisy discrete dynamics by iterating \(X_{n+1} = f(X_n, \xi_n)\), where \(f: S \times R \to S\) is jointly measurable and \(\{\xi_n\}\) is an i.i.d. noise sequence on \((R, \mathcal{G})\).

  2. Unfolding formula: The state at time \(n\) is a measurable function of the initial condition and the noise history: \[ X_n = F_n(X_0, \xi_0, \dots, \xi_{n-1}), \] so \(\mathcal{F}_n = \sigma(X_0, \dots, X_n) \subseteq \sigma(X_0, \xi_0, \dots, \xi_{n-1})\).

  3. Independence of future noise: Because \(\mathcal{F}_n \subseteq \sigma(X_0, \xi_0, \dots, \xi_{n-1})\) and \(\xi_n\) is independent of \(\sigma(X_0, \xi_0, \dots, \xi_{n-1})\) (by the i.i.d. assumption and independence of \(X_0\)), the future noise \(\xi_n\) is independent of \(\mathcal{F}_n\).

  4. Every RDS is a Markov chain. The one-step transition kernel and operator are: \[ Q(x, A) = \mathbb{P}(f(x, \xi_0) \in A), \qquad (Lg)(x) = \mathbb{E}[g(f(x, \xi_0))] = \int_S g(y)\,Q(x, \mathrm{d}y), \] and the Markov property reads \(\mathbb{E}[g(X_{n+1}) \mid \mathcal{F}_n] = (Lg)(X_n)\) a.s. for all \(g \in \mathcal{B}_b(S)\).

  5. Iterated conditional expectation: For all \(n \ge k \ge 0\) and \(g \in \mathcal{B}_b(S)\), \[ \mathbb{E}[g(X_n) \mid X_k] = (L^{n-k} g)(X_k) \quad \text{a.s.} \] That is, \((n-k)\)-step-ahead predictions are computed by applying the operator \(L\) exactly \(n-k\) times to \(g\) and evaluating at the current state \(X_k\).
