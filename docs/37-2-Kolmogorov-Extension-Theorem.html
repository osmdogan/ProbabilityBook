81  Lecture 37.2: Kolmogorov Extension Theorem

81.1 Introduction and Conceptual Context

In the foundational theory of Markov processes, a process defined on a standard Borel space \((S, \mathcal{B})\) comes equipped with a family of transition operators \(\{Q_{s,t}\}_{s \le t}\) acting on \(\mathcal{B}_b(S, \mathcal{B})\). These operators satisfy the Chapman–Kolmogorov equations: \[ Q_{r,t} = Q_{r,s} Q_{s,t}, \quad Q_{t,t} = \text{Id} \quad \text{for all } r \le s \le t \text{ in } T. \tag{81.1}\]

This setup is directly analogous to the independent and identically distributed (i.i.d.) setting: an i.i.d. sequence \(\{X_n\}_{n \in \mathbb{N}}\) comes with a sequence of joint laws \(\mu_n \in \mathcal{P}(S^n)\) satisfying the multiplicativity property \(\mu_n \otimes \mu_m = \mu_{n+m}\) — a special case of the (weaker, and operative) projective-consistency condition defined in Definition 81.2 below, which only requires compatibility of marginals rather than this full tensor-factorization property.

The fundamental reverse problem asks: given a family of consistent finite-dimensional marginal distributions, can we construct an actual stochastic process on a canonical probability space having these exact joint distributions? For i.i.d. random variables, the existence of such a process on \(S^{\mathbb{N}}\) is established via Kolmogorov’s Extension Theorem. Here, we extend this framework to construct general continuous- or discrete-time Markov processes on product spaces \(S^T\).

81.2 Kolmogorov’s Extension Theorem

Let \((S, \mathcal{B})\) be a standard Borel space (a space homeomorphic to a Borel subset of a complete separable metric space) and let \(T\) be an arbitrary index set (e.g., \(T = \mathbb{R}_+\), \(T = \mathbb{N}\), or an uncountably infinite set).

Definition 81.1 (Canonical Product Space and Cylinder Sets) The product space \(S^T := \{\omega : T \to S\}\) consists of all paths/functions from \(T\) to \(S\). For each \(t \in T\), the coordinate projection map \(\pi_t : S^T \to S\) is defined by: \[ \pi_t(\omega) = \omega(t). \tag{81.2}\]

For a finite subset \(\Lambda = \{t_1, \dots, t_n\} \subseteq T\) (listed in the order induced by \(T\)), the finite-dimensional projection \(\pi_\Lambda : S^T \to S^\Lambda\) is: \[ \pi_\Lambda(\omega) = \big(\omega(t_1), \dots, \omega(t_n)\big), \tag{81.3}\] where we identify \(S^\Lambda\) (functions \(\Lambda \to S\)) with \(S^n\) via this ordering; the product \(\sigma\)-algebra \(\mathcal{B}^{\otimes \Lambda}\) is transported along the same identification. This identification is used silently throughout the rest of this chapter.

The product \(\sigma\)-algebra \(\mathcal{B}^{\otimes T}\) is generated by all individual coordinate projections: \[ \mathcal{B}^{\otimes T} := \sigma(\pi_t : t \in T) = \sigma \left( \bigcup_{\Lambda \subseteq T, \, |\Lambda| < \infty} \sigma(\pi_\Lambda) \right). \tag{81.4}\] (The two expressions on the right agree because \(\sigma(\pi_t) \subseteq \sigma(\pi_\Lambda)\) whenever \(t \in \Lambda\), giving “\(\subseteq\)”; and \(\sigma(\pi_\Lambda) \subseteq \sigma(\pi_t : t \in T)\) for every finite \(\Lambda\), since \(\mathcal{B}^{\otimes\Lambda}\) is generated by rectangles and \(\pi_\Lambda^{-1}(B_1\times\cdots\times B_n) = \bigcap_i \pi_{t_i}^{-1}(B_i)\), giving “\(\supseteq\)”.)

A subset \(A \subseteq S^T\) is called a cylinder set if \(A = \pi_\Lambda^{-1}(B)\) for some finite subset \(\Lambda \subseteq T\) and \(B \in \mathcal{B}^{\otimes \Lambda}\); every cylinder set belongs to \(\mathcal{B}^{\otimes T}\), by the displayed equality above.

Remark 81.1 (Remark on Cylinder Sets). Let \(\Lambda=\{t_1,\ldots,t_n\}\subseteq T\) be a finite set of time points, and define the coordinate map \(\pi_\Lambda:\Omega\to S^\Lambda\) and \(\pi_\Lambda(\omega)=(\omega(t_1),\ldots,\omega(t_n))\). For \(B\in\mathcal B^{\otimes\Lambda}\), a cylinder set is a set of the form \[ A=\pi_\Lambda^{-1}(B) =\{\omega\in\Omega:\pi_\Lambda(\omega)\in B\}. \] In other words, a path belongs to \(A\) if its values at the selected finite set of times satisfy the condition specified by \(B\). The path’s values at all other times are irrelevant to membership in \(A\).

For example, take \(S=\mathbb R\), \(T=[0,\infty)\), and \(\Lambda=\{1,2\}\). Let \(B=\{(x_1,x_2)\in\mathbb R^2:x_1\leq 0,\ x_2>1\}\). The corresponding cylinder set is \(A=\{\omega\in\Omega:\omega(1)\leq 0,\ \omega(2)>1\}\). This set contains every path whose value at time \(1\) is nonpositive and whose value at time \(2\) exceeds \(1\), regardless of what the path does at any other time.

Basic Properties of Cylinder Sets

  1. Every cylinder set is measurable: By definition of the product \(\sigma\)-algebra, \(A=\pi_\Lambda^{-1}(B)\in\mathcal F\). Thus, every cylinder set is an event in the canonical measurable space.

  2. Cylinder sets are closed under finite intersections: Suppose \(A_1=\pi_{\Lambda_1}^{-1}(B_1)\) and \(A_2=\pi_{\Lambda_2}^{-1}(B_2)\). Then \(A_1\cap A_2=\pi_{\Lambda_1\cup\Lambda_2}^{-1}(C)\), where \(C\) imposes both conditions \(B_1\) and \(B_2\) on their respective coordinates. Since \(\Lambda_1\cup\Lambda_2\) is finite, the intersection is again a cylinder set. More generally, a finite intersection of cylinder sets is a cylinder set.

  3. The complement of a cylinder set is a cylinder set: If \(A=\pi_\Lambda^{-1}(B)\), then \(A^c=\pi_\Lambda^{-1}(B^c)\), where \(B^c=S^\Lambda\setminus B\). Hence \(A^c\) is a cylinder set.

  4. Cylinder sets are closed under finite unions: For cylinder sets \(A_1\) and \(A_2\), their union can be represented as a cylinder set based on \(\Lambda_1\cup\Lambda_2\), just as for intersections. Therefore, finite unions of cylinder sets are cylinder sets.

  5. Cylinder sets generate the product \(\sigma\)-algebra: The product \(\sigma\)-algebra is precisely \(\mathcal B^{\otimes T} = \sigma(\mathcal C)\), where \(\mathcal C\) denotes the collection of all cylinder sets. This means that every set in the product \(\sigma\)-algebra can be obtained from cylinder sets by taking countable unions, countable intersections, and complements.

  6. Important: Cylinder sets themselves are generally not closed under countable unions or countable intersections. They form an algebra of sets, not necessarily a \(\sigma\)-algebra.

  7. Cylinder sets depend on finitely many coordinates: If two paths \(\omega,\omega'\in\Omega\) agree on \(\Lambda\), then \(\pi_\Lambda(\omega)=\pi_\Lambda(\omega')\).Consequently, \(\omega\in A\iff\omega'\in A\) for every cylinder set \(A=\pi_\Lambda^{-1}(B)\).

The goal is to construct a probability measure on the entire path space \(S^T\), where a path specifies the process’s values at every time point. We begin by specifying distributions for finite collections of coordinates. But these distributions cannot be chosen independently: they must be compatible. Projective consistency is precisely this compatibility requirement. In short, projective consistency means that reducing a joint distribution to fewer coordinates must give the distribution already specified for those coordinates.

Definition 81.2 (Consistency Condition) A family of probability measures \(\{\mu_\Lambda \in \mathcal{P}(S^\Lambda, \mathcal{B}^{\otimes \Lambda}) : \Lambda \subseteq T, \, |\Lambda| < \infty\}\) is called projectively consistent if, for all finite index sets \(\Lambda' \subseteq \Lambda \subseteq T\), we have: \[ (\pi_{\Lambda' \mid S^\Lambda})^* \mu_\Lambda = \mu_{\Lambda'}, \tag{81.5}\] where \(\pi_{\Lambda' \mid S^\Lambda} : S^\Lambda \to S^{\Lambda'}\) is the natural restriction map between finite Cartesian products, and \(f^*\mu\) denotes the pushforward of a measure \(\mu\) along a measurable map \(f\) (i.e. \((f^*\mu)(B) := \mu(f^{-1}(B))\)); we use this superscript-star convention for pushforwards throughout. Explicitly, for all \(B' \in \mathcal{B}^{\otimes \Lambda'}\): \[ \mu_\Lambda \big( B' \times S^{\Lambda \setminus \Lambda'} \big) = \mu_{\Lambda'}(B'). \tag{81.6}\]

Theorem 81.1 (Kolmogorov’s (Extended) Extension Theorem) Let \((S, \mathcal{B})\) be a standard Borel space and let \(T\) be an arbitrary set. Suppose \(\{\mu_\Lambda\}_{\Lambda \subseteq T, \, |\Lambda| < \infty}\) is a projectively consistent family of probability measures. Then there exists a unique probability measure \(\mathbb{P} \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\) such that: \[ \pi_\Lambda^* \mathbb{P} = \mu_\Lambda \quad \text{for all finite subsets } \Lambda \subseteq T. \tag{81.7}\]

Remark 81.2 (Kolmogorov’s Extension Theorem). The theorem provides the mathematical foundation for constructing a stochastic process from its finite-dimensional distributions.

  • Input: A probability distribution for every finite collection of time points, with all these distributions satisfying projective consistency.
  • Output: A probability measure \(\mathbb P\) on the entire path space \(S^T\) that reproduces every specified finite-dimensional distribution.

The existence part says that the finite-dimensional distributions can be realized jointly on a common path space. The uniqueness part says that there is only one such probability measure on the product \(\sigma\)-algebra.

81.3 Proof Construction

We structure the proof in two main steps: pre-measure construction on an algebra, followed by verification of countable additivity.

81.3.1 Step 1: Definition on the Cylinder Algebra

Define the collection of cylinder sets: \[ \mathcal{A} := \bigcup_{\Lambda \subseteq T, \, |\Lambda| < \infty} \sigma(\pi_\Lambda) = \left\{ \pi_\Lambda^{-1}(B) : \Lambda \subseteq T \text{ finite}, \, B \in \mathcal{B}^{\otimes \Lambda} \right\}. \tag{81.8}\]

We will repeatedly use the following elementary fact. For finite \(\Lambda \subseteq \Lambda' \subseteq T\), write \(p_\Lambda^{\Lambda'} : S^{\Lambda'} \to S^\Lambda\) for the natural restriction map; then \(\pi_\Lambda = p_\Lambda^{\Lambda'} \circ \pi_{\Lambda'}\), so for \(C \subseteq S^\Lambda\), \[ \pi_\Lambda^{-1}(C) = \pi_{\Lambda'}^{-1}\big( (p_\Lambda^{\Lambda'})^{-1}(C) \big). \tag{81.9}\] Moreover, since \(S \ne \emptyset\) (implicit throughout, as each \(\mu_\Lambda\) with \(\Lambda \ne \emptyset\) is a genuine probability measure on \(S^\Lambda\)), every projection \(\pi_\Lambda : S^T \to S^\Lambda\) and every restriction map \(p_\Lambda^{\Lambda'}\) is surjective (any partial assignment extends to \(S^T\), resp. \(S^{\Lambda'}\), by filling in arbitrary values of \(S\) elsewhere). Consequently, for surjective \(f\), \(f^{-1}(C_1) \subseteq f^{-1}(C_2) \iff C_1 \subseteq C_2\) (so in particular \(f^{-1}(C_1)=f^{-1}(C_2) \iff C_1=C_2\), and \(f^{-1}\) commutes with the resulting set operations, including monotone limits). We refer to this as the cylinder-factorization lemma; it is used below to pass between a cylinder set on \(S^T\) and any of its finite-dimensional representations.

Using Equation 81.9 and surjectivity of the restriction maps, \(\mathcal{A}\) is closed under complementation (\((\pi_\Lambda^{-1}(B))^c = \pi_\Lambda^{-1}(B^c)\)) and finite unions (lift two cylinders \(\pi_{\Lambda_1}^{-1}(B_1), \pi_{\Lambda_2}^{-1}(B_2)\) to the common index set \(\Lambda_1 \cup \Lambda_2\) via Equation 81.9, then take the union of the lifted base sets in \(\mathcal{B}^{\otimes(\Lambda_1\cup\Lambda_2)}\)); together with \(S^T \in \mathcal A\), this shows \(\mathcal{A}\) forms a Boolean algebra of subsets of \(S^T\). Also \(\sigma(\mathcal{A}) = \mathcal{B}^{\otimes T}\), by Equation 81.4.

Define a set function \(\mathbb{P} : \mathcal{A} \to [0, 1]\) by setting, for \(A = \pi_\Lambda^{-1}(B)\): \[ \mathbb{P}(A) := \mu_\Lambda(B). \tag{81.10}\]

To verify that \(\mathbb{P}\) is well-defined, suppose \(A \in \mathcal{A}\) has two representations: \(A = \pi_\Lambda^{-1}(B)\) and \(A = \pi_{\Lambda'}^{-1}(B')\). Let \(\Lambda'' = \Lambda \cup \Lambda'\). By Equation 81.9, \(A = \pi_{\Lambda''}^{-1}(B \times S^{\Lambda''\setminus\Lambda}) = \pi_{\Lambda''}^{-1}(B' \times S^{\Lambda''\setminus\Lambda'})\), and surjectivity of \(\pi_{\Lambda''}\) then forces the literal set equality \(B \times S^{\Lambda''\setminus\Lambda} = B' \times S^{\Lambda''\setminus\Lambda'}\) in \(S^{\Lambda''}\) (cylinder-factorization lemma). Hence, by the projective consistency condition Equation 81.6: \[ \mu_\Lambda(B) = \mu_{\Lambda''}(B \times S^{\Lambda'' \setminus \Lambda}) = \mu_{\Lambda''}(B' \times S^{\Lambda'' \setminus \Lambda'}) = \mu_{\Lambda'}(B'), \] where the middle equality now holds because both sides are the \(\mu_{\Lambda''}\)-measure of the same set. Thus, \(\mathbb{P}(A)\) does not depend on the choice of cylinder representation.

Furthermore, \(\mathbb{P}(S^T) = \mu_\Lambda(S^\Lambda) = 1\). Finite additivity follows directly: if \(A_1, \dots, A_n \in \mathcal{A}\) are disjoint cylinder sets, we represent them over a joint index set \(\Lambda = \bigcup_{j=1}^n \Lambda_j\) as \(A_j = \pi_\Lambda^{-1}(B_j')\) (via Equation 81.9) with \(B_j' \in \mathcal{B}^{\otimes \Lambda}\) pairwise disjoint — disjointness of the \(B_j'\) follows from disjointness of the \(A_j\) and surjectivity of \(\pi_\Lambda\), again by the cylinder-factorization lemma. By finite additivity of \(\mu_\Lambda\): \[ \mathbb{P}\left(\bigcup_{j=1}^n A_j\right) = \mu_\Lambda\left(\bigcup_{j=1}^n B_j'\right) = \sum_{j=1}^n \mu_\Lambda(B_j') = \sum_{j=1}^n \mathbb{P}(A_j). \tag{81.11}\]

81.3.2 Step 2: Verification of Countable Additivity

To extend \(\mathbb{P}\) from \(\mathcal{A}\) to \(\mathcal{B}^{\otimes T}\) via the Carathéodory Extension Theorem (Theorem 8.1), it suffices to prove that \(\mathbb{P}\) is countably additive on \(\mathcal{A}\), or equivalently (since \(\mathcal{A}\) is an algebra and \(\mathbb{P}\) is finite with \(\mathbb{P}(S^T)=1\)), that if \(A_n \downarrow \emptyset\) in \(\mathcal{A}\), then \(\mathbb{P}(A_n) \to 0\).

Let \(A_n = \pi_{\Lambda_n}^{-1}(B_n) \in \mathcal{A}\) with \(A_n \downarrow \emptyset\). Each \(A_n\) depends on a finite coordinate set \(\Lambda_n \subseteq T\). Define the countable collection of involved time points: \[ L := \bigcup_{n=1}^\infty \Lambda_n \subseteq T. \tag{81.12}\]

Consider the countable product space \((S^L, \mathcal{B}^{\otimes L})\). Since \(L\) is countable, fix a bijection between \(L\) and \(\mathbb{N}\) (or an initial segment of \(\mathbb{N}\), if \(L\) is finite); under this relabeling, \(\{\mu_\Lambda\}_{\Lambda \subseteq L, \,|\Lambda|<\infty}\) is exactly a projectively consistent family of finite-dimensional measures indexed by initial segments of \(\mathbb{N}\), in the sense of Corollary 35.2. That theorem — proved independently in Lecture 16.2 via tightness of Borel probability measures on a Polish space (and extended there, in Remark 35.2, from \(S = \mathbb{R}\) to an arbitrary standard Borel state space) — is a logically prior result, not a special case of the theorem we are currently proving; invoking it here for the countable index set \(L\) therefore involves no circularity. It guarantees the existence of a unique probability measure \(\mathbb{P}_L \in \mathcal{P}(S^L, \mathcal{B}^{\otimes L})\) satisfying \(\pi_{\Lambda_n \mid S^L}^* \mathbb{P}_L = \mu_{\Lambda_n}\) for every \(n\).

Define \(\tilde{B}_n := (\pi_{\Lambda_n \mid S^L})^{-1}(B_n) \subseteq S^L\). Then: \[ \mathbb{P}(A_n) = \mu_{\Lambda_n}(B_n) = \mathbb{P}_L(\tilde{B}_n). \tag{81.13}\]

Since \(A_n \downarrow \emptyset\) on \(S^T\), and \(A_n = \pi_L^{-1}(\tilde B_n)\) by Equation 81.9 (as \(\Lambda_n \subseteq L\)), surjectivity of \(\pi_L : S^T \to S^L\) (cylinder-factorization lemma) transfers both the monotonicity and the empty intersection through the projection, so \(\tilde{B}_n \downarrow \emptyset\) in \(S^L\). By the countable additivity of the probability measure \(\mathbb{P}_L\) on \((S^L, \mathcal{B}^{\otimes L})\): \[ \lim_{n \to \infty} \mathbb{P}(A_n) = \lim_{n \to \infty} \mathbb{P}_L(\tilde{B}_n) = \mathbb{P}_L(\emptyset) = 0. \tag{81.14}\]

Thus, \(\mathbb{P}\) is countably additive on \(\mathcal{A}\), i.e. \(\mathbb{P}\) is a (finite) premeasure on the algebra \(\mathcal{A}\). By the Carathéodory Extension Theorem (Theorem 8.1), \(\mathbb{P}\) extends to a probability measure on \(\mathcal{B}^{\otimes T} = \sigma(\mathcal{A})\), and since \(\mathbb{P}(S^T) = 1 < \infty\), this extension is unique by the uniqueness theorem for finite premeasures (Theorem 10.1). \(\blacksquare\)

81.4 Canonical Construction of Markov Processes

The following theorem provides a canonical construction of Markov processes using the Kolmogorov Extension Theorem.

Theorem 81.2 (Existence of Canonical Markov Measure) Let \(T\) be a totally ordered index set with a least element, denoted \(0\) (e.g. \(T \subseteq [0,\infty)\) or \(T = \mathbb{N}\), as in Lecture 37.1), and let \((S, \mathcal{B})\) be a standard Borel space. Let \(\nu \in \mathcal{P}(S, \mathcal{B})\) be an initial distribution, and let \(\{Q_{s,t}\}_{s \le t}\) be a family of Markov transition operators on \((S, \mathcal{B})\) satisfying the Chapman–Kolmogorov equations.

Then there exists a unique probability measure \(\mathbb{P}^\nu \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\) on the product space \((\Omega, \mathcal{F}) = (S^T, \mathcal{B}^{\otimes T})\) such that the coordinate process \(X_t(\omega) := \omega(t)\) is a Markov process relative to its natural filtration \(\mathcal{F}_t^X = \sigma(X_s : s \le t)\), with initial law \(\text{Law}_{\mathbb{P}^\nu}(X_0) = \nu\) and transition operators \(\{Q_{s,t}\}_{s \le t}\). We write \(\mathbb{E}^\nu[\cdot]\) for expectation with respect to \(\mathbb{P}^\nu\).

81.5 Proof

The proof proceeds in two main steps: defining finite-dimensional distributions and checking consistency, followed by verifying the Markov property.

81.5.1 Step 1: Definition of Finite-Dimensional Marginals and Consistency

For any finite ordered set of times \(\Lambda = \{t_0 < t_1 < \dots < t_n\} \subseteq T\), write \(\nu_{t_0} := \nu Q_{0,t_0}\) for the pushforward of \(\nu\) along the transition operator from \(0\) to \(t_0\) (so \(\nu_{t_0} = \nu\) when \(t_0 = 0\), since \(Q_{0,0} = \text{Id}\)), and define the finite-dimensional measure \(\mu_\Lambda \in \mathcal{P}(S^{n+1})\) by: \[ \begin{aligned} \mu_\Lambda(dx_0, dx_1, \dots, dx_n) &:= \nu_{t_0}(dx_0) \, q_{t_0, t_1}(x_0, dx_1) \, q_{t_1, t_2}(x_1, dx_2)\\ &\quad \cdots q_{t_{n-1}, t_n}(x_{n-1}, dx_n). \end{aligned} \tag{81.15}\] (When \(0 \in \Lambda\), i.e. \(t_0 = 0\), this reduces to the familiar \(\nu(dx_0) q_{0,t_1}(x_0,dx_1)\cdots\); the role of \(\nu_{t_0}\) is to supply the correct marginal law of \(X_{t_0}\) at the smallest element of \(\Lambda\) when \(\Lambda\) does not contain \(0\) — using \(\nu\) itself in that case would be incorrect in general, since it would force \(\nu\) to be invariant under the transition kernels, which is not assumed.)

We verify projective consistency by checking that deleting a single point from \(\Lambda\) reproduces the corresponding smaller measure; full consistency for arbitrary \(\Lambda' \subseteq \Lambda\) then follows by induction on \(|\Lambda \setminus \Lambda'|\). There are three cases, according to whether the deleted point is interior, the largest point of \(\Lambda\), or the smallest point of \(\Lambda\).

Interior point. Let \(\Lambda = \{t_0 < t_1 < t_2\}\) and \(\Lambda' = \{t_0 < t_2\}\) (deleting \(t_1\)). Integrating over the intermediate state \(x_1 \in S\): \[ \begin{aligned} &\mu_\Lambda(B_0 \times S \times B_2) = \int_{B_0} \nu_{t_0}(dx_0) \int_S q_{t_0, t_1}(x_0, dx_1) \int_{B_2} q_{t_1, t_2}(x_1, dx_2) \\ &= \int_{B_0} \nu_{t_0}(dx_0) \int_{B_2} \left( \int_S q_{t_0, t_1}(x_0, dx_1) \, q_{t_1, t_2}(x_1, dx_2) \right) \\ &= \int_{B_0} \nu_{t_0}(dx_0) \int_{B_2} q_{t_0, t_2}(x_0, dx_2) \quad \text{(by Chapman–Kolmogorov)} \\ &= \mu_{\Lambda'}(B_0 \times B_2). \end{aligned} \tag{81.16}\] (The inner reordering of the two integrals is Tonelli’s theorem, valid since all integrands are nonnegative.) The same computation, with an arbitrary number of untouched factors carried along on either side of \(t_1\), handles deletion of any interior point of \(\Lambda\).

Largest point. Deleting \(t_n\) from \(\Lambda\) is immediate: since \(q_{t_{n-1},t_n}(x_{n-1}, \cdot)\) is a probability measure, \(\int_S q_{t_{n-1},t_n}(x_{n-1}, dx_n) = 1\), so integrating the last factor of Equation 81.15 over \(S\) gives \(\mu_\Lambda(B_0\times\cdots\times B_{n-1}\times S) = \mu_{\Lambda \setminus \{t_n\}}(B_0 \times \cdots \times B_{n-1})\).

Smallest point. This is the case not covered by the two above, and the one for which the correction \(\nu_{t_0} = \nu Q_{0,t_0}\) (rather than \(\nu\) itself) is essential. Let \(\Lambda = \{t_0 < t_1\}\) and \(\Lambda' = \{t_1\}\) (deleting \(t_0\)). Integrating over \(x_0 \in S\) and using associativity of kernel composition together with the Chapman–Kolmogorov identity \(Q_{0,t_0}Q_{t_0,t_1} = Q_{0,t_1}\): \[ \begin{aligned} \mu_\Lambda(S \times B_1) &= \int_S \nu_{t_0}(dx_0) \int_{B_1} q_{t_0,t_1}(x_0,dx_1) \\ &= \int_{B_1} \big( (\nu Q_{0,t_0}) Q_{t_0,t_1} \big)(dx_1) \\ &= \int_{B_1} (\nu Q_{0,t_1})(dx_1) \\ &= \nu_{t_1}(B_1) \\ &= \mu_{\Lambda'}(B_1). \end{aligned} \tag{81.17}\] (With \(\nu\) in place of \(\nu_{t_0}\), this computation would instead require \(\nu Q_{t_0,t_1} = \nu\) for every \(t_0 < t_1\) — i.e. \(\nu\) invariant under the whole transition semigroup — which is not assumed; this is exactly why the plain formula \(\nu(dx_0)q_{t_0,t_1}(x_0,dx_1)\cdots\) fails to be projectively consistent when \(\Lambda\) does not contain \(0\).)

Together, these three cases show that the family \(\{\mu_\Lambda\}_{\Lambda \subseteq T, \, |\Lambda| < \infty}\) satisfies projective consistency for all finite subsets.

Applying Kolmogorov’s Extension Theorem (Theorem 81.1), there exists a unique probability measure \(\mathbb{P}^\nu \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\) such that \(\pi_\Lambda^* \mathbb{P}^\nu = \mu_\Lambda\). Taking \(\Lambda = \{0\}\) gives \(\nu_0 = \nu Q_{0,0} = \nu\), so under \(\mathbb{P}^\nu\), the coordinate process \(X_t(\omega) = \omega(t)\) has initial law \(\nu\) and the target finite-dimensional distributions.

81.5.2 Step 2: Verification of the Markov Property

Fix \(t_0 < t_1 < \dots < t_{n-1} = s < t = t_n\) in \(T\) (not necessarily including \(0\)). Let \(g \in \mathcal{B}_b(S)\) and let \(h \in \mathcal{B}_b(S^n)\) be a bounded test function. Compute the joint expectation under \(\mathbb{P}^\nu\), using Equation 81.15 with leading factor \(\nu_{t_0} = \nu Q_{0,t_0}\): \[ \begin{aligned} &\mathbb{E}^\nu \left[ h(X_{t_0}, \dots, X_{t_{n-1}}) \, g(X_{t_n}) \right] = \int_{S^{n+1}} h(x_0, \dots, x_{n-1}) \, g(x_n) \, \nu_{t_0}(dx_0) \prod_{i=1}^n q_{t_{i-1}, t_i}(x_{i-1}, dx_i) \\ &= \int_{S^n} h(x_0, \dots, x_{n-1}) \left( \int_S g(x_n) \, q_{t_{n-1}, t_n}(x_{n-1}, dx_n) \right) \nu_{t_0}(dx_0) \prod_{i=1}^{n-1} q_{t_{i-1}, t_i}(x_{i-1}, dx_i) \\ &= \int_{S^n} h(x_0, \dots, x_{n-1}) \, (Q_{s,t} g)(x_{n-1}) \, \nu_{t_0}(dx_0) \prod_{i=1}^{n-1} q_{t_{i-1}, t_i}(x_{i-1}, dx_i) \\ &= \mathbb{E}^\nu \left[ h(X_{t_0}, \dots, X_{t_{n-1}}) \, (Q_{s,t} g)(X_s) \right]. \end{aligned} \tag{81.18}\]

Thus, for any cylinder random variable \(Y = h(X_{t_0}, \dots, X_{t_{n-1}})\) with \(t_{n-1} = s\): \[ \mathbb{E}^\nu \left[ g(X_t) \, Y \right] = \mathbb{E}^\nu \left[ (Q_{s,t} g)(X_s) \, Y \right]. \tag{81.19}\]

By Dynkin’s \(\pi\)-\(\lambda\) Theorem (uniqueness of measures agreeing on a generating \(\pi\)-system; cf. Lemma 32.1) — or standard monotone class arguments — identity Equation 81.19 extends from the generating class of finite-dimensional cylinder functions \(Y = h(X_{t_0},\dots,X_{t_{n-1}})\), \(t_0 < \dots < t_{n-1} \le s\) arbitrary, to all bounded \(\mathcal{F}_s^X\)-measurable random variables \(Y \in \mathcal{B}_b(\Omega, \mathcal{F}_s^X)\).

By definition of conditional expectation: \[ \mathbb{E}^\nu \left[ g(X_t) \mid \mathcal{F}_s^X \right] = (Q_{s,t} g)(X_s) = \mathbb{E}^\nu \left[ g(X_t) \mid X_s \right] \quad \mathbb{P}^\nu\text{-a.s.} \tag{81.20}\]

This proves that \(X_t\) is a Markov process relative to \(\mathcal{F}_t^X\) with transition operators \(\{Q_{s,t}\}_{s \le t}\). \(\blacksquare\)

81.6 Takeaways

  • The reverse problem. Given a consistent family of finite-dimensional distributions \(\{\mu_\Lambda\}_{\Lambda \subseteq T, \, |\Lambda| < \infty}\) (Definition 81.2), Kolmogorov’s Extension Theorem produces an actual process on the canonical product space \((S^T, \mathcal{B}^{\otimes T})\) realizing exactly those marginals, with no restriction on the cardinality of \(T\).
  • Standard Borel is the right hypothesis. The theorem genuinely needs \((S,\mathcal{B})\) to be standard Borel; this is what lets the classical, tightness-based countable-index theorem (Corollary 35.2, Lecture 16.2) be bootstrapped to an arbitrary index set \(T\) by reducing countable additivity on the cylinder algebra to countable additivity on the countable sub-product \(S^L\) determined by any given decreasing sequence of cylinder sets.
  • Cylinder sets behave like a generating algebra. Every measurability, well-definedness, and limit argument in the proof reduces to one fact: finite-dimensional projections \(\pi_\Lambda\) factor consistently (\(\pi_\Lambda = p_\Lambda^{\Lambda'}\circ\pi_{\Lambda'}\)) and are surjective, so set relations transfer freely between a cylinder set on \(S^T\) and any of its finite-dimensional representations.
  • Canonical construction of Markov processes. An initial law \(\nu\) together with a Chapman–Kolmogorov-consistent transition family \(\{Q_{s,t}\}_{s\le t}\) determines a unique probability measure \(\mathbb{P}^\nu\) on \((S^T,\mathcal{B}^{\otimes T})\) under which the coordinate process is Markov with exactly these ingredients — provided \(T\) has a least element \(0\), so that “initial law” is meaningful.
  • Mind the starting point. When assembling the finite-dimensional law \(\mu_\Lambda\) for \(\Lambda = \{t_0 < \dots < t_n\}\) not containing \(0\), the correct marginal at \(t_0\) is \(\nu Q_{0,t_0}\) — the law \(\nu\) pushed forward through the transition kernel from \(0\) to \(t_0\) — not \(\nu\) itself; using \(\nu\) directly would silently assume \(\nu\) is invariant under the transition semigroup.
  • Chapman–Kolmogorov consistency and the Markov property are separate. Verifying that \(\{\mu_\Lambda\}\) is projectively consistent only uses the Chapman–Kolmogorov equations; it says nothing yet about conditioning on the whole past. The Markov property itself is established separately, in Step 2, via a generating class of finite-dimensional cylinder functions and Dynkin’s \(\pi\)-\(\lambda\) theorem.
