82  Lecture 38.1: Path Space

82.1 Introduction and the Path Space Framework

Given a totally ordered index set \(T\) with least element \(0\), an initial probability measure \(\nu \in \mathcal{P}(S, \mathcal{B})\), and a family of Markov transition operators \(\{Q_{s,t}\}_{s \le t}\) satisfying the Chapman–Kolmogorov equations on a standard Borel space \((S, \mathcal{B})\) (Theorem 81.2, Lecture 37.2), the Kolmogorov Extension Theorem constructs a canonical probability measure \(\mathbb{P}^\nu \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\) on the infinite product space \(S^T = \{\omega : T \to S\}\). Under \(\mathbb{P}^\nu\), the coordinate process \(X_t(\omega) = \omega(t)\) is a Markov process matching the specified finite-dimensional distributions.

However, not every Markov process associated with the data \((\nu, \{Q_{s,t}\}_{s \le t})\) “is” literally this coordinate process on \(S^T\). In general, any stochastic process \(X = \{X_t\}_{t \in T}\) defined on an arbitrary probability space \((\Omega, \mathcal{F}, \mathbb{P})\) induces a pushforward measure \(P_X\) on the path space \((S^T, \mathcal{B}^{\otimes T})\):

Definition 82.1 (Law of a Stochastic Process / Path Measure) Let \(X = \{X_t\}_{t \in T}\) be an \(S\)-valued stochastic process defined on \((\Omega, \mathcal{F}, \mathbb{P})\). The law of the process \(X\), denoted by \(P_X \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\), is the pushforward measure under the path map \(\omega \mapsto (t \mapsto X_t(\omega))\): \[ P_X(E) := \mathbb{P} \Big( \big\{ \omega \in \Omega : (t \mapsto X_t(\omega))_{t \in T} \in E \big\} \Big) \quad \text{for } E \in \mathcal{B}^{\otimes T}. \tag{82.1}\] This is well defined: since \(\mathcal{B}^{\otimes T} = \sigma(\pi_t : t \in T)\) and \(\pi_t \circ (t \mapsto X_t(\omega)) = X_t\) is \((\mathcal{F}, \mathcal{B})\)-measurable for every \(t \in T\), the path map \(\omega \mapsto (t \mapsto X_t(\omega))\) is \((\mathcal{F}, \mathcal{B}^{\otimes T})\)-measurable, so \(P_X\) is a genuine probability measure on \((S^T, \mathcal{B}^{\otimes T})\).

82.2 Limitations of the Product \(\sigma\)-Algebra

The product \(\sigma\)-algebra allows us to describe events determined by countably many coordinates, but it cannot capture every property of an entire path when the time index set is uncountable. A central measure-theoretic challenge arises when evaluating path properties (e.g., continuity, right-continuity, boundedness) directly on \((S^T, \mathcal{B}^{\otimes T})\).

Remark 82.1 (Smallness of \(\mathcal{B}^{\otimes T}\)). Recall that the product \(\sigma\)-algebra \(\mathcal{B}^{\otimes T} := \sigma(\pi_t : t \in T)\) is generated by individual coordinate projections. Consequently (a standard fact about product \(\sigma\)-algebras, provable by a monotone-class argument: the collection of sets depending on only countably many coordinates is itself a \(\sigma\)-algebra containing every cylinder set, hence all of \(\mathcal{B}^{\otimes T}\)), every set \(E \in \mathcal{B}^{\otimes T}\) depends on at most a countable subset of time coordinates \(T_0 \subseteq T\), i.e. \(E = \pi_{T_0}^{-1}(E')\) for some \(E' \in \mathcal{B}^{\otimes T_0}\) and some countable \(T_0 \subseteq T\).

When \(T = [0, \infty)\), this countable-dependence property shows that path properties genuinely depending on uncountably many time coordinates are not measurable with respect to \(\mathcal{B}^{\otimes T}\). For example, the space of continuous paths \(C([0, \infty), \mathbb{R})\) is not an element of \(\mathcal{B}(\mathbb{R})^{\otimes [0, \infty)}\): if it were, it would depend only on the coordinates in some countable \(T_0 \subseteq [0,\infty)\), i.e. membership in \(C([0,\infty),\mathbb{R})\) would be determined by \((\omega(t))_{t \in T_0}\) alone. But any \(\omega \in C([0,\infty),\mathbb{R})\) can be modified at a single point \(t^* \notin T_0\) (which exists since \(T_0\) is countable and \([0,\infty)\) is not) to destroy continuity at \(t^*\) while leaving all \(T_0\)-coordinates unchanged — contradicting that membership in \(C([0,\infty),\mathbb{R})\) depends only on \(T_0\).

82.4 Brownian Motion

Definition 82.2 (Standard Brownian Motion) An adapted stochastic process \(B = \{B_t\}_{t \ge 0}\) defined on \((\Omega, \mathcal{F}, \{\mathcal{F}_t\}_{t \ge 0}, \mathbb{P})\) is a standard Brownian motion if:

  1. Standard Start: \(B_0 = 0\) \(\mathbb{P}\)-almost surely.
  2. Independent Increments: For all \(0 \le s < t\), \(B_t - B_s\) is independent of \(\mathcal{F}_s\) (in the sense of Definition 80.5, Lecture 37.1). (If \(\{\mathcal{F}_t\}\) is the natural filtration \(\mathcal{F}_t^B = \sigma(B_u : u \le t)\), this is equivalent, via Remark 80.3 together with \(B_0 = 0\), to the weaker-looking statement that for any \(0 \le t_0 < t_1 < \dots < t_n\) the increments \(B_{t_1}-B_{t_0},\dots,B_{t_n}-B_{t_{n-1}}\) are mutually independent; for a general, possibly strictly larger, filtration \(\{\mathcal{F}_t\}\) the two need not coincide, and it is independence from \(\mathcal{F}_s\) that is required for the Markov property.)
  3. Gaussian Increments: \(B_t - B_s \sim \mathcal{N}(0, t-s)\) for all \(0 \le s < t\).
  4. Continuous Sample Paths: The map \(t \mapsto B_t(\omega)\) is continuous \(\mathbb{P}\)-almost surely.

Using Kolmogorov’s Extension Theorem, one can readily construct a Markov process \(X = \{X_t\}_{t \ge 0}\) satisfying conditions (0)–(2) via the Gaussian transition kernel \[ q_{s,t}(x, B) := \int_B \frac{1}{\sqrt{2\pi(t-s)}} \exp \left( -\frac{(y-x)^2}{2(t-s)} \right) dy, \tag{82.2}\] for \(0 \le s \le t\), \(x \in \mathbb{R}\) and \(B \in \mathcal{B}(\mathbb{R})\) together with \(\nu = \delta_0\) as initial law, applying Theorem 81.2 (Lecture 37.2). Once a process \(B\) with this law is in hand, Equation 82.2 indeed coincides with \[ q_{s,t}(x,B) = \mathbb{E}[\mathbf{1}_B(x+B_t-B_s)]= \mathbb{P}(x + B_t - B_s \in B), \] since \(x + B_t - B_s \sim \mathcal{N}(x,\, t-s)\).

The corresponding transition operators \(Q_{s,t} f = \gamma_{t-s} * f\) (where \(\gamma_\tau\) denotes the centered Gaussian density with variance \(\tau\)) satisfy the Chapman–Kolmogorov equations by convolution properties of independent normal distributions: \[ \gamma_{s-r} * \gamma_{t-s} = \gamma_{t-r}, \quad \text{which gives} \quad Q_{r,s} Q_{s,t} = Q_{r,t}. \tag{82.3}\]

Moreover, because the kernel is translation-invariant (\(q_{s,t}(x,\cdot)\) is the law of \(x + Z_{s,t}\) for \(Z_{s,t} \sim \mathcal{N}(0,t-s)\) not depending on \(x\) beyond this translation), the resulting finite-dimensional law of \((X_{t_0}, X_{t_1}, \dots, X_{t_n})\) factors, via the change of variables \(z_i = x_i - x_{i-1}\) (exactly as in the arrival-time computation of Proposition 82.1 below), into a product of the marginal law of \(X_{t_0}\) and independent \(\mathcal{N}(0, t_i - t_{i-1})\) laws for the increments \(z_i = X_{t_i}-X_{t_{i-1}}\). This confirms that \(X\) constructed this way indeed also satisfies condition (1), i.e. has independent increments relative to its own natural filtration.

Property 3 asserts that the sample paths of \(B\) are continuous almost surely: \[ \mathbb{P}\!\Big(\big\{\omega \in \Omega : t \mapsto B_t(\omega) \text{ is continuous on } [0,\infty)\big\}\Big) = 1. \] Equivalently, there exists \(\Omega' \in \mathcal{F}\) with \(\mathbb{P}(\Omega') = 1\) such that for every \(\omega \in \Omega'\) and every \(t_0 \ge 0\), \(\lim_{t \to t_0} B_t(\omega) = B_{t_0}(\omega)\).

For this statement to make sense, the set \(\{\omega : t \mapsto B_t(\omega) \text{ is continuous}\}\) must belong to \(\mathcal{F}\). This is where the lecture’s remark bites: the set of continuous paths \(C([0,\infty), \mathbb{R})\) is not a member of the product \(\sigma\)-algebra \(\mathcal{B}(\mathbb{R})^{\otimes [0,\infty)}\), as shown there — continuity genuinely depends on uncountably many coordinates simultaneously, so it lies outside what the product \(\sigma\)-algebra can see.

However, incorporating path continuity (Property 3) requires substantial further analysis (e.g., Kolmogorov’s Continuity Theorem or explicit series expansions). An explicit constructive representation using i.i.d. \(\mathcal{N}(0,1)\) random variables \(\{\xi_n\}_{n=0}^\infty\) on \(t \in [0, 1]\) is given by the Paley–Wiener / Fourier series: \[ B_t = \xi_0 \, t + \sqrt{2} \sum_{n=1}^\infty \xi_n \, \frac{\sin(n \pi t)}{n \pi}, \qquad t \in [0,1], \] (or standard Haar/Lévy–Ciesielski series expansions), where the series converges uniformly in \(t\) almost surely, which is what yields the a.s. continuity of \(t \mapsto B_t\).

82.5 The Poisson Process and Jump Timings

Definition 82.3 (Poisson Process) An adapted process \(N = \{N_t\}_{t \ge 0}\) defined on \((\Omega, \mathcal{F}, \{\mathcal{F}_t\}_{t \ge 0}, \mathbb{P})\) and taking values in \(\mathbb{N}_0 = \{0, 1, 2, \dots\}\) is a Poisson process with rate \(\lambda > 0\) if:

  1. Standard Start: \(N_0 = 0\) \(\mathbb{P}\)-almost surely.
  2. Independent Increments: For all \(0 \le s < t\), \(N_t - N_s\) is independent of \(\mathcal{F}_s\); equivalently (given \(N_0=0\)), increments over disjoint intervals are mutually independent.
  3. Poisson Increments: \(N_t - N_s \sim \text{Poisson}(\lambda(t-s))\) for all \(0 \le s < t\).
  4. Cadlag / Right-Continuous Paths: \(t \mapsto N_t(\omega)\) is non-decreasing and right-continuous \(\mathbb{P}\)-a.s., with jumps of size exactly \(1\).

Property 3 is not redundant: it is a genuine regularity condition on sample paths that is not implied by properties 0–2 alone (Remark 82.2 below spells this out), and it is exactly what makes \(N\) a bona fide counting process whose jump times can be read off from the path. (That the jumps automatically have size \(1\), given right-continuity and monotonicity, follows from \(\mathbb{P}(N_{t+h}-N_t \ge 2) = O(h^2)\) as \(h \downarrow 0\) together with a standard dyadic-partition/Borel–Cantelli argument; we take it as part of the definition here rather than re-derive it.)

We explicitly construct \(N_t\) from jump arrival times \(X_n = \sum_{k=1}^n \xi_k\) (with \(X_0 := 0\)), where \(\{\xi_k\}_{k=1}^\infty \stackrel{\text{i.i.d.}}{\sim} \text{Exp}(\lambda)\): \[ N_t(\omega) := \sup \left\{ n \in \mathbb{N}_0 : X_n(\omega) \le t \right\}. \tag{82.4}\]

The transition kernel on the discrete state space \(S = \mathbb{N}_0\) is given by: \[ \begin{aligned} q_{s,t}(n, m) &= \mathbb{P}(n + N_t - N_s = m)\\ & = e^{-\lambda(t-s)} \frac{\big(\lambda(t-s)\big)^{m-n}}{(m-n)!} \quad \text{for } m \ge n. \end{aligned} \tag{82.5}\]

Convolution of independent Poisson variables confirms that \(\{q_{s,t}\}_{s \le t}\) satisfies the Chapman–Kolmogorov equations.

Proposition 82.1 (Characterization of Jump Times) Let \(N = \{N_t\}_{t \ge 0}\) satisfy properties (0)–(3) of Definition 82.3 (so, in particular, \(N_0 = 0\) a.s. and \(N\) has non-decreasing, right-continuous paths with unit jumps, in addition to independent and Poisson increments). Define the sequence of jump arrival times by \(X_n := \inf \{ t \ge 0 : N_t = n\}\) for \(n \in \mathbb{N}_0\), and the inter-arrival times \(\xi_n := X_n - X_{n-1}\) for \(n \ge 1\). Then \(\{\xi_n\}_{n=1}^\infty\) are i.i.d. \(\text{Exp}(\lambda)\) random variables.

(Properties 0 and 3 are essential, not merely convenient: they are what make \(X_n\) the literal \(n\)-th jump time of the path \(t \mapsto N_t(\omega)\), so that \(\{X_n \in J_n\}\) can be read off from the values of \(N\) at the endpoints of \(J_n\). Properties (1)–(2) alone, without path regularity, do not suffice for this conclusion — see Remark 82.2.)

Proof 82.1 (Proof). Fix \(n \ge 1\). Partition \([0, t_n]\) into alternating disjoint intervals: \[ \begin{aligned} &K_1 = (0, s_1], \; J_1 = (s_1, t_1], \; K_2 = (t_1, s_2], \; J_2 = (s_2, t_2],\\ & \dots, \; K_n = (t_{n-1}, s_n], \; J_n = (s_n, t_n], \end{aligned} \] where \(0 < s_1 < t_1 < s_2 < t_2 < \dots < s_n < t_n\). Denote \(N(s, t) := N_t - N_s\).

Since \(N_0 = 0\) and \(N\) is non-decreasing, right-continuous, with unit jumps (property 3), the path \(t\mapsto N_t(\omega)\) passes through every integer value it ever reaches, one at a time, so for each \(n\) there is a.s. a well-defined, finite, strictly increasing sequence of jump times \(X_1(\omega) < X_2(\omega) < \dots\) with \(N_t(\omega) = \#\{k \ge 1 : X_k(\omega) \le t\}\). In particular, \(X_j \in (s_j, t_j]\) holds if and only if no jump has occurred by time \(s_j\) beyond the \((j-1)\)-th (i.e. \(N_{s_j} \le j-1\)) and the \(j\)-th jump has occurred by time \(t_j\) (i.e. \(N_{t_j} \ge j\)); this is what licenses translating the event \(\{X_1 \in J_1, \dots, X_n \in J_n\}\) into the disjoint increment conditions below. The event \(\{X_1 \in J_1, X_2 \in J_2, \dots, X_n \in J_n\}\) corresponds to: \[ \begin{aligned} &\{X_1 \in J_1, \dots, X_n \in J_n\} \\ &= \left\{ \bigcap_{j=1}^n \{N(K_j) = 0\} \right\} \cap \left\{ \bigcap_{j=1}^{n-1} \{N(J_j) = 1\} \right\} \cap \{N(J_n) \ge 1\}. \end{aligned} \tag{82.6}\]

Because \(N\) has independent increments over disjoint intervals \(K_1, J_1, \dots, K_n, J_n\), these \(2n\) events are independent. Recalling that \(\mathbb{P}(N(J) = k) = e^{-\lambda|J|} \frac{(\lambda|J|)^k}{k!}\) and \(\mathbb{P}(N(J) \ge 1) = 1 - e^{-\lambda|J|}\): \[ \begin{aligned} \mathbb{P}(X_1 \in J_1, \dots, X_n \in J_n) &= \left( \prod_{j=1}^n e^{-\lambda |K_j|} \right) \left( \prod_{j=1}^{n-1} \lambda |J_j| e^{-\lambda |J_j|} \right) \left( 1 - e^{-\lambda |J_n|} \right) \\ &= \lambda^{n-1} \left( \prod_{j=1}^{n-1} |J_j| \right) e^{-\lambda s_n} \left( 1 - e^{-\lambda(t_n - s_n)} \right) \\ &= \lambda^{n-1} \left( \prod_{j=1}^{n-1} |J_j| \right) \left( e^{-\lambda s_n} - e^{-\lambda t_n} \right) \\ &= \int_{J_1} \dots \int_{J_n} \lambda^n e^{-\lambda x_n} \, dx_1 dx_2 \dots dx_n. \end{aligned} \tag{82.7}\]

By Dynkin’s \(\pi\)-\(\lambda\) Theorem, the joint distribution of \((X_1, \dots, X_n)\) on \(\Delta_n = \{0 < x_1 < x_2 < \dots < x_n\}\) has joint density: \[ f_{X_1, \dots, X_n}(x_1, \dots, x_n) = \lambda^n e^{-\lambda x_n} \mathbf{1}_{\{0 < x_1 < \dots < x_n\}}. \tag{82.8}\]

Applying the change of variables transformation \(\xi_k = X_k - X_{k-1}\) (with \(X_0 = 0\)), the Jacobian determinant is \(1\), yielding joint density: \[ \begin{aligned} f_{\xi_1, \dots, \xi_n}(u_1, \dots, u_n) &= \lambda^n e^{-\lambda \sum_{k=1}^n u_k} \mathbf{1}_{\{u_1 > 0, \dots, u_n > 0\}} \\ &= \prod_{k=1}^n \left( \lambda e^{-\lambda u_k} \mathbf{1}_{\{u_k > 0\}} \right). \end{aligned} \tag{82.9}\]

This proves that \(\{\xi_k\}_{k=1}^n\) are i.i.d. \(\text{Exp}(\lambda)\) random variables. \(\blacksquare\)

82.6 Insufficiency of Transition Kernels for Path Properties

Remark 82.2 (Moral: Path Properties Lie Outside Transition Kernels). Property 3 (right-continuity of \(t \mapsto N_t\)) does not follow from the finite-dimensional distributions or transition kernels alone — nor, as noted above, does it follow from properties (0)–(2).

To demonstrate this, consider the modified process defined using the arrival times \(X_n\) (not the inter-arrival times \(\xi_n\)): \[ M_t(\omega) := \sum_{n=1}^\infty \mathbf{1}_{[0, t)}(X_n(\omega)) = N_{t-}(\omega). \tag{82.10}\] Because each \(X_n\) has a continuous (atomless) law, \(\mathbb{P}(X_n = t) = 0\) for every fixed \(t \ge 0\), so \(\mathbb{P}(M_t \ne N_t) = 0\) at each fixed \(t\), and in fact \(\mathbb{P}(M_{t_1} \ne N_{t_1}, \dots, \text{or } M_{t_k} \ne N_{t_k}) = 0\) for every finite set of times \(t_1, \dots, t_k\) (a finite union of null events is null). Hence \(\{M_t\}_{t \ge 0}\) has the exact same finite-dimensional distributions as \(\{N_t\}_{t \ge 0}\), but its paths are left-continuous instead of right-continuous (it is the left-limit process \(N_{t-}\)).

Key Takeaway: Transition kernels \(\{q_{s,t}\}_{s \le t}\) uniquely specify finite-dimensional distributions on \((S^T, \mathcal{B}^{\otimes T})\), but they do not dictate sample path properties (such as continuity, cadlag paths, or measurability of path functionals). Sample path regularity requires selecting an appropriate separable modification or constructing the process on a restricted path space (such as \(D([0, \infty), S)\) or \(C([0, \infty), S)\)).

82.7 Takeaways

  • Law of a process vs. the canonical coordinate process. Any stochastic process \(X\) on an arbitrary probability space has a well-defined law \(P_X \in \mathcal{P}(S^T, \mathcal{B}^{\otimes T})\) (Definition 82.1), but \(X\) need not literally be the coordinate process constructed by the Kolmogorov Extension Theorem — the two share only their finite-dimensional distributions.
  • The product \(\sigma\)-algebra is too small for path properties. Every \(E \in \mathcal{B}^{\otimes T}\) depends on only countably many coordinates (Remark 82.1), so for \(T = [0,\infty)\), sets like \(C([0,\infty),\mathbb{R})\) that genuinely depend on uncountably many coordinates are not \(\mathcal{B}^{\otimes T}\)-measurable at all.
  • Brownian motion and the Poisson process as Markov processes built from the KET. Both are specified by an initial law together with a transition kernel (Gaussian, resp. Poisson), which is readily checked to satisfy Chapman–Kolmogorov; the Kolmogorov Extension Theorem then produces a process with the correct finite-dimensional distributions, including independent increments and (for a Markov process with a translation-invariant kernel) the correct marginal law of each increment. What the KET construction does not automatically provide is path regularity (continuity for BM, cadlag unit-jump paths for the Poisson process) — these are additional facts (Kolmogorov’s continuity theorem, explicit series or renewal constructions) that must be established separately, and that require \(N_0 = 0\) (resp. \(B_0 = 0\)) to even be meaningful.
  • The arrival-time characterization genuinely needs path regularity. Showing that the jump times of a Poisson process have i.i.d. \(\text{Exp}(\lambda)\) increments (Proposition 82.1) requires not just independent Poisson increments but also that \(N\) has non-decreasing, right-continuous, unit-jump paths starting at \(0\) — without this, the hitting times \(X_n = \inf\{t : N_t = n\}\) need not correspond to literal jump times of the path.
  • Moral: transition kernels do not determine sample path properties. Two processes with identical finite-dimensional distributions (e.g. \(N\) and its left-continuous modification \(M = N_{-}\)) can have incompatible path properties (right- vs. left-continuity); selecting a version with the “correct” regularity is a separate construction, not a consequence of the finite-dimensional distributions (Remark 82.2).
