85  Lecture 39.2: Markov Generator

85.1 Continuous-Time Semigroups and Matrix Exponential

In continuous time \(T = [0, \infty)\), the Chapman-Kolmogorov equations take the semigroup form: \[ Q_{t+s} = Q_t Q_s, \quad Q_0 = \mathrm{Id}. \tag{85.1}\]

This semigroup property \(Q_{t+s} = Q_t Q_s\) is strongly suggestive of the exponential function \(e^{tA}\).

85.2 Finite State Space

Let the state space be finite, \(S = \{1, 2, \dots, n\}\). If there exists an \(n \times n\) matrix \(A \in \mathbb{M}_{n \times n}(\mathbb{R})\) such that \(Q_t = e^{tA} = \sum_{k=0}^\infty \frac{t^k A^k}{k!}\), then:

  1. \(Q_0 = e^{0 \cdot A} = \mathrm{Id}\);
  2. \(Q_{t+s} = e^{(t+s)A} = e^{tA} e^{sA} = Q_t Q_s\) (since \(tA\) and \(sA\) commute).

The matrix \(A\) is called the infinitesimal generator of the transition semigroup \((Q_t)_{t \ge 0}\).

If \(A\) exists, it can be recovered via the time derivative at \(t = 0\): \[ \begin{aligned} &\frac{\mathrm{d}}{\mathrm{d}t} Q_t = A e^{tA} = e^{tA} A\\ &\implies A = \left. \frac{\mathrm{d}}{\mathrm{d}t} Q_t \right|_{t=0} = \lim_{t \downarrow 0} \frac{Q_t - \mathrm{Id}}{t}. \end{aligned} \tag{85.2}\]

Because \(q_t(i, j) = \mathbb{P}(X_t = j \mid X_0 = i)\) denotes the scalar entries of the transition kernel of \(Q_t\) on \(S\) (so that \(Q_t = (q_t(i,j))_{i,j\in S}\), matching the operator/matrix-entry convention of Lecture 39.1), \(q_t\) satisfies: \[ q_t(i, j) \ge 0 \quad \forall i, j \in S, \quad \text{and} \quad \sum_{j=1}^n q_t(i, j) = 1 \quad \forall i \in S. \tag{85.3}\]

Proposition 85.1 (Characterization of Finite Generator Matrices) Let \(A \in \mathbb{M}_{n \times n}(\mathbb{R})\). Then \(Q_t = e^{tA}\) is a time-homogeneous Markov transition operator for all \(t \ge 0\) if and only if \(A\) is an intensity matrix (or \(Q\)-matrix), meaning:

  1. \(A_{ij} \ge 0\) for all \(i \ne j\);
  2. \(\sum_{j=1}^n A_{ij} = 0\) for all \(i \in \{1, \dots, n\}\) (implying \(A_{ii} = -\sum_{j \ne i} A_{ij} \le 0\)).

Proof. \((\implies)\) Since \(q_t(i, j) \ge 0\) for all \(t > 0\), taking off-diagonal entries \(i \ne j\) gives: \[ A_{ij} = \lim_{t \downarrow 0} \frac{q_t(i, j) - q_0(i, j)}{t} = \lim_{t \downarrow 0} \frac{q_t(i, j)}{t} \ge 0. \] Furthermore, since \(\sum_{j=1}^n q_t(i, j) = 1\) for all \(t \ge 0\), differentiating with respect to \(t\) at \(t = 0\) yields: \[ \sum_{j=1}^n A_{ij} = \left. \frac{\mathrm{d}}{\mathrm{d}t} \sum_{j=1}^n q_t(i, j) \right|_{t=0} = \frac{\mathrm{d}}{\mathrm{d}t}(1) = 0. \]

\((\impliedby)\) Suppose \(A\) satisfies conditions 1–2. Let \(c := \max_{i} (-A_{ii}) = \max_i \sum_{j \ne i} A_{ij} < \infty\) (finite since \(S\) is finite), and set \(B := A + cI\). Then \(B_{ij} = A_{ij} \ge 0\) for \(i \ne j\), and \(B_{ii} = A_{ii} + c \ge 0\) by the choice of \(c\); so \(B\) has all entries \(\ge 0\). Since \(B\) and \(cI\) commute, \[ Q_t = e^{tA} = e^{t(B - cI)} = e^{-ct} e^{tB} = e^{-ct} \sum_{k=0}^\infty \frac{t^k B^k}{k!}. \] For \(t \ge 0\), every term \(\frac{t^k}{k!} B^k\) has non-negative entries (a product, and hence any power, of entrywise non-negative matrices is entrywise non-negative), so the convergent series \(\sum_k \frac{t^kB^k}{k!}\) has non-negative entries; multiplying by the positive scalar \(e^{-ct}\) preserves this, giving \(q_t(i,j) \ge 0\) for all \(i,j\).

For the row sums, condition 2 says \(A\mathbf{1} = 0\) where \(\mathbf{1} = (1,\dots,1)^\top\), so by induction \(A^k\mathbf{1} = A^{k-1}(A\mathbf{1}) = 0\) for every \(k \ge 1\). Hence \[ Q_t \mathbf{1} = \sum_{k=0}^\infty \frac{t^k}{k!} A^k \mathbf{1} = \mathbf{1} + \sum_{k=1}^\infty \frac{t^k}{k!}\cdot 0 = \mathbf{1}, \] i.e. \(\sum_{j=1}^n q_t(i,j) = 1\) for every \(i \in S\) and every \(t \ge 0\). Together with \(Q_0 = \mathrm{Id}\) and the semigroup property already verified, \((Q_t)_{t\ge0}\) is a time-homogeneous Markov transition semigroup.

85.3 Non-Continuous Transition Semigroups

Is every transition semigroup of the form \(Q_t = e^{tA}\) for some operator \(A\)? The answer is no if continuity at \(t=0\) fails.

Example 85.1 (Discontinuous Semigroup) Fix a probability mass vector \(\boldsymbol{\nu} = (\nu(1), \dots, \nu(n))\) on \(S = \{1, \dots, n\}\). Define \(P \in \mathbb{M}_{n \times n}(\mathbb{R})\) by \(P_{ij} = \nu(j)\) for all \(i \in S\).

Consider the family \(q_t(i, j) = P_{ij} = \nu(j)\) for all \(t > 0\) and \(q_0(i, j) = \delta_{ij}\). Check the semigroup property for \(s, t > 0\): \[ \sum_{k \in S} q_s(i, k) q_t(k, j) = \sum_{k \in S} \nu(k) \nu(j) = \nu(j) \sum_{k \in S} \nu(k) = \nu(j) = q_{s+t}(i, j). \]

However, this semigroup is discontinuous at \(t = 0\) whenever \(n \ge 2\): since \(\boldsymbol\nu\) is a single fixed vector (not depending on \(i\)), there is no choice of \(\boldsymbol\nu\) for which \(\nu(j) = \delta_{ij}\) holds simultaneously for every pair \(i,j \in S\) — this would require \(\nu(i) = 1\) for every \(i \in S\), impossible once \(n \ge 2\). Hence for every \(i\) there is some \(j\) with \[ \lim_{t \downarrow 0} q_t(i, j) = P_{ij} = \nu(j) \ne \delta_{ij} = q_0(i, j). \] (The degenerate case \(n=1\) is the only exception, where \(S\) is a single point and the semigroup is trivially continuous.)

Probabilistically, \(\mathbb{P}(X_t = j \mid X_s = i) = q_{t-s}(i, j) = \nu(j) = \mathbb{P}(X_t = j)\), which corresponds to \((X_t)_{t > 0}\) being an i.i.d. family of random variables with law \(\boldsymbol{\nu}\) for all \(t > 0\), completely independent of \(X_0\).

85.4 Generator of the Poisson Process

Consider a Poisson process \((N_t)_{t \ge 0}\) with intensity \(\lambda > 0\) on state space \(S = \mathbb{N}_0 = \{0, 1, 2, \dots\}\).

The transition kernel is: \[ \begin{aligned} q_{s,t}(m, n) &= \mathbb{P}(N_t = n \mid N_s = m) \\ &= \mathbb{P}(N_t - N_s+N_s = n\mid N_s = m) \\ &= \mathbb{P}(N_t - N_s + m = n \mid N_s = m) \\ &= \mathbb{P}(N_t - N_s = n - m) \\ &= e^{-\lambda(t-s)} \frac{(\lambda(t-s))^{n-m}}{(n-m)!} \mathbf{1}_{\{n \ge m\}}. \end{aligned} \]

For any \(f \in \mathcal{B}_b(\mathbb{N}_0)\), the operator \(Q_t\) acts on \(f\) as: \[ \begin{aligned} (Q_t f)(k) &= \sum_{n=0}^\infty q_t(k, k+n) f(k+n)\\ &= e^{-\lambda t} \sum_{n=0}^\infty \frac{(\lambda t)^n}{n!} f(k+n). \end{aligned} \tag{85.4}\]

Differentiating \((Q_t f)(k)\) with respect to \(t\) using power series term-by-term differentiation (valid since \(f\) is bounded): \[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d}t} (Q_t f)(k) &= -\lambda e^{-\lambda t} \sum_{n=0}^\infty \frac{(\lambda t)^n}{n!} f(k+n) + e^{-\lambda t} \sum_{n=1}^\infty \lambda \frac{n (\lambda t)^{n-1}}{n!} f(k+n) \\ &= -\lambda (Q_t f)(k) + \lambda e^{-\lambda t} \sum_{m=0}^\infty \frac{(\lambda t)^m}{m!} f(k+m+1) \quad (\text{setting } m = n-1) \\ &= -\lambda (Q_t f)(k) + \lambda Q_t f(k+1) \\ &= \lambda \left[ (Q_t f)(k+1) - (Q_t f)(k) \right]. \end{aligned} \]

Defining the operator \(A\) by: \[ (A f)(k) := \lambda [f(k+1) - f(k)], \tag{85.5}\] the computation above shows \(\frac{\mathrm{d}}{\mathrm{d}t} Q_t f = A Q_t f\). The companion identity \(A Q_t f = Q_t A f\) follows from the translation-invariance of the Poisson kernel, \(q_t(k, k+n) = q_t(k+1, k+1+n)\) for every \(n \ge 0\) (both sides equal \(e^{-\lambda t}(\lambda t)^n/n!\)): reindexing, \[ \begin{aligned} (Q_t A f)(k) &= \lambda \sum_{n=0}^\infty q_t(k,k+n)\big[f(k+n+1) - f(k+n)\big] \\ &= \lambda\big[(Q_tf)(k+1) - (Q_tf)(k)\big] = (AQ_tf)(k), \end{aligned} \] where we use \[ \begin{aligned} \sum_n q_t(k,k+n) f(k+n+1) &= \sum_n q_t(k+1,(k+1)+n) f((k+1)+n) \\ &= (Q_tf)(k+1). \end{aligned} \] Hence, we obtain the differential equation \(\frac{\mathrm{d}}{\mathrm{d}t} Q_t f = Q_t A f = A Q_t f\).

Theorem 85.1 (Exponential Representation for Poisson Generator) Let \(A = \lambda (T - \mathrm{Id})\) where \(T f(k) = f(k+1)\) is the forward shift operator on \(\mathcal{B}_b(\mathbb{N}_0)\). Then \(A\) is a bounded operator on \((\mathcal{B}_b(\mathbb{N}_0), \|\cdot\|_\infty)\) with \(\|A\| \le 2\lambda\).

Consequently, the operator exponential series \(e^{tA} = \sum_{n=0}^\infty \frac{t^n A^n}{n!}\) converges uniformly, and: \[ \begin{aligned} e^{tA} &= e^{t \lambda (T - \mathrm{Id})} \\ &= e^{-\lambda t \mathrm{Id}} e^{\lambda t T} \\ &= e^{-\lambda t} \sum_{n=0}^\infty \frac{(\lambda t)^n}{n!} T^n \\ &= Q_t. \end{aligned} \tag{85.6}\] Thus, \(A = \lambda (T - \mathrm{Id})\) is the explicit infinitesimal generator of the Poisson process.

Proof (Proof of Theorem 85.1). Let \(T:\mathcal{B}_b(\mathbb{N}_0)\to\mathcal{B}_b(\mathbb{N}_0)\) be the forward shift \(Tf(k)=f(k+1)\), and set \(A=\lambda(T-\mathrm{Id})\). Then:

  1. \(A\) is a bounded operator with \(\|A\|\le 2\lambda\).
  2. The series \(e^{tA}=\sum_{n=0}^\infty \frac{t^n A^n}{n!}\) converges in operator norm for every \(t\ge 0\).
  3. \(e^{tA} = Q_t\), i.e. \((e^{tA}f)(k) = e^{-\lambda t}\sum_{n=0}^\infty \frac{(\lambda t)^n}{n!}f(k+n)\).

Step 1: Boundedness of \(T\) and \(A\): The shift \(T\) is an isometry: for any \(f\in\mathcal{B}_b(\mathbb{N}_0)\), \[ \|Tf\|_\infty = \sup_{k\in\mathbb{N}_0}|f(k+1)| = \sup_{k\in\mathbb{N}_0}|f(k)| = \|f\|_\infty, \] so \(\|T\|=1\). Since \(\|\mathrm{Id}\|=1\) as well, the triangle inequality gives \[ \|Af\|_\infty = \lambda\|(T-\mathrm{Id})f\|_\infty \le \lambda\bigl(\|Tf\|_\infty + \|f\|_\infty\bigr) = 2\lambda\|f\|_\infty. \] Hence \(A\) is bounded with \(\|A\|\le 2\lambda\).

Step 2: Norm convergence of \(e^{tA}\): Because \(\|A^n\|\le\|A\|^n\le(2\lambda)^n\) (operator norm is submultiplicative), the series of operator norms satisfies \[ \sum_{n=0}^\infty \frac{t^n\|A^n\|}{n!} \le \sum_{n=0}^\infty \frac{(2\lambda t)^n}{n!} = e^{2\lambda t} < \infty. \] Absolute convergence in operator norm implies the series \(e^{tA}=\sum_{n=0}^\infty \frac{t^nA^n}{n!}\) converges to a well-defined bounded operator.

Step 3: Splitting \(e^{tA}=e^{-\lambda t}e^{\lambda tT}\): Write \(A = \lambda T - \lambda\,\mathrm{Id}\), so \(tA = (\lambda t T) + (-\lambda t\,\mathrm{Id})\). The two summands commute because \(\mathrm{Id}\) commutes with every operator. For commuting bounded operators \(B\) and \(C\) (meaning \(BC=CB\)), the identity \(e^{B+C}=e^Be^C\) holds. To see why, use the binomial theorem (valid since \(B\) and \(C\) commute): \[ (B+C)^n = \sum_{k=0}^n\binom{n}{k}B^k C^{n-k}, \] so \[ e^{B+C} = \sum_{n=0}^\infty\frac{1}{n!}\sum_{k=0}^n\binom{n}{k}B^kC^{n-k} = \sum_{k=0}^\infty\sum_{j=0}^\infty\frac{B^k}{k!}\frac{C^j}{j!} = e^Be^C, \] where the double series rearrangement is justified by absolute convergence (both \(B\) and \(C\) are bounded). Applying this with \(B=-\lambda t\,\mathrm{Id}\) and \(C=\lambda tT\): \[ e^{tA} = e^{-\lambda t\,\mathrm{Id}}\,e^{\lambda tT}. \] Since \((\alpha\,\mathrm{Id})^n=\alpha^n\mathrm{Id}\), the series for \(e^{-\lambda t\,\mathrm{Id}}\) gives simply the scalar \(e^{-\lambda t}\) times the identity, so \[ e^{tA} = e^{-\lambda t}\,e^{\lambda tT}. \]

Step 4: Computing \(T^n\) and the series for \(e^{\lambda tT}\): Applying the shift \(n\) times: \(T^n f(k) = T^{n-1}(Tf)(k) = T^{n-1}f(k+1) = \cdots = f(k+n)\). Therefore \[ (e^{\lambda tT}f)(k) = \sum_{n=0}^\infty\frac{(\lambda t)^n}{n!}(T^nf)(k) = \sum_{n=0}^\infty\frac{(\lambda t)^n}{n!}f(k+n). \] This series converges for every \(k\) since \(f\) is bounded: \[ \left|\sum_{n=0}^\infty\frac{(\lambda t)^n}{n!}f(k+n)\right| \le \|f\|_\infty\sum_{n=0}^\infty\frac{(\lambda t)^n}{n!} = e^{\lambda t}\|f\|_\infty < \infty. \]

Step 5: Conclusion \(e^{tA}=Q_t\): Combining Steps 3 and 4: \[ (e^{tA}f)(k) = e^{-\lambda t}(e^{\lambda tT}f)(k) = e^{-\lambda t}\sum_{n=0}^\infty\frac{(\lambda t)^n}{n!}f(k+n). \] This is exactly \((Q_tf)(k)\) from the file. Hence \(e^{tA}=Q_t\) as operators on \(\mathcal{B}_b(\mathbb{N}_0)\), and \(A=\lambda(T-\mathrm{Id})\) is the infinitesimal generator of the Poisson semigroup.

85.5 Generator of Brownian Motion

Consider standard Brownian motion \((B_t)_{t \ge 0}\) on \(\mathbb{R}\). Its transition density is the Gaussian heat kernel: \[ q_t(x, y) = \frac{1}{\sqrt{2\pi t}} e^{-\frac{|x-y|^2}{2t}}, \quad t > 0, \, x, y \in \mathbb{R}. \tag{85.7}\]

By definition, \((Q_t f)(x) = \mathbb{E}[f(B_t) \mid B_0 = x]\). Given \(B_0 = x\), the random variable \(B_t\) has distribution \(\mathcal{N}(x, t)\), whose density is exactly \(q_t(x, y) = \frac{1}{\sqrt{2\pi t}}e^{-\frac{(y-x)^2}{2t}}\). Writing the expectation as an integral against this density: \[ \begin{aligned} (Q_t f)(x) &= \mathbb{E}[f(B_t)\mid B_0=x] \\ & = \int_\mathbb{R} f(y)\, q_t(x,y)\,\mathrm{d}y\\ & = (q_t * f)(x). \end{aligned} \tag{85.8}\]

Remark 85.1. A convolution \((g * f)(x) = \int_\mathbb{R} g(x-y)f(y)\,\mathrm{d}y\) only makes sense when the kernel depends on \(x\) and \(y\) solely through their difference \(x - y\). The heat kernel has exactly this structure: since \(|x-y|^2 = |y-x|^2\), the kernel satisfies \[ q_t(x,y) = \frac{1}{\sqrt{2\pi t}}e^{-\frac{(y-x)^2}{2t}} = p_t(y-x), \] where \(p_t(z) = \frac{1}{\sqrt{2\pi t}}e^{-z^2/2t}\) is a function of the single variable \(z = y - x\) only. Because \(p_t\) is even (\(p_t(-z) = p_t(z)\), since the Gaussian is symmetric), we also have \(p_t(y-x) = p_t(x-y)\), so \[ \int_\mathbb{R} f(y)\,q_t(x,y)\,\mathrm{d}y = \int_\mathbb{R} p_t(x-y)f(y)\,\mathrm{d}y = (p_t * f)(x). \] We write this as \((q_t * f)(x)\), using \(q_t\) to also denote the one-variable function \(p_t\) — a slight abuse of notation, but standard in this context.

Proposition 85.2 (Infinitesimal Generator of Brownian Motion) If \(f \in C_b^2(\mathbb{R})\) (bounded, with bounded continuous first and second derivatives), then \((Q_t f)(x)\) satisfies the Kolmogorov forward/backward equations: \[ \frac{\mathrm{d}}{\mathrm{d}t} (Q_t f)(x) = A (Q_t f)(x) = Q_t (A f)(x), \tag{85.9}\] where the generator operator \(A\) on \(C_b^2(\mathbb{R})\) is given by: \[ A f(x) = \frac{1}{2} \frac{\mathrm{d}^2 f}{\mathrm{d}x^2}(x) = \frac{1}{2} f''(x). \tag{85.10}\]

Proof. Step 1: \(A f(x) = \frac12 f''(x)\) at \(t=0\). Fix \(x \in \mathbb{R}\) and write \((Q_tf)(x) = \mathbb{E}[f(x+B_t)]\) (using \(B_0=0\) and the translation structure of Equation 85.8). By Taylor’s theorem with Lagrange remainder, for each realization of \(B_t\) there is \(\xi\) between \(x\) and \(x+B_t\) with \[ f(x+B_t) = f(x) + f'(x)B_t + \tfrac12 f''(x) B_t^2 + \tfrac12\big[f''(\xi) - f''(x)\big]B_t^2. \] Taking expectations and using \(\mathbb{E}[B_t]=0\), \(\mathbb{E}[B_t^2]=t\): \[ \frac{(Q_tf)(x) - f(x)}{t} = \tfrac12 f''(x) + \tfrac12\,\mathbb{E}\!\left[\big(f''(\xi)-f''(x)\big)\frac{B_t^2}{t}\right]. \] Write \(B_t = \sqrt t\, Z\) with \(Z \sim N(0,1)\), and set \(g_t(z) := f''(\xi(x,\sqrt t z)) - f''(x)\), so the remainder term is \(\tfrac12\mathbb{E}[g_t(Z)Z^2]\). Since \(f''\) is bounded, \(|g_t(Z)Z^2| \le 2\|f''\|_\infty Z^2\) with \(\mathbb{E}[Z^2] < \infty\); and since \(\sqrt t Z \to 0\) a.s. as \(t \downarrow 0\) while \(\xi\) lies between \(x\) and \(x+\sqrt t Z\), continuity of \(f''\) at \(x\) gives \(g_t(Z) \to 0\) a.s. By the Dominated Convergence Theorem, \(\mathbb{E}[g_t(Z)Z^2] \to 0\) as \(t \downarrow 0\). Hence \[ Af(x) := \lim_{t\downarrow0}\frac{(Q_tf)(x)-f(x)}{t} = \tfrac12 f''(x). \]

Step 2: extension to all \(t \ge 0\). The heat kernel Equation 85.7 is \(C^\infty\) in \(x\) with all \(x\)-derivatives bounded by integrable functions of \(y\) uniformly for \(x\) in compacts (Gaussian tails dominate any polynomial prefactor), so differentiation under the integral sign in Equation 85.8 is justified and \(Q_tf \in C_b^2(\mathbb{R})\) for every \(t>0\) and every \(f\in\mathcal B_b(\mathbb R)\), in particular for \(f \in C_b^2(\mathbb{R})\). Using the semigroup property \(Q_{t+h}=Q_tQ_h=Q_hQ_t\) (Equation 85.1), \[ \frac{\mathrm{d}}{\mathrm{d}t}(Q_tf)(x) = \lim_{h\downarrow0}\frac{(Q_h(Q_tf))(x) - (Q_tf)(x)}{h} = A(Q_tf)(x) \] by Step 1 applied to \(Q_tf \in C_b^2(\mathbb{R})\) in place of \(f\); and, since \(Q_t\) is a bounded operator (\(\|Q_tg\|_\infty \le \|g\|_\infty\)) and hence continuous, \[ \begin{aligned} \frac{\mathrm{d}}{\mathrm{d}t}(Q_tf)(x) &= \lim_{h\downarrow0}\frac{(Q_t(Q_hf))(x) - (Q_t f)(x)}{h} \\ &= Q_t\!\left(\lim_{h\downarrow0}\frac{Q_hf - f}{h}\right)\!(x) = Q_t(Af)(x), \end{aligned} \] where passing the limit inside \(Q_t\) uses boundedness/linearity of \(Q_t\) together with Step 1 applied at the point \(x\) after convolving. This proves Equation 85.9.

Remark 85.2.

  1. The generator of Brownian motion is the half-Laplacian. The most concrete output is the formula \(Af = \frac{1}{2}f''\). Recall that the generator is defined as \(Af(x) = \lim_{t\downarrow 0}\frac{(Q_tf)(x)-f(x)}{t}\), the “instantaneous rate of change” of the semigroup. The proof shows this limit equals \(\frac{1}{2}f''(x)\) by a second-order Taylor expansion of \(f(x+B_t)\): the mean-zero symmetry of \(B_t\) kills the first-order term \(f'(x)\mathbb{E}[B_t] = 0\), and the second-order term contributes \(\frac{1}{2}f''(x)\cdot\frac{\mathbb{E}[B_t^2]}{t} = \frac{1}{2}f''(x)\). So the curvature of \(f\), measured by \(f''\), is what the Brownian semigroup “sees” instantaneously.

  2. The evolution equation is the heat equation. Setting \(u(t,x) := (Q_tf)(x)\), the equation \(\frac{\mathrm{d}}{\mathrm{d}t}Q_tf = A\,Q_tf\) becomes \[ \frac{\partial u}{\partial t}(t,x) = \frac{1}{2}\frac{\partial^2 u}{\partial x^2}(t,x), \] which is the classical heat equation with initial condition \(u(0,x) = f(x)\). The proposition is therefore saying that Brownian motion solves the heat equation: \((Q_tf)(x) = \mathbb{E}[f(x+B_t)]\) is the unique solution starting from \(f\).

  3. The two sides of the equation \(AQ_tf = Q_tAf\) say different things. The equality \(\frac{\mathrm{d}}{\mathrm{d}t}Q_tf = AQ_tf = Q_tAf\) actually encodes two separate results:

  • \(\frac{\mathrm{d}}{\mathrm{d}t}Q_tf = AQ_tf\) (the backward equation): differentiate \(Q_{t+h}f = Q_h(Q_tf)\) in \(h\) at \(h=0\), applying the generator to \(Q_tf\). This says: to find how the evolved function \(Q_tf\) is changing in time, apply \(A\) to it.
  • \(\frac{\mathrm{d}}{\mathrm{d}t}Q_tf = Q_t(Af)\) (the forward equation): differentiate \(Q_{t+h}f = Q_t(Q_hf)\) in \(h\) at \(h=0\), pulling \(Q_t\) outside the limit. This says: you can instead first apply the generator to \(f\), then evolve the result with \(Q_t\).

Together they mean that \(A\) and \(Q_t\) commute on \(C_b^2(\mathbb{R})\): \(AQ_t = Q_tA\). This commutativity is the operator-theoretic reflection of the translation invariance of Brownian motion.

Remark 85.3 (Domain Restrictions and Feller Processes). Unlike the Poisson generator \(A = \lambda(T - \mathrm{Id})\), which is bounded on all of \(\mathcal{B}_b(\mathbb{N}_0)\), the Laplacian operator \(A = \frac{1}{2} \frac{\mathrm{d}^2}{\mathrm{d}x^2}\) is unbounded.

It cannot be defined on all of \(\mathcal{B}_b(\mathbb{R})\) because discontinuous or non-differentiable functions (such as \(f = \mathbf{1}_{[0,1]}\)) cannot be differentiated twice in the classical sense. Sequences \(\psi_n \in C_c^2(\mathbb{R})\) approximating \(\mathbf{1}_{[0,1]}\) pointwise have unbounded second derivatives \(\|\psi_n''\|_\infty \to \infty\).

This domain issue motivates the theory of Feller semigroups and Feller processes, where the domain of \(A\) is restricted to continuous functions vanishing at infinity, \(\mathcal{D}(A) \subset C_0(\mathbb{R})\).

85.6 Takeaways

  • The generator turns the semigroup law into a differential equation. Since \((Q_t)_{t\ge0}\) satisfies \(Q_{t+s}=Q_tQ_s\), \(Q_0=\mathrm{Id}\) (Equation 85.1), if \(Q_t=e^{tA}\) for some operator \(A\), then \(A\) is recovered as the one-sided derivative \(A=\lim_{t\downarrow0}(Q_t-\mathrm{Id})/t\) (Equation 85.2), and conversely the whole semigroup is reconstructed from \(A\) by exponentiating. The generator is thus the “infinitesimal description” of a Markov process.
  • On a finite state space, generators are exactly the \(Q\)-matrices. Proposition 85.1 shows \(Q_t=e^{tA}\) defines a valid Markov semigroup iff \(A\) has non-negative off-diagonal entries and zero row sums — the classical intensity-matrix conditions. The (\(\Leftarrow\)) direction is proved via the shift trick \(A=B-cI\) with \(B\ge0\) entrywise, which simultaneously gives positivity of \(Q_t\) (via the non-negative series \(e^{tB}\)) and conservation of probability (via \(A\mathbf 1=0 \Rightarrow A^k\mathbf 1 = 0\) for \(k\ge1\)).
  • Not every Markov semigroup has a generator. Example 85.1 exhibits a perfectly valid semigroup (\(Q_t=P\) for all \(t>0\), \(Q_0=\mathrm{Id}\)) that is discontinuous at \(t=0\) whenever \(|S|\ge2\), so no bounded \(A\) with \(Q_t=e^{tA}\) can exist (such a family is automatically continuous at \(0\)). Existence of a generator is therefore a genuine extra hypothesis (continuity of \(t\mapsto Q_t\) at \(t=0\)), not automatic.
  • Bounded generators: the Poisson process. For the Poisson process, \(A=\lambda(T-\mathrm{Id})\) (forward-shift minus identity, scaled by the rate \(\lambda\)) is a bounded operator on \(\mathcal{B}_b(\mathbb{N}_0)\) (Theorem 85.1), so \(Q_t=e^{tA}\) holds literally as a convergent operator-norm series — the discrete-state-space picture carries over verbatim to the countably infinite case because \(\|A\|\le2\lambda<\infty\).
  • Unbounded generators: Brownian motion. The generator of Brownian motion is \(Af=\tfrac12f''\) (Proposition 85.2), proved via a second-order Taylor expansion of \(f(x+B_t)\) combined with dominated convergence. Unlike the Poisson case, \(A\) cannot be bounded on all of \(\mathcal{B}_b(\mathbb{R})\): it is not even classically defined outside \(C_b^2(\mathbb{R})\), since indicator-type functions have no second derivative and their smooth approximations have second derivatives blowing up (Remark 85.3). This is the generic situation for diffusions, not a pathology specific to Brownian motion.
  • Domain restriction, not boundedness, is the right generalization. The Brownian/Poisson contrast shows that “bounded generator on \(\mathcal{B}_b\)” is too strong a requirement for continuous-state-space processes; the correct framework (Feller semigroups, restricting to \(C_0(\mathbb{R})\) with a dense domain \(\mathcal{D}(A)\)) is what must replace it, motivating the operator-theoretic machinery developed in Lecture 40.1.
