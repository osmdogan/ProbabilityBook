93  Lecture 43.2 Biased Random Walks

93.1 Introduction and Construction of the Process

Definition 93.1 (Biased Random Walk on \(\mathbb{Z}\)) Fix a parameter \(p \in (0, 1)\). A biased random walk on \(\mathbb{Z}\) with parameter \(p\) is a discrete-time Markov chain \((X_n)_{n \ge 0}\) taking values in the state space \(S = \mathbb{Z}\) with one-step transition kernel \(q : \mathbb{Z} \times \mathbb{Z} \to [0, 1]\) defined by \[ q(x, y) = p \mathbf{1}_{\{y = x + 1\}} + (1 - p) \mathbf{1}_{\{y = x - 1\}}, \qquad x, y \in \mathbb{Z}. \tag{93.1}\] Since \(S = \mathbb{Z}\) is countable with \(\mathcal{B} = \mathcal{P}(\mathbb{Z})\), the point function \(q\) determines the Markov kernel \(q(x, A) := \sum_{y \in A} q(x, y)\), \(A \subseteq \mathbb{Z}\), of Lectures 42.2 and 43.1; we use the same symbol for both. When \(p = \frac{1}{2}\), the process reduces to the symmetric (simple) random walk on \(\mathbb{Z}\).

Proposition 93.1 (Explicit Construction via Independent Increments) Let \((\Omega, \mathcal{F}, \mathbb{P})\) be a probability space supporting an integer-valued random variable \(X_0\) and a sequence \((\xi_k)_{k \ge 1}\) of random variables such that \(X_0, \xi_1, \xi_2, \dots\) are mutually independent and \((\xi_k)_{k \ge 1}\) are identically distributed (i.i.d.) with common distribution \[ \mu = p \delta_1 + (1 - p) \delta_{-1}, \] where \(\delta_z\) denotes the Dirac point mass at \(z \in \mathbb{Z}\) (i.e., \(\mathbb{P}(\xi_k = 1) = p\) and \(\mathbb{P}(\xi_k = -1) = 1 - p\) for each \(k \ge 1\)). Define the process \((X_n)_{n \ge 0}\) by \[ X_n = X_0 + \sum_{k=1}^n \xi_k = X_0 + \xi_1 + \xi_2 + \cdots + \xi_n, \qquad n \ge 0, \tag{93.2}\] with the empty sum interpreted as \(0\) for \(n = 0\). Then \((X_n)_{n \ge 0}\) is a time-homogeneous Markov chain on \(\mathbb{Z}\) with transition kernel \(q\) given by Equation 93.1.

Proof (Proof of Proposition 93.1). Let \(\mathcal{F}_n = \sigma(X_0, \xi_1, \dots, \xi_n)\) be the natural filtration generated by the initial state and the first \(n\) increments. Since \(\xi_k = X_k - X_{k-1}\), we have \(\sigma(X_0, \dots, X_n) = \mathcal{F}_n\), so \((X_n)_{n \ge 0}\) is adapted to \((\mathcal{F}_n)_{n \ge 0}\). By mutual independence of \(X_0, \xi_1, \xi_2, \dots\) (grouping), \(\xi_{n+1}\) is independent of \(\mathcal{F}_n\). For any \(n \ge 0\) and any \(y \in \mathbb{Z}\), we have \[ \mathbb{P}(X_{n+1} = y \mid \mathcal{F}_n) = \mathbb{P}(X_n + \xi_{n+1} = y \mid \mathcal{F}_n) = \mathbb{P}(\xi_{n+1} = y - X_n \mid \mathcal{F}_n). \] Since \(X_n\) is \(\mathcal{F}_n\)-measurable and \(\xi_{n+1}\) is independent of \(\mathcal{F}_n\), the standard freezing lemma for conditional expectations yields \[ \begin{aligned} \mathbb{P}(\xi_{n+1} = y - X_n \mid \mathcal{F}_n) &= \mu(\{y - X_n\}) \\ & = p \mathbf{1}_{\{y - X_n = 1\}} + (1 - p) \mathbf{1}_{\{y - X_n = -1\}} \\ & = q(X_n, y) \quad \text{a.s.} \end{aligned} \] Since \(\mathbb{Z}\) is countable, summing over \(y \in A\) (countable additivity of conditional probabilities, valid a.s.) gives \(\mathbb{P}(X_{n+1} \in A \mid \mathcal{F}_n) = q(X_n, A)\) a.s. for every \(A \subseteq \mathbb{Z}\). This confirms the Markov property with transition kernel \(q\).

NoteNotation for Initial States

We work in the canonical setting of Lectures 42.2 and 43.1 with \(S = \mathbb{Z}\), \(\mathcal{B} = \mathcal{P}(\mathbb{Z})\): \(\Omega = \mathbb{Z}^{\mathbb{N}_0}\), \(X_n\) is the \(n\)-th coordinate, \(\mathcal{F}_n = \sigma(X_0, \dots, X_n)\), and for each \(x \in \mathbb{Z}\), \(\mathbb{P}^x\) and \(\mathbb{E}^x\) denote the probability measure and expectation under which \((X_n)_{n \in \mathbb{N}_0}\) is a Markov chain with kernel \(q\) started deterministically at \(X_0 = x\) (so that \(\mathbb{P}^x(X_0 = x) = 1\)). The measure \(\mathbb{P}^x\) depends on \(p\); when the parameter must be made explicit we write \(\mathbb{P}^x_p\).

Remark 93.1 (Increments Under \(\mathbb{P}^x\)). On the canonical space define \(\xi_k := X_k - X_{k-1}\) for \(k \ge 1\). Then under \(\mathbb{P}^x\) the random variables \(\xi_1, \xi_2, \dots\) are i.i.d. with law \(\mu = p\delta_1 + (1-p)\delta_{-1}\). Indeed, by the Markov property the finite-dimensional distributions are \(\mathbb{P}^x(X_1 = x_1, \dots, X_n = x_n) = \prod_{k=1}^n q(x_{k-1}, x_k)\) with \(x_0 := x\), so for \(e_1, \dots, e_n \in \mathbb{Z}\), writing \(x_k := x + e_1 + \cdots + e_k\), \[ \begin{aligned} \mathbb{P}^x(\xi_1 = e_1, \dots, \xi_n = e_n) &= \mathbb{P}^x(X_1 = x_1, \dots, X_n = x_n) \\ &= \prod_{k=1}^n q(x_{k-1}, x_{k-1} + e_k) \\ &= \prod_{k=1}^n \mu(\{e_k\}). \end{aligned} \] In particular, \(\mathbb{P}^x\)-a.s. we have \(X_0 = x\) and \(|X_{n+1} - X_n| = 1\) for all \(n \ge 0\): the walk is skip-free, so it cannot pass from one side of an integer level to the other without visiting it. Conversely, the process of Proposition 93.1 with \(X_0 \equiv x\) has the same finite-dimensional distributions, hence the same law on \(\mathbb{Z}^{\mathbb{N}_0}\), as \(X\) under \(\mathbb{P}^x\). Thus every probability of a path event computed with i.i.d. increments is a \(\mathbb{P}^x\)-probability.

93.2 First-Step Analysis and Harmonic Equations

Let \(B \subseteq \mathbb{Z}\) be a nonempty target set. Define the first hitting time of \(B\) by \[ T_B = \inf \{ n \ge 0 : X_n \in B \}, \] with the standard convention \(\inf \emptyset = +\infty\). Define the hitting location (exit position) by \[ L_B = X_{T_B} \quad \text{on } \{T_B < \infty\}, \qquad L_B = \Delta \quad \text{on } \{T_B = \infty\}, \] where \(\Delta \notin \mathbb{Z}\) is a cemetery point, as in Lecture 43.1. Thus \(\{L_B = y\} = \{T_B < \infty, X_{T_B} = y\}\) for \(y \in B\). Let \(h : B \to \mathbb{R}\) be a bounded function on \(B\) (every function on \(\mathbb{Z}\) is measurable for \(\mathcal{P}(\mathbb{Z})\)), and define the value function \(u : \mathbb{Z} \to \mathbb{R}\) by \[ u(x) = \mathbb{E}^x \left[ h(X_{T_B}) \mathbf{1}_{\{T_B < \infty\}} \right], \qquad x \in \mathbb{Z}. \tag{93.3}\] In the special case \(h \equiv 1\) on \(B\), Equation 93.3 reduces to the hitting probability \[ u(x) = \mathbb{P}^x(T_B < \infty), \qquad x \in \mathbb{Z}. \]

Proposition 93.2 (Boundary-Value Problem from First-Step Analysis) Let \(B \subseteq \mathbb{Z}\) and let \(h : B \to \mathbb{R}\) be bounded. The function \(u(x) = \mathbb{E}^x[h(X_{T_B}) \mathbf{1}_{\{T_B < \infty\}}]\) satisfies the boundary-value problem \[ \begin{cases} u(x) = h(x), & x \in B, \\ u(x) = (Qu)(x) := \sum_{y \in \mathbb{Z}} q(x, y) u(y), & x \in B^c, \end{cases} \tag{93.4}\] where \(B^c = \mathbb{Z} \setminus B\). Specifically, for \(x \notin B\), \(u\) satisfies the homogeneous three-term linear recurrence relation \[ p u(x + 1) - u(x) + (1 - p) u(x - 1) = 0, \qquad x \notin B. \tag{93.5}\]

Proof (Proof of Proposition 93.2). This is the special case \(S = \mathbb{Z}\) of Proposition 92.1 in Lecture 43.1 (extend \(h\) arbitrarily to \(\mathbb{Z}\), e.g. by \(0\) on \(B^c\); only \(h|_B\) enters). For the reader’s convenience we sketch the argument.

First, suppose \(x \in B\). Under \(\mathbb{P}^x\), we have \(X_0 = x \in B\) almost surely, which implies \(T_B = 0\) and \(X_{T_B} = X_0 = x\) \(\mathbb{P}^x\)-a.s. Hence \(u(x) = \mathbb{E}^x[h(x)] = h(x)\).

Second, suppose \(x \notin B\). Let \(F(\underline{x}) := h(L_B(\underline{x}))\mathbf{1}_{\{T_B(\underline{x}) < \infty\}}\) on path space, so that \(u(y) = \mathbb{E}^y[F(X)]\). By the shift identities of Proposition 91.1, for every path \(\underline{y}\) we have \(T_B(x, \underline{y}) = 1 + T_B(\underline{y})\) and \(L_B(x, \underline{y}) = L_B(\underline{y})\), hence \(F(x, \underline{y}) = F(\underline{y})\). The first-step formula (Theorem 91.1) and the fact that \(X_1\) has law \(q(x, \cdot)\) under \(\mathbb{P}^x\) give \[ \begin{aligned} u(x) &= \mathbb{E}^x[F(X)] \\ &= \sum_{y \in \mathbb{Z}} q(x, y) \, \mathbb{E}^y\left[F(x, X)\right] \\ &= \sum_{y \in \mathbb{Z}} q(x, y) \, \mathbb{E}^y\left[F(X)\right] \\ &= \sum_{y \in \mathbb{Z}} q(x, y) u(y), \end{aligned} \] where only the two terms \(y = x \pm 1\) (each with \(q(x, y) > 0\)) are non-zero, so no conditioning on null events occurs. Substituting the explicit form Equation 93.1 of \(q(x, y)\) into the sum gives \[ u(x) = p u(x + 1) + (1 - p) u(x - 1), \qquad x \notin B. \] Rearranging this identity yields Equation 93.5.

Lemma 93.1 (General Solution to the Three-Term Recurrence) Define the parameter \[ \lambda_p := \frac{1 - p}{p}. \tag{93.6}\] Let \(a, b \in \mathbb{Z} \cup \{-\infty, +\infty\}\) with \(a < b\), let \(I = \{x \in \mathbb{Z} : a < x < b\}\) and \(\bar{I} = \{x \in \mathbb{Z} : a \le x \le b\}\) (so \(\bar{I}\) adds the finite endpoints to \(I\)). Let \(u : \bar{I} \to \mathbb{R}\) be any real-valued function satisfying the recurrence \(p u(x+1) - u(x) + (1-p) u(x-1) = 0\) for all \(x \in I\). Then:

  • If \(p \neq \frac{1}{2}\) (so \(\lambda_p \neq 1\)), \[ u(x) = \alpha + \beta \lambda_p^x, \qquad x \in \bar{I}, \tag{93.7}\] for unique constants \(\alpha, \beta \in \mathbb{R}\).
  • If \(p = \frac{1}{2}\) (so \(\lambda_p = 1\)), \[ u(x) = \alpha + \beta x, \qquad x \in \bar{I}, \tag{93.8}\] for unique constants \(\alpha, \beta \in \mathbb{R}\).

Conversely, every function of this form solves the recurrence on \(I\).

Proof (Proof of Lemma 93.1). Seeking solutions of the form \(u(x) = \lambda^x\) (\(\lambda \neq 0\)) to the linear constant-coefficient difference equation \(p u(x+1) - u(x) + (1-p) u(x-1) = 0\) yields the characteristic polynomial \[ p \lambda^2 - \lambda + (1 - p) = 0. \] Factoring this quadratic polynomial gives \[ (p \lambda - (1 - p))(\lambda - 1) = 0, \] so the characteristic roots are \[ \lambda_1 = 1 \qquad \text{and} \qquad \lambda_2 = \lambda_p = \frac{1 - p}{p}. \] Hence \(x \mapsto 1\) and \(x \mapsto \lambda_p^x\) solve the recurrence. When \(p = \frac{1}{2}\), \(x \mapsto x\) also solves it, since \(\frac{1}{2}(x+1) - x + \frac{1}{2}(x-1) = 0\). By linearity, every function of the stated form is a solution.

Dimension count. Let \(V\) be the real vector space of solutions \(u : \bar{I} \to \mathbb{R}\). Since \(a < b\) are integers or \(\pm\infty\), \(\bar{I}\) contains two consecutive integers \(x_0, x_0 + 1\). Since \(p, 1 - p > 0\), the recurrence can be solved forwards and backwards, \[ \begin{aligned} &u(x + 1) = \frac{u(x) - (1 - p) u(x - 1)}{p}, \\ &u(x - 1) = \frac{u(x) - p u(x + 1)}{1 - p}, \qquad x \in I, \end{aligned} \] so the linear map \(V \to \mathbb{R}^2\), \(u \mapsto (u(x_0), u(x_0 + 1))\), is a bijection and \(\dim V = 2\). (If \(I = \emptyset\), i.e. \(b = a + 1\), then \(\bar{I} = \{a, b\}\) and \(V = \mathbb{R}^{\bar{I}}\), which is again two-dimensional.)

When \(p \neq \frac{1}{2}\), the vectors \((1, 1)\) and \((\lambda_p^{x_0}, \lambda_p^{x_0+1})\) are linearly independent because \(\lambda_p \neq 1\). So \(\{1, \lambda_p^x\}\) is a basis of \(V\), yielding Equation 93.7 with unique \(\alpha, \beta\). When \(p = \frac{1}{2}\), \((1, 1)\) and \((x_0, x_0 + 1)\) are linearly independent, so \(\{1, x\}\) is a basis of \(V\), yielding Equation 93.8.

93.3 Symmetry and Reduction to \(p \in \left(\frac{1}{2}, 1\right)\)

The case \(p = \frac{1}{2}\) corresponds to the symmetric simple random walk treated in Lecture 42.2. For \(p \neq \frac{1}{2}\), spatial reflection allows us to restrict attention to the upward-drifting regime \(p > \frac{1}{2}\).

Proposition 93.3 (Spatial Reflection Symmetry) Let \((X_n)_{n \ge 0}\) be a biased random walk on \(\mathbb{Z}\) with parameter \(p \in (0, 1)\) and transition kernel \(q_p\). Then the reflected process \((-X_n)_{n \ge 0}\) is a biased random walk on \(\mathbb{Z}\) with parameter \(1 - p\) and transition kernel \(q_{1-p}\).

Proof (Proof of Proposition 93.3). For any \(x, y \in \mathbb{Z}\), evaluating \(q_p\) at the reflected states \(-x\) and \(-y\) gives \[ \begin{aligned} q_p(-x, -y) &= p \mathbf{1}_{\{-y = -x + 1\}} + (1 - p) \mathbf{1}_{\{-y = -x - 1\}} \\ &= p \mathbf{1}_{\{y = x - 1\}} + (1 - p) \mathbf{1}_{\{y = x + 1\}} \\ &= (1 - p) \mathbf{1}_{\{y = x + 1\}} + p \mathbf{1}_{\{y = x - 1\}} \\ &= q_{1-p}(x, y). \end{aligned} \] Let \((\mathcal{F}_n)\) be a filtration with respect to which \((X_n)\) is Markov with kernel \(q_p\). Since \(x \mapsto -x\) is a bijection of \(\mathbb{Z}\), \(-X_n\) is \(\mathcal{F}_n\)-measurable, and for every \(y \in \mathbb{Z}\), \[ \begin{aligned} \mathbb{P}(-X_{n+1} = y \mid \mathcal{F}_n) &= \mathbb{P}(X_{n+1} = -y \mid \mathcal{F}_n)\\ & = q_p(X_n, -y) \\ &= q_p(-(-X_n), -y) \\ &= q_{1-p}(-X_n, y) \quad \text{a.s.} \end{aligned} \] Hence \((-X_n)_{n \ge 0}\) is a Markov chain with transition kernel \(q_{1-p}\), i.e., a biased random walk with parameter \(1 - p\).

In particular, the law of \((-X_n)_{n \ge 0}\) under \(\mathbb{P}^x_p\) has the same finite-dimensional distributions as, and hence equals, the law of \((X_n)_{n \ge 0}\) under \(\mathbb{P}^{-x}_{1-p}\). Since reflection maps \(T_z\) to \(T_{-z}\), for example \(\mathbb{P}^x_p(T_b < T_a) = \mathbb{P}^{-x}_{1-p}(T_{-b} < T_{-a})\) and \(\mathbb{E}^x_p[T_b] = \mathbb{E}^{-x}_{1-p}[T_{-b}]\).

NoteStanding Assumption

By Proposition 93.3, any hitting probability or expected hitting time for \(p \in (0, \frac{1}{2})\) equals the corresponding quantity for parameter \(1 - p \in (\frac{1}{2}, 1)\) with all states reflected (\(x \mapsto -x\)). Consequently, from Theorem 93.1 onward we assume without loss of generality that \[ p \in \left(\frac{1}{2}, 1\right), \qquad \text{so that} \qquad 0 < \lambda_p = \frac{1 - p}{p} < 1. \] The only exceptions are Lemma 93.2 and Lemma 93.3, which hold for every \(p \in (0, 1)\).

93.4 Two-Sided Exit Problem

Fix two integers \(a, b \in \mathbb{Z}\) with \(a < b\), and consider the two-point boundary set \(B = \{a, b\}\). For any \(z \in \mathbb{Z}\), write \(T_z := T_{\{z\}} = \inf\{n \ge 0 : X_n = z\}\). Then \[ T_{\{a, b\}} = \inf \{ n \ge 0 : X_n \in \{a, b\} \} = T_a \wedge T_b = \min(T_a, T_b). \]

Lemma 93.2 (Exit from a Finite Interval in Finite Time) Let \(p \in (0, 1)\), let \(a, b \in \mathbb{Z}\) with \(a < b\), put \(m := b - a\), and let \(x \in \mathbb{Z}\) with \(a \le x \le b\). Then for every \(k \in \mathbb{N}_0\), \[ \mathbb{P}^x\big(T_{\{a, b\}} > k m\big) \le (1 - p^m)^k. \] Consequently \(\mathbb{P}^x(T_{\{a, b\}} < \infty) = 1\), and moreover \(\mathbb{E}^x[T_{\{a, b\}}] \le m p^{-m} < \infty\).

Proof (Proof of Lemma 93.2). If \(x \in \{a, b\}\), then \(T_{\{a, b\}} = 0\) \(\mathbb{P}^x\)-a.s. and there is nothing to prove, so let \(a < x < b\). Write \(T := T_{\{a, b\}}\) and, with \(\xi_k = X_k - X_{k-1}\) as in Remark 93.1, consider the events on disjoint blocks of increments \[ A_j := \{\xi_{jm+1} = \xi_{jm+2} = \cdots = \xi_{(j+1)m} = +1\}, \qquad j \in \mathbb{N}_0. \] By Remark 93.1, the events \(A_0, A_1, \dots\) are independent under \(\mathbb{P}^x\), with \(\mathbb{P}^x(A_j) = p^m\).

On \(\{T > jm\}\) we have \(a < X_{jm} < b\), by skip-freeness. If in addition \(A_j\) occurs, then the walk makes \(m\) consecutive up-steps from \(X_{jm} \ge a + 1\), reaching \(X_{jm} + m \ge b + 1\). Being skip-free, it therefore visits \(b\) at some time in \((jm, (j+1)m]\), so \(T \le (j+1)m\). Hence, up to a \(\mathbb{P}^x\)-null set, \[ \{T > (j+1)m\} \subseteq \{T > jm\} \cap A_j^c, \] and by induction \(\{T > km\} \subseteq A_0^c \cap \cdots \cap A_{k-1}^c\). Independence gives \(\mathbb{P}^x(T > km) \le (1 - p^m)^k\). Letting \(k \to \infty\) yields \(\mathbb{P}^x(T = \infty) = 0\). Finally, since \(\mathbb{P}^x(T > n)\) is non-increasing in \(n\), \[ \mathbb{E}^x[T] = \sum_{n=0}^{\infty} \mathbb{P}^x(T > n) \le m \sum_{k=0}^{\infty} \mathbb{P}^x(T > km) \le m \sum_{k=0}^{\infty} (1 - p^m)^k = \frac{m}{p^m}. \]

Theorem 93.1 (Two-Sided Exit Probabilities) Let \(p \in (\frac{1}{2}, 1)\) and let \(a, b \in \mathbb{Z}\) with \(a < b\). For every \(x \in \mathbb{Z}\) satisfying \(a \le x \le b\), we have \[ \mathbb{P}^x(T_b < T_a) = \mathbb{P}^x(L_{\{a, b\}} = b) = \frac{\lambda_p^x - \lambda_p^a}{\lambda_p^b - \lambda_p^a} = \frac{1 - \lambda_p^{x - a}}{1 - \lambda_p^{b - a}}, \tag{93.9}\] where \(\lambda_p = \frac{1-p}{p} \in (0, 1)\). In addition, \(\mathbb{P}^x(T_a < T_b) = 1 - \mathbb{P}^x(T_b < T_a)\). (Formally letting \(\lambda_p \to 1\) in the last expression, via \(\frac{1 - \lambda^{x-a}}{1 - \lambda^{b-a}} \to \frac{x-a}{b-a}\), recovers the symmetric formula \(\mathbb{P}^x(T_b < T_a) = \frac{x - a}{b - a}\) of the case \(p = \frac{1}{2}\); that case is proved separately by the same method using Equation 93.8.)

Proof (Proof of Theorem 93.1). Step 1: Exit in finite time.
By Lemma 93.2, \(\mathbb{P}^x(T_{\{a, b\}} < \infty) = 1\). Since \(a \neq b\), at most one of \(T_a, T_b\) equals \(T_{\{a, b\}}\) when the latter is finite, so \(\{T_a < T_b\}\) and \(\{T_b < T_a\}\) are disjoint and their union is \(\{T_{\{a, b\}} < \infty\}\). This gives \(\mathbb{P}^x(T_a < T_b) = 1 - \mathbb{P}^x(T_b < T_a)\). (Step 1 is not needed for Equation 93.9 itself.)

Step 2: Formulation via first-step analysis.
Define the boundary function \(h : \{a, b\} \to \{0, 1\}\) by \(h(a) = 0\) and \(h(b) = 1\), i.e., \(h(y) = \mathbf{1}_{\{y = b\}}\). For every path we have the identity of events \[ \{T_b < T_a\} = \{T_{\{a, b\}} < \infty, \ X_{T_{\{a, b\}}} = b\} = \{L_{\{a, b\}} = b\}. \] Indeed, if \(T_b < T_a\) then \(T_b < \infty\) and \(T_{\{a, b\}} = T_b\). Conversely, if \(T_{\{a, b\}} < \infty\) and \(X_{T_{\{a, b\}}} = b\), then \(T_{\{a,b\}} = T_b\) and \(X_{T_b} = b \ne a\), so \(T_a \ne T_b\) and hence \(T_a > T_b\). Therefore, \[ u(x) := \mathbb{P}^x(T_b < T_a) = \mathbb{P}^x(L_{\{a, b\}} = b) = \mathbb{E}^x \left[ h(X_{T_{\{a, b\}}}) \mathbf{1}_{\{T_{\{a, b\}} < \infty\}} \right]. \] By Proposition 93.2, \(u\) satisfies the boundary conditions \[ u(a) = \mathbb{P}^a(T_b < T_a) = 0, \qquad u(b) = \mathbb{P}^b(T_b < T_a) = 1, \] and the recurrence \[ u(x) = p u(x + 1) + (1 - p) u(x - 1), \qquad a < x < b. \]

Step 3: Solving for the constants.
Since \(p > \frac{1}{2}\), we have \(\lambda_p \neq 1\). The restriction of \(u\) to \(\{a, \dots, b\}\) satisfies the recurrence on \(\{a+1, \dots, b-1\}\), so by Lemma 93.1 (with \(\bar{I} = \{a, \dots, b\}\)) there exist constants \(\alpha, \beta \in \mathbb{R}\) such that \[ u(x) = \alpha + \beta \lambda_p^x, \qquad a \le x \le b. \] Imposing the boundary conditions at \(x = a\) and \(x = b\) yields the linear system \[ \begin{aligned} \alpha + \beta \lambda_p^a &= 0, \\ \alpha + \beta \lambda_p^b &= 1. \end{aligned} \] Subtracting the first equation from the second gives \(\beta(\lambda_p^b - \lambda_p^a) = 1\). Since \(a < b\) and \(0 < \lambda_p < 1\), we have \(\lambda_p^b - \lambda_p^a \neq 0\), so \[ \beta = \frac{1}{\lambda_p^b - \lambda_p^a}, \qquad \alpha = -\beta \lambda_p^a = -\frac{\lambda_p^a}{\lambda_p^b - \lambda_p^a}. \] Substituting \(\alpha\) and \(\beta\) back into \(u(x) = \alpha + \beta \lambda_p^x\) gives \[ u(x) = \frac{\lambda_p^x - \lambda_p^a}{\lambda_p^b - \lambda_p^a}. \] Dividing both numerator and denominator by \(-\lambda_p^a \neq 0\) produces \[ u(x) = \frac{1 - \lambda_p^{x - a}}{1 - \lambda_p^{b - a}}, \qquad a \le x \le b, \] which establishes Equation 93.9.

93.5 Application: Gambler’s Ruin

Consider a gambler playing a repeated game against the House, where on each round the gambler either wins \(\$1\) or loses \(\$1\). Suppose the House has probability \(p > \frac{1}{2}\) of winning each round (so the gambler wins each round with probability \(1 - p < \frac{1}{2}\)), and successive rounds are independent.

We model the game from the House’s perspective: - Suppose the gambler starts with an initial fortune of \(\$k\) (\(k \in \mathbb{N}\)), and let \(G_n\) denote the gambler’s fortune after \(n\) rounds, so \(G_0 = k\). Set \[ X_n := -G_n = (\text{House's net winnings after } n \text{ rounds}) - k. \] Each round, \(X_n\) increases by \(1\) (House wins) with probability \(p\) and decreases by \(1\) with probability \(1 - p\), independently. So \((X_n)\) is a biased random walk with parameter \(p > \frac{1}{2}\), started at \(x = -k < 0\) (and \(|x| = k\) is the gambler’s initial fortune). - The gambler plays repeatedly until one of two stopping events occurs: 1. Gambler goes broke: The gambler loses all \(\$k\), which corresponds to the House winning \(\$k\), i.e., \(X_n = 0\). 2. Gambler reaches target fortune: The gambler increases their fortune to \(\$m\) for some integer \(m > k\) (winning an additional \(\$(m - k)\)), which corresponds to \(X_n = b\), where \(b = -m < x < 0\) (so \(|b| = m > |x|\) is the gambler’s target fortune).

In this parameterization (\(b < x < 0\)), the probability that the gambler reaches fortune \(|b|\) before going broke is \(\mathbb{P}^x(T_b < T_0)\). Since the walk is stopped at time \(T_b \wedge T_0\), this probability depends only on the walk up to that time and can be computed for the unstopped walk. Applying Theorem 93.1 with lower boundary \(b\) and upper boundary \(0\) (in place of \(a\) and \(b\)), including its complement statement, gives \[ \mathbb{P}^x(T_b < T_0) = 1 - \mathbb{P}^x(T_0 < T_b) = 1 - \frac{\lambda_p^x - \lambda_p^b}{\lambda_p^0 - \lambda_p^b} = \frac{1 - \lambda_p^x}{1 - \lambda_p^b}. \] Equivalently, \[ \mathbb{P}^x(T_b < T_0) = \frac{1 - \lambda_p^x}{1 - \lambda_p^b} = \frac{1 - \left(\frac{1}{\lambda_p}\right)^{|x|}}{1 - \left(\frac{1}{\lambda_p}\right)^{|b|}}, \qquad b < x < 0, \tag{93.10}\] since \(x = -|x|\) and \(b = -|b|\).

Special Case: Doubling One’s Fortune (\(|b| = 2|x|\)).
Suppose the gambler aims to double their initial fortune, so \(|b| = 2|x|\). Substituting \(|b| = 2|x|\) into Equation 93.10 and factoring the difference of squares in the denominator gives \[ \begin{aligned} \mathbb{P}^x(T_b < T_0) &= \frac{1 - \left(\frac{1}{\lambda_p}\right)^{|x|}}{1 - \left(\frac{1}{\lambda_p}\right)^{2|x|}} \\ &= \frac{1 - \left(\frac{1}{\lambda_p}\right)^{|x|}}{\left(1 - \left(\frac{1}{\lambda_p}\right)^{|x|}\right)\left(1 + \left(\frac{1}{\lambda_p}\right)^{|x|}\right)} \\ &= \frac{1}{1 + \left(\frac{1}{\lambda_p}\right)^{|x|}} \\ &< \lambda_p^{|x|}. \end{aligned} \]

Numerical Illustration:
In a game with a modest House edge, take \(p = 0.53\). This is close to an even-money bet in American roulette, where the gambler wins with probability \(18/38 \approx 0.474\), so \(p = 20/38 \approx 0.526\). Then \[ \lambda_p = \frac{1 - p}{p} = \frac{0.47}{0.53} \approx 0.8868 < 0.89. \] If the gambler starts with \(|x| = 100\) dollars and attempts to double their fortune to \(|b| = 200\) dollars, the probability of succeeding before going broke is bounded above by \[ \mathbb{P}^{-100}(T_{-200} < T_0) < (0.8868)^{100} \approx 6.06 \times 10^{-6}, \] (or, with the cruder bound, \((0.89)^{100} \approx 8.69 \times 10^{-6}\)) which is less than one in \(100{,}000\). (The exact value \(1/(1 + \lambda_p^{-100})\) is also \(\approx 6.06 \times 10^{-6}\).) For comparison, European roulette has a single zero, so the gambler wins with probability \(18/37\), giving \(\lambda_p = 18/19\) and success probability \(1/(1 + (19/18)^{100}) \approx 4.47 \times 10^{-3}\). A smaller House edge makes a dramatic difference, but the gambler remains overwhelmingly likely to be ruined.

93.6 Single-Point Hitting Probabilities and Transience

We now pass to the limit as one of the boundaries tends to \(\pm \infty\) in Theorem 93.1 to compute the single-point hitting probabilities \(\mathbb{P}^x(T_b < \infty)\) for arbitrary \(x, b \in \mathbb{Z}\).

Lemma 93.3 (Monotone Limits of Hitting Events) Let \(p \in (0, 1)\), let \(x \in \mathbb{Z}\), and consider the biased random walk \((X_n)_{n \ge 0}\) under \(\mathbb{P}^x\). All indices \(a, b\) below are integers.

  1. Let \(b \ge x\). For \(a_2 < a_1 < x\), we have \(\{T_b < T_{a_1}\} \subseteq \{T_b < T_{a_2}\}\) up to a \(\mathbb{P}^x\)-null set, and (for every path) \[ \bigcup_{a < x} \{T_b < T_a\} = \{T_b < \infty\}. \] Consequently, \[ \mathbb{P}^x(T_b < \infty) = \lim_{a \to -\infty} \mathbb{P}^x(T_b < T_a). \]
  2. Let \(a \le x\). For \(x < b_1 < b_2\), we have \(\{T_{b_2} < T_a\} \subseteq \{T_{b_1} < T_a\}\) up to a \(\mathbb{P}^x\)-null set, and \[ \bigcap_{b > x} \{T_b < T_a\} = \{T_a = \infty\} \qquad \text{up to a } \mathbb{P}^x\text{-null set}. \] Consequently, \[ \mathbb{P}^x(T_a = \infty) = \lim_{b \to +\infty} \mathbb{P}^x(T_b < T_a). \]
WarningThe identity in part 2 is not pathwise

The set identity in part 2 is genuinely only almost sure. For skip-free paths started at \(x\), \(\bigcap_{b > x} \{T_b < T_a\} = \{T_a = \infty, \ \sup_n X_n = \infty\}\). For example, if \(a < x\), the alternating path \(x, x+1, x, x+1, \dots\) lies in \(\{T_a = \infty\}\) but never reaches \(x + 2\). Such paths form a \(\mathbb{P}^x\)-null set by Lemma 93.2.

Proof (Proof of Lemma 93.3). By Remark 93.1 there is a \(\mathbb{P}^x\)-null set \(N\) outside of which \(X_0 = x\) and \(|X_{n+1} - X_n| = 1\) for all \(n\). We work on \(N^c\); since probabilities are unaffected by modifications on null sets, continuity of probability applies to events that are monotone up to null sets.

  1. Let \(x \le b\) and \(a_2 < a_1 < x\). On \(N^c\) the walk starts at \(x > a_1\) and is skip-free, so it must visit \(a_1\) before (or at the time) it first visits \(a_2\); hence \(T_{a_1} \le T_{a_2}\), and \(\{T_b < T_{a_1}\} \subseteq \{T_b < T_{a_2}\}\). For the set identity, if \(T_b < \infty\), choose an integer \(a < \min\{x, \min_{0 \le k \le T_b} X_k\}\). The walk does not visit \(a\) up to time \(T_b\), so \(T_b < T_a\). Conversely, if \(T_b < T_a\) for some \(a\), then \(T_b < T_a \le \infty\), so \(T_b < \infty\). Continuity of probability from below, along the (a.s.) increasing sequence \(a = x - 1, x - 2, \dots\), yields \(\mathbb{P}^x(T_b < \infty) = \lim_{a \to -\infty} \mathbb{P}^x(T_b < T_a)\).

  2. Let \(a \le x < b_1 < b_2\). On \(N^c\), skip-freeness gives \(T_{b_1} \le T_{b_2}\), so \(\{T_{b_2} < T_a\} \subseteq \{T_{b_1} < T_a\}\).

    Inclusion “\(\subseteq\)”. On \(N^c \cap \bigcap_{b > x}\{T_b < T_a\}\), skip-freeness gives \(T_b \ge b - x\), hence \(T_a > b - x\) for every \(b > x\), forcing \(T_a = \infty\).

    Inclusion “\(\supseteq\)” up to a null set. For each \(b > x\), \[ \{T_a = \infty\} \setminus \{T_b < T_a\} = \{T_a = \infty, \ T_b = \infty\} = \{T_{\{a, b\}} = \infty\}, \] which is \(\mathbb{P}^x\)-null by Lemma 93.2 (applicable since \(a \le x \le b\) and \(p \in (0, 1)\)). Hence \(\{T_a = \infty\} \setminus \bigcap_{b > x}\{T_b < T_a\} \subseteq \bigcup_{b > x} \{T_{\{a, b\}} = \infty\}\) is a countable union of null sets, hence null.

    Continuity of probability from above (valid since \(\mathbb{P}^x\) is finite), along the (a.s.) decreasing sequence \(b = x + 1, x + 2, \dots\), yields \(\mathbb{P}^x(T_a = \infty) = \lim_{b \to +\infty} \mathbb{P}^x(T_b < T_a)\).

Corollary 93.1 (Single-Point Hitting Probabilities) Let \((X_n)_{n \ge 0}\) be the biased random walk with parameter \(p \in (\frac{1}{2}, 1)\), so that \(\lambda_p = \frac{1-p}{p} \in (0, 1)\). Then for all \(x, b \in \mathbb{Z}\), \[ \mathbb{P}^x(T_b < \infty) = \begin{cases} 1, & \text{if } x \le b, \\[6pt] \left(\dfrac{1 - p}{p}\right)^{x - b} = \lambda_p^{x - b}, & \text{if } x > b. \end{cases} \tag{93.11}\] In particular, whenever \(b < x\), we have \(\mathbb{P}^x(T_b = \infty) = 1 - \lambda_p^{x - b} > 0\), and hence \(\mathbb{E}^x[T_b] = \infty\).

Proof (Proof of Corollary 93.1). We consider the two cases \(x \le b\) and \(x > b\) separately.

Case 1: \(x \le b\).
If \(x = b\), then \(T_b = 0\) \(\mathbb{P}^x\)-a.s., so \(\mathbb{P}^x(T_b < \infty) = 1\). If \(x < b\), apply Lemma 93.3 (1) and Theorem 93.1. Since \(0 < \lambda_p < 1\), we have \(\lambda_p^{x - a} \to 0\) and \(\lambda_p^{b - a} \to 0\) as \(a \to -\infty\). Therefore, \[ \mathbb{P}^x(T_b < \infty) = \lim_{a \to -\infty} \mathbb{P}^x(T_b < T_a) = \lim_{a \to -\infty} \frac{1 - \lambda_p^{x - a}}{1 - \lambda_p^{b - a}} = \frac{1 - 0}{1 - 0} = 1. \]

Case 2: \(x > b\).
Relabeling \(b\) as \(a\) in Lemma 93.3 (2), for \(x > b\) we have \(\lambda_p^{y - b} \to 0\) as \(y \to +\infty\) because \(0 < \lambda_p < 1\). Thus, \[ \mathbb{P}^x(T_b = \infty) = \lim_{y \to +\infty} \mathbb{P}^x(T_y < T_b) = \lim_{y \to +\infty} \frac{1 - \lambda_p^{x - b}}{1 - \lambda_p^{y - b}} = \frac{1 - \lambda_p^{x - b}}{1 - 0} = 1 - \lambda_p^{x - b}. \] Taking the complement gives \[ \mathbb{P}^x(T_b < \infty) = 1 - \mathbb{P}^x(T_b = \infty) = \lambda_p^{x - b} = \left(\frac{1 - p}{p}\right)^{x - b}. \] Finally, when \(b < x\), we have \(x - b \ge 1\) and \(\lambda_p < 1\), so \(\mathbb{P}^x(T_b = \infty) = 1 - \lambda_p^{x - b} > 0\). Since \(T_b\) takes the value \(+\infty\) with strictly positive \(\mathbb{P}^x\)-probability, its expectation is infinite: \[ \mathbb{E}^x[T_b] \ge (+ \infty) \cdot \mathbb{P}^x(T_b = \infty) = \infty. \]

Remark 93.2 (Transience). Let \(T_x^+ := \inf\{n \ge 1 : X_n = x\}\) be the return time to \(x\). For every path \(\underline{y}\), \(T_x^+(x, \underline{y}) = 1 + T_x(\underline{y})\). So the first-step formula (Theorem 91.1) applied to \(F = \mathbf{1}_{\{T_x^+ < \infty\}}\), together with Corollary 93.1, gives \[ \begin{aligned} \mathbb{P}^x(T_x^+ < \infty) &= p\, \mathbb{P}^{x+1}(T_x < \infty) + (1 - p)\, \mathbb{P}^{x-1}(T_x < \infty) \\ &= p \lambda_p + (1 - p) = 2(1 - p) < 1. \end{aligned} \] Hence every state \(x \in \mathbb{Z}\) is transient for \(p \in (\frac{1}{2}, 1)\); by Proposition 93.3 the same holds for \(p \in (0, \frac{1}{2})\), with return probability \(2\min(p, 1-p)\).

93.7 Expected Hitting Times

When \(b \ge x\) (with \(p > \frac{1}{2}\)), Corollary 93.1 shows that \(\mathbb{P}^x(T_b < \infty) = 1\), meaning the walk hits \(b\) almost surely. It is natural to ask whether the expected hitting time \(\mathbb{E}^x[T_b]\) is also finite.

Theorem 93.2 (Expected Hitting Time of a Single State) Let \(p \in (\frac{1}{2}, 1)\). For all \(x, b \in \mathbb{Z}\), the expected first hitting time of \(b\) starting from \(x\) is given by \[ \mathbb{E}^x[T_b] = \begin{cases} \infty, & \text{if } b < x, \\[8pt] \dfrac{b - x}{p - (1 - p)} = \dfrac{b - x}{2p - 1}, & \text{if } b \ge x. \end{cases} \tag{93.12}\]

Proof (Proof of Theorem 93.2). The case \(b < x\) was already established in Corollary 93.1, since \(\mathbb{P}^x(T_b = \infty) > 0\) implies \(\mathbb{E}^x[T_b] = \infty\).

For \(b = x\), we have \(T_b = 0\) \(\mathbb{P}^x\)-a.s., so \(\mathbb{E}^x[T_b] = 0 = \frac{b - x}{2p - 1}\).

Now fix \(b\) and consider \(m(y) := \mathbb{E}^y[T_b] \in [0, \infty]\) for \(y \in \mathbb{Z}\). The argument has four steps.

Step 1: The first-step equation in \([0, \infty]\). Apply Corollary 92.2 and Theorem 92.1 (part 2, with \(g = \mathbf{1}_{B^c}\)) of Lecture 43.1 to \(S = \mathbb{Z}\) and \(B = \{b\}\). Then \(m\) is the least \([0, \infty]\)-valued function satisfying \[ m(b) = 0, \qquad m(y) = 1 + p\, m(y+1)\mathbf{1}_{\{y + 1 \ne b\}} + (1 - p)\, m(y-1)\mathbf{1}_{\{y - 1 \ne b\}}, \quad y \ne b, \] and \(m \le \tilde{v}\) for every \(\tilde{v} \in \mathcal{B}_+(\mathbb{Z})\) with \(\tilde{v}(y) \ge 1 + p\, \tilde{v}(y+1)\mathbf{1}_{\{y + 1 \ne b\}} + (1 - p)\, \tilde{v}(y-1)\mathbf{1}_{\{y - 1 \ne b\}}\) for all \(y \ne b\). Since \(m(b) = 0\), for \(y < b\) the equation reads \[ m(y) = 1 + p\, m(y + 1) + (1 - p)\, m(y - 1), \qquad y < b, \tag{93.13}\] as an identity in \([0, \infty]\). This equation alone does not determine \(m\); see Remark 93.3.

Step 2: An explicit supersolution, hence finiteness. A particular solution of \(p\, w(y+1) - w(y) + (1-p)\, w(y-1) = -1\) is linear: setting \(w(y) = c y\) gives \[ p c(y + 1) - c y + (1 - p) c(y - 1) = c(2p - 1) = -1 \iff c = -\frac{1}{2p - 1}. \] Hence \(m_0(y) := \frac{b - y}{2p - 1}\) satisfies Equation 93.13 for \(y < b\) with \(m_0(b) = 0\). Define \(\tilde{v} := m_0\) on \(\{y \le b\}\) and \(\tilde{v} := +\infty\) on \(\{y > b\}\). Then \(\tilde{v} \ge 0\), and it satisfies the system of Step 1 on \(\mathbb{Z} \setminus \{b\}\): - for \(y < b\) the system reduces to the recurrence for \(m_0\), which holds with equality; - for \(y > b\) both sides are \(+\infty\), because \(\tilde{v}(y) = \infty\) and \(\tilde{v}(y+1) = \infty\) enters with weight \(p > 0\).

By minimality, \(m \le \tilde{v}\); in particular \[ 0 \le m(y) \le \frac{b - y}{2p - 1} < \infty, \qquad y \le b. \]

Step 3: Solving the recurrence. By Step 2, \(m\) is real-valued on \(\{y \le b\}\), so we may subtract: \(m - m_0\) solves the homogeneous recurrence on \(\{y < b\}\). By Lemma 93.1 with \(a = -\infty\) and \(\bar{I} = \{y \le b\}\), there are \(\alpha, \beta \in \mathbb{R}\) with \(m(y) - m_0(y) = \alpha + \beta \lambda_p^y\) for \(y \le b\). The condition \(m(b) = 0 = m_0(b)\) gives \(\alpha = -\beta \lambda_p^b\), so \[ m(y) = \frac{b - y}{2p - 1} + \beta\big(\lambda_p^y - \lambda_p^b\big), \qquad y \le b. \]

Step 4: Identifying \(\beta = 0\). For \(y < b\) we have \(\lambda_p^y > \lambda_p^b\), since \(0 < \lambda_p < 1\). - The upper bound \(m \le m_0\) from Step 2 forces \(\beta \le 0\). - If \(\beta < 0\), then \(\beta \lambda_p^y = \beta \lambda_p^{-|y|} \to -\infty\) exponentially fast as \(y \to -\infty\), whereas \(\frac{b - y}{2p - 1}\) grows only linearly. So \(m(y) < 0\) for \(y\) sufficiently negative, contradicting \(m \ge 0\).

Hence \(\beta = 0\), and \[ \mathbb{E}^x[T_b] = \frac{b - x}{2p - 1} = \frac{b - x}{p - (1 - p)}, \qquad x \le b. \]

Remark 93.3 (Why Minimality (or Some Extra Input) Is Needed). For every \(\beta \ge 0\), the function \(m_\beta(y) := \frac{b - y}{2p - 1} + \beta(\lambda_p^y - \lambda_p^b)\), \(y \le b\), is finite, non-negative, satisfies Equation 93.13, and vanishes at \(b\). So is \(m \equiv \infty\) on \(\{y < b\}\). The recurrence and boundary condition alone therefore cannot identify \(\mathbb{E}^x[T_b]\). In particular, an argument of the form “\(m\) grows at most linearly, hence \(\beta = 0\)” presupposes what is to be proved. Some additional information is required; above it is supplied by the minimality principle of Lecture 43.1.

Remark 93.4 (Two Alternative Proofs).

  1. Optional stopping. Under \(\mathbb{P}^x\), \(M_n := X_n - (2p - 1) n\) is a martingale, since the increments \(\xi_k\) are i.i.d. with mean \(2p - 1\) by Remark 93.1. Optional stopping at the bounded time \(T_b \wedge n\) gives \(x + (2p - 1)\mathbb{E}^x[T_b \wedge n] = \mathbb{E}^x[X_{T_b \wedge n}]\).
    • For \(x \le b\), skip-freeness gives \(X_{T_b \wedge n} \le b\). So \(\mathbb{E}^x[T_b \wedge n] \le \frac{b - x}{2p - 1}\), and monotone convergence gives \(\mathbb{E}^x[T_b] \le \frac{b - x}{2p - 1} < \infty\).
    • By Corollary 93.1, \(X_{T_b \wedge n} \to X_{T_b} = b\) a.s. Moreover \(|X_{T_b \wedge n}| \le |x| + T_b\), which is integrable. Dominated convergence then gives \((2p - 1)\mathbb{E}^x[T_b] = b - x\).
  2. Truncation. For \(a < x \le b\), let \(T := T_{\{a,b\}}\) and \(u_{a,b}(x) := \mathbb{P}^x(T_b < T_a)\), given by Equation 93.9. By Lemma 93.2, \(T\) has finite expectation. Applying 1. to the bounded stopped walk then yields \[ \mathbb{E}^x[T] = \frac{a - x + (b - a)\, u_{a,b}(x)}{2p - 1}. \] As \(a \downarrow -\infty\), \(T_{\{a,b\}} \uparrow T_b\), because \(T_a \ge x - a \to \infty\). Write the numerator as \((b - x) + (b - a)\big(u_{a,b}(x) - 1\big)\) and note that \((b - a)\big(u_{a,b}(x) - 1\big) = (b-a)\frac{\lambda_p^{b-a} - \lambda_p^{x-a}}{1 - \lambda_p^{b-a}} \to 0\). Monotone convergence again gives \(\mathbb{E}^x[T_b] = \frac{b - x}{2p - 1}\).

93.8 Takeaways

  • Construction. The biased random walk is \(X_n = X_0 + \xi_1 + \cdots + \xi_n\) with \(X_0, \xi_1, \xi_2, \dots\) independent and \(\mathbb{P}(\xi_k = 1) = p = 1 - \mathbb{P}(\xi_k = -1)\). Under each \(\mathbb{P}^x\) the increments are i.i.d., and the walk is skip-free. Reflection \(x \mapsto -x\) exchanges \(p\) and \(1 - p\), so it suffices to treat \(p > \frac{1}{2}\), where \(\lambda_p = \frac{1-p}{p} \in (0, 1)\).
  • Harmonic equations. By first-step analysis, hitting functionals \(u(x) = \mathbb{E}^x[h(X_{T_B})\mathbf{1}_{\{T_B < \infty\}}]\) solve \(u = h\) on \(B\) and \(p\,u(x+1) - u(x) + (1-p)\,u(x-1) = 0\) off \(B\). On an integer interval, the solutions are exactly \(\alpha + \beta\lambda_p^x\) (for \(p \ne \frac{1}{2}\)) or \(\alpha + \beta x\) (for \(p = \frac{1}{2}\)).
  • Exit from finite intervals. For every \(p \in (0, 1)\), the walk leaves \(\{a+1, \dots, b-1\}\) in finite time a.s., with a geometric tail \(\mathbb{P}^x(T_{\{a,b\}} > km) \le (1 - p^m)^k\) (Lemma 93.2).
  • Two-sided exit. For \(a \le x \le b\), the walk hits \(b\) before \(a\) with probability \(\mathbb{P}^x(T_b < T_a) = \frac{1 - \lambda_p^{x-a}}{1 - \lambda_p^{b-a}}\). The two boundary values determine the two constants in the general solution uniquely.
  • Gambler’s ruin. Against a House with edge \(p > \frac{1}{2}\), the probability of doubling a fortune of \(k\) is \(\frac{1}{1 + \lambda_p^{-k}} < \lambda_p^k\). This is exponentially small in \(k\): for \(p = 0.53\) and \(k = 100\) it is about \(6 \times 10^{-6}\).
  • Single-point hitting and transience. Letting one boundary escape to infinity (Lemma 93.3; the downward limit is an identity only up to null sets) gives:
    • \(\mathbb{P}^x(T_b < \infty) = 1\) for \(b \ge x\): the walk reaches every level above its start;
    • \(\mathbb{P}^x(T_b < \infty) = \lambda_p^{x-b} < 1\) for \(b < x\): it reaches a level below its start only with exponentially small probability.
    In particular, every state is transient, with return probability \(2(1-p) < 1\) (Remark 93.2).
  • Expected hitting times. \(\mathbb{E}^x[T_b] = \frac{b - x}{2p - 1}\) for \(b \ge x\), and \(\mathbb{E}^x[T_b] = \infty\) for \(b < x\). The walk climbs at the linear speed \(2p - 1\), the mean increment.
  • Non-uniqueness and minimality. The first-step recurrence for \(\mathbb{E}^x[T_b]\) has a one-parameter family of finite non-negative solutions \(m_\beta\), \(\beta \ge 0\), together with \(+\infty\). The true expectation is singled out by a genuine extra input, here minimality (Lecture 43.1); alternatively, optional stopping or truncation can be used.
